# What works

This is a short, living record of what learners like. Keep successful
patterns when fixing existing lessons or creating new ones; use it alongside
the private feedback issues as evidence.

## How to write entries

Write one line per entry: what to keep doing, where it applies, the supporting
issue number(s), and the date. Use issue numbers only; do not copy names or
comment text.
