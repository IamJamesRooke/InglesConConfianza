# **Decide → Decided → Decided**

The **-ed** ending adds the syllable `/ɪd/`.


When a regular base ends in silent **e** after `/d/`, add only written **-d**. The result still ends in **-ded** and gains the `/ɪd/` syllable:

**decide → decided**

| Course source | Base | Past and past participle | Spanish bridge |
|---|---|---|---|
| core verb and cognate | decide | decided | decidió / decidido |
| cognate reinforcement | divide | divided | dividió / dividido |
| cognate reinforcement | include | included | incluyó / incluido |
| cognate reinforcement | conclude | concluded | concluyó / concluido |

- Past: Laura **decided** to revise the document and **included** another example.
- Past participle: Laura has **decided** to revise the document and has **included** another example.

Do not add another written **e**: **decide + d = decided**, not *decideed*. Pronounce the result as **deci-ded**.
