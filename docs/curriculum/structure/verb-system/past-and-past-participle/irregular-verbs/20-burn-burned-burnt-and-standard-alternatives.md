# **Burn → Burned/Burnt**: Standard Alternatives

Both regular and irregular forms are standard for these verbs. Usage varies by region and context.

| Base | Past = participle |
|---|---|
| burn | burned / burnt |
| dream | dreamed / dreamt |
| dwell | dwelled / dwelt |
| fit | fit / fitted |
| kneel | kneeled / knelt |
| lean | leaned / leant |
| leap | leaped / leapt |
| learn | learned / learnt |
| light | lighted / lit |
| smell | smelled / smelt |
| spell | spelled / spelt |
| spill | spilled / spilt |
| spoil | spoiled / spoilt |
| speed | speeded / sped |

American English often favors the regular form, but fixed adjectives may preserve the irregular one: **learned a lesson**, but **a learned professor** has a different pronunciation and meaning.

**I learned the route, but in Britain you will also hear that I learnt it.**
