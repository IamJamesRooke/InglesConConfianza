# The **-ted** Ending

When a regular base verb ends in `/t/`, **-ed** adds a new syllable pronounced `/ɪd/`:

**want `/wɑnt/` → wanted `/ˈwɑn.tɪd/`**

| Spelling family | Model transformation |
|---|---|
| [base ending in written **t**](01-want-wanted.md) | **want → wanted** |
| [base ending in **-ct**](02-accept-accepted.md) | **accept → accepted** |
| [base ending in written **te**](03-create-created.md) | **create → created** |

## One ending, two grammatical jobs

| Job | Example |
|---|---|
| past | Laura **wanted** help yesterday. |
| past participle | Laura has **wanted** help before. |

The simple course bridge is:

> If the result ends in written **-ted**, pronounce the **e**.

The ending is `/ɪd/`, not a bare `/t/`, because English needs a vowel between the two `/t/` sounds.
