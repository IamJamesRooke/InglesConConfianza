# **Fix → Fixed**

Final **x** represents the voiceless cluster `/ks/`, so **-ed** is pronounced `/t/`:

**fix → fixed**

| Course source | Base | Past and past participle | Spanish bridge |
|---|---|---|---|
| model vocabulary | fix | fixed | arregló / arreglado |
| supporting vocabulary | mix | mixed | mezcló / mezclado |
| cognate reinforcement | relax | relaxed | se relajó / se ha relajado |

- Past: Laura **fixed** the shelf, **mixed** the paint, and then **relaxed**.
- Past participle: Laura has **fixed** the shelf, **mixed** the paint, and finally **relaxed**.

The final cluster is compact: fix + `/t/` → `/fɪkst/`. It does not gain an extra syllable.
