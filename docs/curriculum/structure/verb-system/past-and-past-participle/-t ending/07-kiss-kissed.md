# **Kiss → Kissed**

After final `/s/`, **-ed** is pronounced `/t/`:

**kiss → kissed**

| Course source | Base | Past and past participle | Spanish bridge |
|---|---|---|---|
| model vocabulary | kiss | kissed | besó / besado |
| core source verb | promise | promised | prometió / prometido |
| cognate reinforcement | compress | compressed | comprimió / comprimido |
| memory bridge | practice | practiced | practicó / practicado |

- Past: Laura **promised** to help after she **practiced** the presentation.
- Past participle: Laura has **promised** to help and has **practiced** the presentation.

The final `/s/` appears under several spellings—**s, ss**, and **se**—but each takes `/t/`.
