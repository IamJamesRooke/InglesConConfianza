# High-Confusion Verb Structures

These drills compare structures that reuse the same small verbs but follow different question and negation patterns.

| Structure | Example |
|---|---|
| possession with **have** | **Does she have it?** |
| obligation with **have to** | **Do you have to do it?** |
| perfect **have + past participle** | **Have you done it?** |
| existence with **there + be** | **Is there a problem?** |

The vocabulary overlaps, but the grammar does not. Practice each complete structure as a unit.
