# Fluency Drill: **Should**

Use **should + base verb** for advice or what is advisable.

| Drill step | Spanish | English |
|---|---|---|
| embedded **if** clause | Quiero saber si lo deberías hacer. | I want to know if you should do it. |
| direct question | ¿Lo deberías hacer? | Should you do it? |
| affirmative answer | Sí, lo debería hacer. | Yes, I should do it. |
| negative answer | No, no lo debería hacer. | No, I shouldn't do it. |
| negative **why** question | ¿Por qué no lo deberías hacer? | Why shouldn't you do it? |
| embedded **why** clause | Quiero saber por qué no lo deberías hacer. | I want to know why you shouldn't do it. |

The direct question uses **should you**. The embedded clauses use statement order: **if you should** and **why you shouldn't**.
