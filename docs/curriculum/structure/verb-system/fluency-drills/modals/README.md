# Fluency Drills: Modal Verbs

Modal verbs go before the base form of the main verb:

| Modal | Example |
|---|---|
| **will** | I **will do** it. |
| **would** | I **would do** it. |
| **can** | I **can do** it. |
| **could** | I **could do** it. |
| **must** | I **must do** it. |
| **should** | I **should do** it. |

To form a direct question, move the modal before the subject: **You can do it. → Can you do it?**

After **I want to know**, keep statement order: **I want to know why you can't do it.**
