# Fluency Drills: **Be**

These drills practice **am, is, are, was**, and **were** as the first verb in two high-frequency structures:

| Structure | Present | Past |
|---|---|---|
| action in progress | **are doing / is doing** | **were doing / was doing** |
| plan or intention | **are going to do / is going to do** | **were going to do / was going to do** |

In a direct question, the form of **be** moves before the subject:

- You **are** doing it. → **Are** you doing it?
- He **was** going to do it. → **Was** he going to do it?

In an embedded clause after **I want to know**, use statement order:

- **I want to know if you are doing it.**
- **I want to know why he wasn't doing it.**

Do not invert the embedded clause: *I want to know why wasn't he doing it*.
