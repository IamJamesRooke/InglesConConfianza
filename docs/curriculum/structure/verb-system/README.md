# Verb System

This branch preserves reusable rules for English multiword verbs. The lexical meanings of particles and phrasal verbs live in mappings; these lessons teach how the pieces behave inside a sentence.

| Area | Focus |
|---|---|
| [Object and Particle Placement](phrasal-verbs/object-particle-placement/README.md) | Where noun and pronoun objects can appear with separable phrasal verbs. |
| [Separable and Inseparable Phrasal Verbs](phrasal-verbs/separable-and-inseparable-phrasal-verbs/README.md) | Which combinations split, which remain together, and when a dictionary check is necessary. |

Use mapping examples to introduce a specific expression, then use this branch when the learner needs a general placement rule.
