# Verb System

The verb system organizes English around six reusable forms and the structures that select them.

| Area | Focus |
|---|---|
| [Verb Forms](verb-forms/README.md) | Full infinitive, base form, third-person present, **-ing**, past, and past participle. |
| [Fluency Drills](fluency-drills/README.md) | Rapid transformations among statements, questions, emphasis, and negation. |
| [Past and Past Participle Transformations](../../transformations/past-and-past-participle/README.md) | Complete regular and irregular three-form coverage organized by sound and memory family. |
| [Verb Patterns](verb-patterns/README.md) | Structures selected by particular verbs, including perception patterns. |

The verb system explains when structures select each form. The past and participle form inventories are preserved under transformations, and their overlap will be evaluated during the next dedicated collation pass.
