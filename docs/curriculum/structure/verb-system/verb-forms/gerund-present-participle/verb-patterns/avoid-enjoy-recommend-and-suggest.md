# **Avoid, Enjoy, Recommend**, and **Suggest** + **-ing**

These verbs select an **-ing** form when another action follows:

| Spanish | English |
|---|---|
| Evito hacerlo de noche. | I avoid doing it at night. |
| Disfruto haciéndolo con mis amigos. | I enjoy doing it with my friends. |
| Recomiendo hacerlo temprano. | I recommend doing it early. |
| Sugiero hacerlo mañana. | I suggest doing it tomorrow. |

Use:

**avoid/enjoy/recommend/suggest + verb-ing**

Do not use a full infinitive in these patterns:

- **I suggest doing it tomorrow.**
- Not: *I suggest to do it tomorrow.*
