# Adjective + Full Infinitive

Use **it + be + adjective + full infinitive** to evaluate an action.

**it + is + adjective + to + bare infinitive**

| Spanish | English |
|---|---|
| Es importante hacerlo. | It is important to do it. |
| Es necesario hacerlo. | It is necessary to do it. |
| Es posible hacerlo. | It is possible to do it. |
| Es difícil hacerlo. | It is difficult to do it. |
| Es fácil hacerlo. | It is easy to do it. |
| Es mejor hacerlo ahora. | It is better to do it now. |

English needs the grammatical subject **it** in this pattern:

- **It is important to do it.**
- Not: *Is important to do it.*

The action after the adjective uses the full infinitive:

- **important to do**
- Not: *important do*

This pattern connects an evaluation to the action being evaluated.
