# Irregular Verbs in the Past

Irregular verbs do not form the past by adding regular **-ed**. Learn their base and past forms together.

These lessons use small sound families to make the forms easier to remember.

The foundation includes the irregular past forms needed for the closed core-verb curriculum. The advanced curriculum contains the complete irregular-verb inventory.
