# **Was** and **Were**

**Was** and **were** are the past forms of **be**.

| Subject | Present | Past |
|---|---|---|
| I | **am** | **was** |
| he, she, it | **is** | **was** |
| you, we, they | **are** | **were** |

The same forms appear in several foundational constructions.
