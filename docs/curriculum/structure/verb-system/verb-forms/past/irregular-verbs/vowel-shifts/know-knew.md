# Vowel Shifts: **Know → Knew**

The vowel changes from **know** `/noʊ/` to **knew** `/nuː/`.

Use **knew** for both knowing information and knowing a person.

| Spanish | Base form | Past |
|---|---|---|
| saber algo, sabía algo | **know something** | **knew something** |
| conocer a alguien, conocía a alguien | **know somebody** | **knew somebody** |

**Sabía la respuesta porque conocía a la profesora.**<br>
I knew the answer because I knew the teacher.
