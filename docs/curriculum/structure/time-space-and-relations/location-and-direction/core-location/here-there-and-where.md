# **Here, There**, and **Where**

| Spanish | English |
|---|---|
| aquí / acá | here |
| allí / allá | there |
| ¿dónde? | where? |

| Spanish | English |
|---|---|
| Estoy aquí. | I am here. |
| La tienda está allí. | The store is there. |
| ¿Dónde está la oficina? | Where is the office? |
| Quiero saber dónde está la oficina. | I want to know where the office is. |

In a direct question, use **where + be + subject**: **Where is the office?**

In an embedded question, use statement order: **where the office is**, not *where is the office*.
