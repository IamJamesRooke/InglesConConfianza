# Minimal Place Vocabulary

These nouns support the location patterns without expanding the lesson into a large places list.

| Spanish | English |
|---|---|
| un lugar | a place |
| la casa / el hogar | home |
| la tienda | the store |
| la oficina | the office |
| el apartamento | the apartment |
| el cuarto / la habitación | the room |
| el baño | the bathroom |
| el parque | the park |
| el aeropuerto | the airport |
| el barrio | the neighborhood |
| la ciudad | the city |
| el país | the country |

Use the place nouns as replaceable slots:

- **at the office → at the store → at the airport**
- **in the room → in the apartment → in the city**
- **near the park → near the office → near the airport**
