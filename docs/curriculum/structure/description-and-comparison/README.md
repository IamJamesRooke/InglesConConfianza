# Description and Comparison

These lessons explain how English combines descriptions, comparisons, and degree words. The word-specific translations live under `/mappings`; these files preserve the rules for combining them.

| Area | Lesson |
|---|---|
| adjective position | [Adjective Position](adjective-position.md) |
| comparison grammar | [Comparisons](comparisons/README.md) |
| intensifiers | [Intensifiers](intensifiers/README.md) |

English adjectives do not change for grammatical gender or number: **a good book**, **a good idea**, and **two good books**.
