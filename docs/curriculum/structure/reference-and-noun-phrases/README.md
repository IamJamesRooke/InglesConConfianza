# Reference and Noun Phrases

These lessons teach how English identifies people and things, introduces or omits articles, points to referents, and expresses quantity. Word-specific translation choices remain in mappings; this branch owns reusable noun-phrase rules.

| Area | Lessons |
|---|---|
| articles | [Articles](articles/README.md), including [No Article](articles/no-article.md) |
| demonstratives | [These and Those Without One](demonstratives/these-and-those-without-one.md) |
| quantity | [Quantity](quantity/README.md) |

The branch is a reference collection, not a teaching sequence. Lessons may be introduced whenever a sentence requires the distinction.
