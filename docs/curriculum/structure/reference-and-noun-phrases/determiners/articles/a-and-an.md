# **A** and **An**

Use **a/an** with one singular countable noun when the listener does not yet know exactly which one.

| Spanish | English |
|---|---|
| un gato | a cat |
| una tienda | a store |
| un evento | an event |
| una oficina | an office |

Choose by the next **sound**, not simply the next letter:

- **a** before a consonant sound: **a cat, a university**
- **an** before a vowel sound: **an office, an hour**

The noun must be singular: **a cat**, not *a cats*.

English has no plural form of **a/an**. Spanish **unos/unas** normally becomes **some** or **a few**:

| Spanish | English |
|---|---|
| unos gatos | some cats / a few cats |
| unas tiendas | some stores / a few stores |
