# Numbers

Numbers belong in Foundations because they provide essential quantity and order vocabulary for dates, prices, addresses, measurements, and everyday instructions.

| Area | Core examples |
|---|---|
| small cardinal numbers | **one, two, twelve** |
| teens and tens | **thirteen, thirty, ninety** |
| large cardinal numbers | **one hundred, one thousand, one million** |
| special formats | **3.14, phone numbers** |
| ordinal numbers | **first, second, twentieth** |
| fractions | **half, a third, a quarter** |

Cardinal numbers answer **How many?** Ordinal numbers identify position in an ordered series.
