# **All, Every**, and **Each**

| Determiner | Noun pattern | Core viewpoint |
|---|---|---|
| all | all the cats / all cats | the complete group |
| every | every cat | all members seen as a complete set |
| each | each cat | members considered individually |

| Spanish | English |
|---|---|
| todos los gatos | all the cats |
| cada gato | every cat |
| cada gato | each cat |

Use a singular countable noun after **every** and **each**:

- **every cat**
- **each cat**
- Not: *every cats* or *each cats*

**All** can also introduce an uncountable noun: **all the time**.

The related pronouns are **everybody/everyone** for people and **everything** for things.
