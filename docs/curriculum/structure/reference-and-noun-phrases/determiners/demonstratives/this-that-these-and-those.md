# **This, That, These**, and **Those**

These determiners show number and relative distance.

| | Near | Far |
|---|---|---|
| singular | this cat | that cat |
| plural | these cats | those cats |

| Spanish | English |
|---|---|
| este gato / esta gata | this cat |
| ese gato / esa gata | that cat |
| estos gatos / estas gatas | these cats |
| esos gatos / esas gatas | those cats |

English forms do not change for grammatical gender.

Without a noun, the same words are demonstrative pronouns:

| Spanish | English |
|---|---|
| Esto es importante. | This is important. |
| Eso es importante. | That is important. |
