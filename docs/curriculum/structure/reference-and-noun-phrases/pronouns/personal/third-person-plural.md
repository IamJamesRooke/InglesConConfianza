# Third-Person Plural

> **they · them · their · theirs · themselves · each other**

| Spanish | English | |
|---|---|---|
| ellos, ellas | **they** | *Ellos lo hacen.*<br>They do it. |
| los, las | **them** | *Yo los veo.*<br>I see them. |
| les | **them** | *Yo les doy el libro.*<br>I give them the book. |
| para ellos, ellas | **for them** | *Es para ellos.*<br>It is for them. |
| con ellos, ellas | **with them** | *Yo lo hago con ellos.*<br>I do it with them. |
| se lo | **it to them** | *Yo se lo doy.*<br>I give it to them. |
| se los, se las | **them to them** | *Yo se los doy.*<br>I give them to them. |
| el libro de John y Paula | **John and Paula's book** | *Yo veo el libro de John y Paula.*<br>I see John and Paula's book. |
| su libro | **their book** | *Yo veo su libro.*<br>I see their book. |
| suyo, suya | **theirs** | *Es suyo.*<br>It is theirs. |
| ellos mismos, ellas mismas, sí mismos, sí mismas | **themselves** | *Ellos mismos lo hacen.*<br>They do it themselves. |
| se… el uno al otro | **each other** | *Ellos se ven el uno al otro.*<br>They see each other. |
