# Basic Time Units and Clock Time

## Units

| Spanish | English |
|---|---|
| un segundo | a second |
| un minuto | a minute |
| una hora | an hour |
| la hora | the time |
| tiempo | time |

**Time** can mean **tiempo**, but **the time** commonly means **la hora**:

| Spanish | English |
|---|---|
| Necesito más tiempo. | I need more time. |
| ¿Qué hora es? | What time is it? |

## Asking and saying the time

| Spanish | English |
|---|---|
| ¿Qué hora es? | What time is it? |
| Son las doce. | It's twelve o'clock. |
| Son las doce y treinta. | It's twelve thirty. |
| Es mediodía. | It's noon. |
| Es medianoche. | It's midnight. |
| La reunión es a las doce. | The meeting is at twelve. |

Use **at** before a clock time: **at 12:00**, **at six thirty**.
