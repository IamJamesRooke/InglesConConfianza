# Other Ways to Set a Condition

These connectors do not all mean the same thing.

| Connector | Spanish bridge | English example |
|---|---|---|
| **unless** | a menos que / si no | I will not sign unless I understand the terms. |
| **as long as** | siempre y cuando | You can stay as long as you lock the door. |
| **provided/providing that** | con tal de que / siempre que | We will sign today provided that everyone agrees. |
| **even if** | incluso si | Even if it rains, we will play. |
| **in case** | por si / como precaución | Take an umbrella in case it rains. |

## Important contrasts

**Unless** already contains the negative condition:

- **I won't sign unless I understand.**
- **I won't sign if I don't understand.**

**Even if** says the condition will not change the result. **In case** describes a precaution taken before something possibly happens:

- **Call me even if you solve the problem.**
- **Write down my number in case you need help.**
