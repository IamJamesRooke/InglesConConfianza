# Fluency Drill: **Has**

Use **has + past participle** with **he, she**, and **it** in the present perfect.

| Drill step | Spanish | English |
|---|---|---|
| embedded **if** clause | Quiero saber si él lo ha hecho. | I want to know if he has done it. |
| direct question | ¿Lo ha hecho? | Has he done it? |
| affirmative answer | Sí, lo ha hecho. | Yes, he has done it. |
| negative answer | No, no lo ha hecho. | No, he hasn't done it. |
| negative **why** question | ¿Por qué no lo ha hecho? | Why hasn't he done it? |
| embedded **why** clause | Quiero saber por qué no lo ha hecho. | I want to know why he hasn't done it. |

The direct question uses **has he**. The embedded clauses use statement order: **if he has** and **why he hasn't**.
