# Fluency Drill: **Had**

Use **had + past participle** with every subject in the past perfect.

| Drill step | Spanish | English |
|---|---|---|
| embedded **if** clause | Quiero saber si ellos lo habían hecho. | I want to know if they had done it. |
| direct question | ¿Lo habían hecho? | Had they done it? |
| affirmative answer | Sí, lo habían hecho. | Yes, they had done it. |
| negative answer | No, no lo habían hecho. | No, they hadn't done it. |
| negative **why** question | ¿Por qué no lo habían hecho? | Why hadn't they done it? |
| embedded **why** clause | Quiero saber por qué no lo habían hecho. | I want to know why they hadn't done it. |

The direct question uses **had they**. The embedded clauses use statement order: **if they had** and **why they hadn't**.
