# Fluency Drill: **Must**

Use **must + base verb** for a strong obligation. In the negative, **mustn't** means prohibition: the action is not allowed.

| Drill step | Spanish | English |
|---|---|---|
| embedded **if** clause | Quiero saber si lo debes hacer. | I want to know if you must do it. |
| direct question | ¿Lo debes hacer? | Must you do it? |
| affirmative answer | Sí, lo debo hacer. | Yes, I must do it. |
| negative answer | No, no debo hacerlo. | No, I mustn't do it. |
| negative **why** question | ¿Por qué no debes hacerlo? | Why mustn't you do it? |
| embedded **why** clause | Quiero saber por qué no debes hacerlo. | I want to know why you mustn't do it. |

**Mustn't** does not mean “no es necesario.” That meaning is **don't have to**.
