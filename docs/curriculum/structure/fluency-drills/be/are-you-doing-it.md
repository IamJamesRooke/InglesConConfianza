# Fluency Drill: **Are You Doing It?**

Use **are + verb-ing** for an action that **you** are doing now or around now.

| Drill step | Spanish | English |
|---|---|---|
| embedded **if** clause | Quiero saber si tú lo estás haciendo. | I want to know if you are doing it. |
| direct question | ¿Lo estás haciendo? | Are you doing it? |
| affirmative answer | Sí, lo estoy haciendo. | Yes, I'm doing it. |
| negative answer | No, no lo estoy haciendo. | No, I'm not doing it. |
| negative **why** question | ¿Por qué no lo estás haciendo? | Why aren't you doing it? |
| embedded **why** clause | Quiero saber por qué no lo estás haciendo. | I want to know why you aren't doing it. |

The direct question uses inversion: **are you**.

The embedded clauses use statement order: **if you are** and **why you aren't**.
