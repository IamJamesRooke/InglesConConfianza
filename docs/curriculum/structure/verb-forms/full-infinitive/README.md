# The Full Infinitive

The **full infinitive** is **to + bare infinitive**:

| Bare infinitive | Full infinitive |
|---|---|
| do | to do |
| make | to make |
| go | to go |

Use the full infinitive in these core patterns:

| Pattern | Example |
|---|---|
| handle verb + full infinitive | I want **to do** it. |
| another person + full infinitive | I want you **to do** it. |
| purpose | I am calling **to confirm** the meeting. |
| adjective connector | It is important **to do** it. |
| obligation with **have** | I have **to do** it. |
| permission in the passive | I am allowed **to do** it. |
| causing or persuading another person | I got Laura **to do** it. |

The lessons in this folder develop each pattern separately and contrast it with structures that select the bare infinitive or **-ing** form.
