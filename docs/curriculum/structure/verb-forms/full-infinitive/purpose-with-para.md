# Purpose: **Para Hacerlo → To Do It**

Use the full infinitive to express the purpose of an action.

| Spanish | English |
|---|---|
| para hacerlo | to do it |
| para confirmar la reunión | to confirm the meeting |
| para hablar con Laura | to speak with Laura |

| Spanish | English |
|---|---|
| Necesito tiempo para hacerlo. | I need time to do it. |
| Llamo para confirmar la reunión. | I am calling to confirm the meeting. |
| Voy a la oficina para hablar con Laura. | I am going to the office to speak with Laura. |

Use **in order to** when the purpose needs emphasis:

**Voy a llamar para confirmar la reunión.**<br>
I am going to call in order to confirm the meeting.

Do not use **for + base verb**:

- **to do it**
- Not: *for do it*

When **para que** introduces a different subject, English normally uses **so that**, not a full infinitive:

**Hablo despacio para que puedas entender.**<br>
I speak slowly so that you can understand.
