# Spanish Present **-e** → English Third-Person **-s**

When the Spanish third-person present ends in **-e**, the English third-person form also normally ends in the **-s** family.

| Spanish present | English base | English third-person present |
|---|---|---|
| corre | run | runs |
| dice | tell | tells |
| dice | say | says |
| decide | decide | decides |
| pide | ask for | asks for |
| pide | ask somebody to | asks somebody to |
| pide | order | orders |
| oye | hear | hears |
| lee | read | reads |
| escribe | write | writes |
| hace | make | makes |
| come | eat | eats |
| bebe | drink | drinks |
| tiene | have | has |
| elige | choose | chooses |
| quiere | want | wants |
| vive | live | lives |
| vende | sell | sells |
| viene | come | comes |
| va | go | goes |
| vuelve | return | returns |
| vuelve | come back | comes back |
| vuelve | go back | goes back |
| conduce | drive | drives |
| sale | leave | leaves |
| abre | open | opens |
| conoce | know a person | knows a person |
| conoce | meet | meets |
| ve | see | sees |
| recibe | receive | receives |
| obtiene | obtain | obtains |
| obtiene | get | gets |
| trae | bring | brings |
| pone | put | puts |
| siente | feel | feels |

| entiende | get an idea | gets an idea |
| cree | believe | believes |

The forms **has, goes**, and **says** belong to the foundational exception group and are practiced separately.
