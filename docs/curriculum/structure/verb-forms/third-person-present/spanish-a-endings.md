# Spanish Present **-a** → English Third-Person **-s**

When the Spanish third-person present ends in **-a**, the English third-person form normally ends in the **-s** family.

| Spanish present | English base | English third-person present |
|---|---|---|

| habla | talk | talks |
| repara | repair | repairs |

| funciona | function | functions |
| estudia | study | studies |

The Spanish ending is the signal; the English ending still follows English spelling:

- **study → studies**
- **try → tries**
- **finish → finishes**
