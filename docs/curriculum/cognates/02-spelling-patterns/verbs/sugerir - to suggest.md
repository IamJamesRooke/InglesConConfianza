# Verb Cognates: **-gest**

In these cognates, Spanish verbs ending in **-gerir** correspond to English verbs ending in **-gest**.

| Spanish | English | Example |
|---|---|---|
| sugerir | **to suggest** | **Te sugiero reservar el hotel con anticipación.**<br>I suggest booking the hotel in advance. |
| digerir | **to digest** | **El cuerpo necesita tiempo para digerir la comida.**<br>The body needs time to digest food. |
| ingerir | **to ingest** | **No debes ingerir este medicamento con alcohol.**<br>You should not ingest this medication with alcohol. |
