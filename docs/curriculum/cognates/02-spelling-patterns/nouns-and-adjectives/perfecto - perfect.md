# Cognates: **-ecto → -ect**

In these cognates, remove the final **-o** from Spanish **-ecto** to find English **-ect**.

| Spanish | English | Example |
|---|---|---|
| perfecto | **perfect** | **Este lugar es perfecto para la reunión.**<br>This place is perfect for the meeting. |
| correcto | **correct** | **Marca la respuesta correcta en el formulario.**<br>Mark the correct answer on the form. |
| directo | **direct** | **Tomamos un vuelo directo de Bogotá a Madrid.**<br>We took a direct flight from Bogotá to Madrid. |
| objeto | **object** | **El museo exhibe un objeto de oro.**<br>The museum displays a gold object. |
| sujeto | **subject** | **Cada sujeto respondió las mismas preguntas.**<br>Each subject answered the same questions. |
| proyecto | **project** | **El proyecto termina a finales de agosto.**<br>The project ends in late August. |

| aspecto | **aspect** | **La seguridad es un aspecto esencial del diseño.**<br>Security is an essential aspect of the design. |

| arquitecto | **architect** | **El arquitecto presentó los planos del edificio.**<br>The architect presented the building plans. |
