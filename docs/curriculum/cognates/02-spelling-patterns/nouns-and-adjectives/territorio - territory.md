# Cognates: Spanish **-orio** and English **-ory**

In these cognates, Spanish **-orio** corresponds to English **-ory**. The stem may require an additional spelling change.

| Spanish | English | Example |
|---|---|---|
| territorio | **territory** | **La reserva protege un territorio extenso.**<br>The reserve protects an extensive territory. |
| laboratorio | **laboratory** | **El laboratorio analiza las muestras de agua.**<br>The laboratory analyzes the water samples. |
| directorio | **directory** | **El directorio contiene los datos de contacto del equipo.**<br>The directory contains the team's contact information. |
| obligatorio | **obligatory** | **El uso del casco es obligatorio en esta zona.**<br>Helmet use is obligatory in this area. |
| satisfactorio | **satisfactory** | **El proyecto produjo un resultado satisfactorio.**<br>The project produced a satisfactory result. |
| contradictorio | **contradictory** | **Los testigos dieron versiones contradictorias.**<br>The witnesses gave contradictory accounts. |
| preparatorio | **preparatory** | **El estudiante completó un curso preparatorio.**<br>The student completed a preparatory course. |
