# Verb Cognates: “Remove the **e**”

“Remove the **e**” is a memory aid for these shorter English cognates, not a complete letter-by-letter rule. It is especially visible when Spanish begins with **e** before **s** plus another consonant.

| Spanish | English | Example |
|---|---|---|
| estudiar | **to study** | **Valentina quiere estudiar medicina en Bogotá.**<br>Valentina wants to study medicine in Bogotá. |
| entrenar | **to train** | **El equipo va a entrenar todas las mañanas.**<br>The team is going to train every morning. |
| espiar | **to spy** | **El agente fue contratado para espiar a un funcionario extranjero.**<br>The agent was hired to spy on a foreign official. |
| escanear | **to scan** | **Debes escanear el documento y enviarlo por correo.**<br>You must scan the document and send it by email. |
