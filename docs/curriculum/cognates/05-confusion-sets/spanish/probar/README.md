# Translations of Spanish **Probar** and **Probarse**

Spanish **probar** and **probarse** map to trying, trying on, tasting, testing, proving, and demonstrating.

The basic testing or sampling pattern is **probar algo → to try something**.

| Lesson | Spanish | English |
|---|---|---|
| [**Probar → Try**](01-try-an-activity.md) | Prueba usar una contraseña diferente. | Try using a different password. |
| [**Probar → Try / Taste** Food](02-try-food.md) | Prueba esta sopa. | Try this soup. |
| [**Probarse → Try On**](03-try-on.md) | Me probé la chaqueta antes de comprarla. | I tried on the jacket before buying it. |
| [**Probar → Test**](04-test.md) | Tenemos que probar el sistema antes de lanzarlo. | We have to test the system before launching it. |
| [**Probar → Prove**](05-prove.md) | Los datos prueban que la teoría es correcta. | The data prove that the theory is correct. |
| [**Probar → Demonstrate / Show**](06-demonstrate.md) | El estudio probó la eficacia del tratamiento. | The study demonstrated the treatment's effectiveness. |
| [**Probar / Saber A → Taste Like**](07-taste-like.md) | La salsa sabe a ajo; pruébala. | The sauce tastes like garlic; taste it. |
| [**Probar → Try Out**](08-try-out.md) | Probamos la aplicación nueva durante una semana. | We tried out the new app for a week. |
