## Mastery Phrases

| Spanish | English |
|---|---|
| Esto me importa porque importa mucho para el proyecto. | I care about this because it matters a lot to the project. |
| ¿Te importa si cierro la puerta? No quiero molestarte, pero el ruido me molesta. | Do you mind if I close the door? I don't want to bother you, but the noise annoys me. |
| No me molesta esperar y no importa dónde, pero me importa Ana y no quiero molestarla. | I don't mind waiting, and it doesn't matter where, but I care about Ana and don't want to bother her. |
