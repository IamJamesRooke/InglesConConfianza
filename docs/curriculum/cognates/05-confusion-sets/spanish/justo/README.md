# Spanish **Justo**

| Spanish | English |
|---|---|
| La decisión fue justa. | The decision was fair. |
| Es un castigo justo. | It is a just punishment. |
| Llegaste justo a tiempo. | You arrived just in time. |
| Vive justo enfrente. | She lives right across the street. |

**Justo** can become **fair, just**, adverb **just/exactly**, or emphatic **right**.
