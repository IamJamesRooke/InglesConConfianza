# Spanish **Descubrir**

| Spanish | English |
|---|---|
| Descubrieron una nueva especie. | They discovered a new species. |
| Descubrí la verdad ayer. | I found out the truth yesterday. |
| Descubre la olla. | Uncover the pot. |
| La investigación descubrió el fraude. | The investigation exposed the fraud. |

**Descubrir** can become **discover, find out, uncover**, or **expose**.
