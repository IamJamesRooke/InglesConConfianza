# Spanish **Realizar**

| Spanish | English |
|---|---|
| Realizaron el proyecto a tiempo. | They carried out the project on time. |
| La artista realizó una presentación. | The artist gave a performance. |
| Realizó su sueño de estudiar medicina. | She fulfilled her dream of studying medicine. |

Spanish **realizar** usually means **carry out, perform**, or **fulfill**. English **realize** meaning become aware is **darse cuenta**.
