# Spanish **Pretender**

| Spanish | English |
|---|---|
| Pretendo terminar hoy. | I intend to finish today. |
| No pretendo ser un experto. | I am not claiming to be an expert. |
| La empresa pretende reducir costos. | The company aims to reduce costs. |
| Pretendía a la hija del alcalde. | He was courting the mayor's daughter. |

Spanish **pretender** usually means **intend, aim**, or **claim**, not English **pretend**, which is normally **fingir**.
