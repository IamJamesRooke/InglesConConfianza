# Translations of Spanish **Tan** and **Tanto**

| Lesson | Spanish | English |
|---|---|---|
| [so-adjective](01-so-adjective.md) | Es tan alto. | He's so tall. |
| [as-as](02-as-as.md) | Es tan alto como Ana. | He's as tall as Ana. |
| [such](03-such.md) | Fue un día tan difícil. | It was such a difficult day. |
| [so-much-many](04-so-much-many.md) | Tengo tanto trabajo y tantas reuniones. | I have so much work and so many meetings. |
| [as-much-many-as](05-as-much-many-as.md) | Trabaja tanto como yo. | She works as much as I do. |
| [meanwhile](06-meanwhile.md) | Mientras tanto, espera aquí. | Meanwhile, wait here. |
