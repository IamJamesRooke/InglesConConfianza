# Translations of Spanish **Poner** and **Ponerse**

Spanish **poner** and **ponerse** cover placement, settings, operation, clothing, beginning an action, and changes of state.

| Lesson | Spanish | English |
|---|---|---|
| [**Poner → Put / Place**](01-put-or-place.md) | Pon las llaves sobre la mesa. | Put the keys on the table. |
| [**Poner → Set**](02-set.md) | Pon la mesa y pon la alarma para las seis. | Set the table and set the alarm for six. |
| [**Poner → Turn On / Put On**](03-turn-on.md) | Pon la luz y pon la música. | Turn on the light and put on some music. |
| [**Ponerse A → Start Doing**](04-start-doing.md) | Se puso a trabajar después del almuerzo. | She started working after lunch. |
| [**Ponerse → Put On** Clothing](05-put-on-clothing.md) | Se puso la chaqueta antes de salir. | She put on her jacket before leaving. |
| [**Ponerse → Become / Get**](06-become.md) | Se puso triste cuando leyó el mensaje. | She became sad when she read the message. |
