# Translations of Spanish **Valer**

Spanish **valer** maps to worth, cost, validity, usefulness, agreement, advice, and worthwhile effort.

| Lesson | Spanish | English |
|---|---|---|
| [**Valer → Be Worth**](01-be-worth.md) | Este reloj vale mucho dinero. | This watch is worth a lot of money. |
| [**Valer → Cost**](02-cost.md) | ¿Cuánto vale la entrada? | How much does the ticket cost? |
| [**Valer → Be Valid**](03-be-valid.md) | Este documento vale hasta diciembre. | This document is valid until December. |
| [**Valer → Be Useful / Work**](04-be-useful.md) | Esta herramienta vale para cortar vidrio. | This tool is useful for cutting glass. |
| [**Vale → Okay / All Right**](05-okay-or-all-right.md) | Vale, nos vemos mañana. | Okay, see you tomorrow. |
| [**Más Vale → Had Better / Better**](06-mas-vale.md) | Más vale salir temprano. | We'd better leave early. |
| [**Valer La Pena → Be Worth It**](07-worth-it.md) | Vale la pena visitar el museo. | It's worth visiting the museum. |
| [**No Vale → It Doesn't Count / That's Not Fair**](08-not-count-or-matter.md) | Eso no vale; cambiaste las reglas. | That doesn't count; you changed the rules. |
