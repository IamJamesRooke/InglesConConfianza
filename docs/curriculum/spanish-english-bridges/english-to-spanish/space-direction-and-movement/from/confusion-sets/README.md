# Confusion Sets for **From**

| Lesson | Central Contrast |
|---|---|
| [**To, From**, and **For**](01-to-from-and-for.md) | Recipient, seller/source, and beneficiary |
| [**Since** vs **From**](02-since-vs-from.md) | Continuing period vs a neutral starting point |
| [**Of** vs **From**](03-of-vs-from.md) | Relationship/material vs origin/source |
| [**Away** vs **Away From**](04-away-vs-away-from.md) | No stated reference point vs explicit reference point |

| Spanish | English |
|---|---|
