# Location

This folder contains the reusable language needed to ask where something is, describe its position, and talk about movement between places.

| Area | Core example |
|---|---|
| general location | **Where is it? It's here.** |
| destination and origin | **to the office / from the office** |
| point, area, and surface | **at / in / on** |
| distance | **near / far from** |
| relative position | **next to / between / behind** |
| vertical position | **above / below** |
| basic directions | **left / right / straight ahead** |

The separate [minimal place vocabulary](../../core/everyday/places/minimal-place-vocabulary.md) remains deliberately limited. The focus here is the reusable location language around those nouns.
