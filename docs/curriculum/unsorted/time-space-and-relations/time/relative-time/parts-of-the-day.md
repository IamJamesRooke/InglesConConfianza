# Morning, Afternoon, Evening, and Night

## The parts of the day

| Spanish | English |
|---|---|
| la mañana | the morning |
| la tarde | the afternoon |
| la tarde / primeras horas de la noche | the evening |
| la noche | the night |

English distinguishes **evening**, the later part of the day when people are usually still active, from **night**, the darker or sleeping period. Spanish often uses **la noche** for both.

## Relative expressions

| Spanish | English |
|---|---|
| ayer por la mañana | yesterday morning |
| esta mañana | this morning |
| mañana por la mañana | tomorrow morning |
| ayer por la tarde | yesterday afternoon |
| esta tarde | this afternoon |
| mañana por la tarde | tomorrow afternoon |
| anoche | last night |
| esta noche | tonight |
| mañana por la noche | tomorrow night |

Do not add **in** before these expressions: **this morning**, not *in this morning*; **last night**, not *in last night*.

Use **in the morning**, **in the afternoon**, **in the evening**, but **at night** when speaking generally.
