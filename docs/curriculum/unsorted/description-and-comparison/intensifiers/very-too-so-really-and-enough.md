# **Very, Too, So, Really**, and **Enough**

Intensifiers change the degree of an adjective.

| Spanish | English | Core meaning |
|---|---|---|
| muy | very | high degree |
| realmente / muy | really | conversational emphasis |
| demasiado | too | more than wanted or acceptable |
| tan | so | strong degree, often with a result or reaction |
| lo suficientemente | enough | sufficient degree |

| Spanish | English |
|---|---|
| Es muy importante. | It is very important. |
| Es realmente difícil. | It is really difficult. |
| Es demasiado caro. | It is too expensive. |
| Es tan fácil. | It is so easy. |
| Es suficientemente bueno. | It is good enough. |

Word order changes with **enough**:

- **very good**
- **too expensive**
- **good enough**

**Too** does not simply mean **very**; it normally communicates a problem or excess.
