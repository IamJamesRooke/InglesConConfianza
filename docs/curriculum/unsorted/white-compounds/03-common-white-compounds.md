# Common Compounds with **White**

These are established combinations, not forms that can be generated mechanically.

| Expression | Spanish | English |
|---|---|---|
| **off-white** | Elegimos una pintura color blanco hueso. | We chose an off-white paint. |
| **whiteboard** | Escriba la respuesta en el tablero blanco. | Write the answer on the whiteboard. |
| **white-collar** | Tiene un trabajo de oficina. | She has a white-collar job. |
| **white lie** | Dijo una mentira piadosa para no arruinar la sorpresa. | He told a white lie so he wouldn't ruin the surprise. |
| **snow-white** | El mantel es blanco como la nieve. | The tablecloth is snow-white. |

**White-collar** is hyphenated before a noun. **Whiteboard** is one word, while **white lie** is two.
