# **If** and **Whether**

Spanish **si** without an accent can introduce a condition or an indirect yes/no question.

| Function | Spanish | English |
|---|---|---|
| condition | Si tengo tiempo, voy a hacerlo. | If I have time, I am going to do it. |
| indirect yes/no question | Quiero saber si tienes tiempo. | I want to know if you have time. |
| explicit alternatives | Quiero saber si vas o no. | I want to know whether you are going or not. |

In indirect questions, **if** and **whether** can often overlap. **Whether** is especially useful before **or not**.

Do not confuse **si** with accented **sí**, which means **yes**.
