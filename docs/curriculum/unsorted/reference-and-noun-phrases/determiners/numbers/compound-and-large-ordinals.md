# Compound and Large Ordinals

For a compound number, only the final part becomes ordinal:

| Number | Spanish | English |
|---|---|---|
| 20th | vigésimo | twentieth |
| 21st | vigésimo primero | twenty-first |
| 22nd | vigésimo segundo | twenty-second |
| 23rd | vigésimo tercero | twenty-third |
| 24th | vigésimo cuarto | twenty-fourth |
| 25th | vigésimo quinto | twenty-fifth |
| 28th | vigésimo octavo | twenty-eighth |
| 29th | vigésimo noveno | twenty-ninth |
| 30th | trigésimo | thirtieth |
| 31st | trigésimo primero | thirty-first |

Notice the spelling:

- **twenty-fourth**, not *twenty-forth*
- **twentieth**, not *twentyth*
- **thirtieth**, not *thirtyth*

Large round numbers also take an ordinal ending:

| Number | Spanish | English |
|---|---|---|
| 100th | centésimo | hundredth |
| 1,000th | milésimo | thousandth |
| 1,000,000th | millonésimo | millionth |

The written ending follows the final ordinal word: **21st, 22nd, 23rd**, but **11th, 12th**, and **13th** all use **-th**.
