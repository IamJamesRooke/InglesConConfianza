# Third-Person Singular: Masculine

> **he · him · his · himself**

| Role | Spanish | English | Basic Example |
|---|---|---|---|
| Subject | él | **he** | *Él lo hace.*<br>He does it. |
| Direct object | lo | **him** | *Yo lo veo.*<br>I see him. |
| Indirect object | le | **him** | *Yo le doy el libro.*<br>I give him the book. |
| After a preposition | para él | **for him** | *Es para él.*<br>It is for him. |
| After a preposition | con él | **with him** | *Yo lo hago con él.*<br>I do it with him. |
| Indirect + direct object | se lo | **it to him** | *Yo se lo doy.*<br>I give it to him. |
| Indirect + direct object | se los | **them to him** | *Yo se los doy.*<br>I give them to him. |
| Possession with a name | el libro de John | **John's book** | *Yo veo el libro de John.*<br>I see John's book. |
| Possessive determiner | su libro | **his book** | *Yo veo su libro.*<br>I see his book. |
| Possessive pronoun | suyo | **his** | *Es suyo.*<br>It is his. |
| Reflexive or emphatic | él mismo, sí mismo | **himself** | *Él mismo lo hace.*<br>He does it himself. |
