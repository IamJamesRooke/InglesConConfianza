# Third-Person Singular: Feminine

> **she · her · hers · herself**

| Spanish | English | |
|---|---|---|
| ella | **she** | *Ella lo hace.*<br>She does it. |
| la | **her** | *Yo la veo.*<br>I see her. |
| le | **her** | *Yo le doy el libro.*<br>I give her the book. |
| para ella | **for her** | *Es para ella.*<br>It is for her. |
| con ella | **with her** | *Yo lo hago con ella.*<br>I do it with her. |
| se lo | **it to her** | *Yo se lo doy.*<br>I give it to her. |
| se los | **them to her** | *Yo se los doy.*<br>I give them to her. |
| el libro de Paula | **Paula's book** | *Yo veo el libro de Paula.*<br>I see Paula's book. |
| su libro | **her book** | *Yo veo su libro.*<br>I see her book. |
| suyo | **hers** | *Es suyo.*<br>It is hers. |
| ella misma, sí misma | **herself** | *Ella misma lo hace.*<br>She does it herself. |
