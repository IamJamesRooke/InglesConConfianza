# Indefinite Pronouns: People

These pronouns refer to people without identifying exactly who they are.

## Core forms

| Spanish | English |
|---|---|
| **alguien** | somebody / someone |
| **todo el mundo** | everybody / everyone |
| **todos / todas** | everybody / everyone |
| **nadie** | nobody / no one |
| **cualquiera** | anybody / anyone |

## Somebody / Someone

**Alguien está en la casa.**  
Somebody is in the house. / Someone is in the house.

## Everybody / Everyone

**Todo el mundo está listo.**  
Everybody is ready. / Everyone is ready.

**Todos están listos.**  
Everybody is ready. / Everyone is ready.

- **Todo el mundo** uses a singular verb.
- **Todos / todas** uses a plural verb.

## Nobody / No one

**Nadie está en la casa.**  
Nobody is in the house. / No one is in the house.

## Anybody / Anyone in questions

Spanish normally uses **alguien** when asking whether a person exists:

**¿Hay alguien en la casa?**  
Is anybody in the house? / Is anyone in the house?

## Anybody / Anyone in negative sentences

Spanish uses **nadie**:

**No veo a nadie.**  
I do not see anybody. / I do not see anyone.

## Anybody / Anyone meaning “any person”

Use **cualquiera** when every person is a possible option:

**Cualquiera puede aprender inglés.**  
Anybody can learn English. / Anyone can learn English.

## The personal **a**

Use **a** when these pronouns are the direct object of a verb:

- **Veo a alguien.** — I see somebody.
- **No veo a nadie.** — I do not see anybody.
- **Conozco a todo el mundo.** — I know everybody.

## Negative word order

If **nadie** comes before the verb, do not use **no**:

**Nadie vino.**  
Nobody came.

If **nadie** comes after the verb, use **no**:

**No vino nadie.**  
Nobody came.

## Adding **else**

| Spanish | English |
|---|---|
| **alguien más** | somebody else / someone else |
| **nadie más** | nobody else / no one else |

**Necesitamos a alguien más.**  
We need somebody else.
