# Preserved Transformation Source Families

This folder preserves the original mixed `word-building` organization before its lessons were distributed into canonical prefix and suffix transformation maps.

The archive prevents information loss where one family, such as **weak → weakness → weaken → weakening**, spans several canonical suffix folders. It remains in the one shared curriculum-level `unsorted` bucket until the later cutting and deduplication pass.
