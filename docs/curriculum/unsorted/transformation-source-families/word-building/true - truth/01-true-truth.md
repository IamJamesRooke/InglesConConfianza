# **True → Truth**

| Form | Spanish | English |
|---|---|---|
| description: **true** | La historia es verdadera. | The story is true. |
| noun: **truth** | Finalmente, Laura dijo la verdad. | Laura finally told the truth. |

The spelling changes from **true** to **truth**: the final **e** disappears before **-th**.

English normally says **the truth** when referring to the true account of a situation.
