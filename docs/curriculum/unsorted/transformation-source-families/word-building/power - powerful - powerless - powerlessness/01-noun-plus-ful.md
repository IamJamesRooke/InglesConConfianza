# Noun + **-ful**

Add **-ful** to certain nouns to build a description meaning “having, showing, or producing the base thing or quality.”

| Base | Description | Spanish |
|---|---|---|
| **power** | **powerful** | poderoso |
| **color** | **colorful** | colorido |
| **use** | **useful** | útil |
| **pain** | **painful** | doloroso |
| **stress** | **stressful** | estresante |
| **meaning** | **meaningful** | significativo / con sentido |
| **success** | **successful** | exitoso |
| **care** | **careful** | cuidadoso |
| **beauty** | **beautiful** | bello / hermoso |
| **wonder** | **wonderful** | maravilloso |
| **hope** | **hopeful** | esperanzado |

| Spanish | English |
|---|---|
| Fue una experiencia dolorosa pero significativa, con un resultado exitoso. | It was a painful but meaningful experience with a successful outcome. |

The suffix is spelled with one **l**: **-ful**, not *-full*.
