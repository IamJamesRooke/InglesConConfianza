# The **Use** Family

| Form | Spanish | English |
|---|---|---|
| **use** | Esta herramienta tiene un uso claro. | This tool has a clear use. |
| **useful** | La herramienta nueva es útil. | The new tool is useful. |
| **useless** | La herramienta rota es inútil. | The broken tool is useless. |
| **usefulness** | Evaluamos su utilidad. | We evaluated its usefulness. |
| **uselessness** | Su inutilidad era evidente. | Its uselessness was obvious. |

**Useful** and **useless** are contrasting branches from **use**. Adding **-ness** names each resulting quality.

For the contextual uses, see [**Usefulness** and **Uselessness**](../../../../mappings/english-to-spanish/use/14-usefulness-and-uselessness.md).
