# **Inner, Outer, Upper**, and **Lower**

These words describe relative parts: **inner/outer** contrast distance from a center or interior, while **upper/lower** contrast vertical level or position.

## Core Pattern

| Direction or position | Relative part |
|---|---|
| **in / inside** | **inner** |
| **out / outside** | **outer** |
| **up / above** | **upper** |
| **down / below** | **lower** |

**Inner, outer, upper**, and **lower** normally describe a part relative to another part. They do not simply replace **inside, outside, up**, or **down**.
