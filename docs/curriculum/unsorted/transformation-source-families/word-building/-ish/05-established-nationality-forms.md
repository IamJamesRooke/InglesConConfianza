# Established Nationality and Language Forms

Some nationality and language words end in **-ish**, but they are established names—not informal approximations.

| Place or people | Description or language |
|---|---|
| **Britain** | **British** |
| **Ireland** | **Irish** |
| **Spain** | **Spanish** |
| **Poland** | **Polish** |
| **Turkey** | **Turkish** |
| **Sweden** | **Swedish** |
| **Denmark** | **Danish** |
| **Finland** | **Finnish** |

| Spanish | English |
|---|---|
| Ella es británica, habla español y está aprendiendo polaco. | She's British, speaks Spanish, and is learning Polish. |

Capitalize these forms. Do not use them as evidence that any place name can freely take **-ish**.
