# **White → Whitish**

The suffix **-ish** has five common jobs. Some are freely useful in informal English; others belong to established words that must be learned individually.

| Group | Core idea | Example |
|---|---|---|
| [Colors](01-white-to-whitish.md) | approximately or tending toward a color | **white → whitish** |
| [Time, Age, and Quantity](02-six-to-sixish.md) | approximately | **six → sixish** |
| [Degree and Informal Hedging](03-cold-to-coldish.md) | somewhat; not completely | **cold → coldish** |
| [Resemblance or Character](04-child-to-childish.md) | like or characteristic of the base | **child → childish** |
| [Nationalities and Languages](05-established-nationality-forms.md) | established identity words | **Britain → British** |
