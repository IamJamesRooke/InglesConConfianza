# **Strong → Strength → Strengthen**

| Form | Spanish | English |
|---|---|---|
| **strong** | La pared es fuerte. | The wall is strong. |
| **strength** | Medimos la resistencia de la pared. | We measured the wall's strength. |
| **strengthen** | Tenemos que reforzar la pared. | We need to strengthen the wall. |
| **strengthening** | El refuerzo tomó dos días. | The strengthening took two days. |
| **strengthened** | Inspeccionamos la pared reforzada. | We inspected the strengthened wall. |

The spelling reveals a real stem change: **strong → strength → strengthen**.

**Strengthener** is possible for something that strengthens, but ordinary English usually names the specific material, exercise, or cause.
