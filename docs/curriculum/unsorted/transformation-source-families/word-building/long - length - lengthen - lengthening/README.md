# **Long → Length → Lengthen → Lengthening**

Some families change their stem before adding **-en**. These are best learned as complete chains rather than as a mechanical suffix rule.

The **long** family is the concrete model for this transformation pattern.

| Family | Chain |
|---|---|
| [**Long**](01-long-length-lengthen.md) | **long → length → lengthen → lengthening / lengthened** |
| [**Strong**](02-strong-strength-strengthen.md) | **strong → strength → strengthen → strengthening / strengthened** |

## Mastery Phrase

| Spanish | English |
|---|---|
| Mida la longitud antes de alargar el cable y mida la resistencia antes de reforzar la pared. | Measure the length before lengthening the cable, and measure the strength before strengthening the wall. |

## Pattern Limit

The stem changes are not freely predictable. Learn **long/length/lengthen** and **strong/strength/strengthen** as complete families.
