# Description + **-ness**

Add **-ness** to many descriptions to name the quality, condition, or state.

| Description | Quality or state | Spanish |
|---|---|---|
| **happy** | **happiness** | felicidad |
| **good** | **goodness** | bondad |
| **dark** | **darkness** | oscuridad |
| **weak** | **weakness** | debilidad |
| **short** | **shortness** | brevedad / poca longitud |
| **useful** | **usefulness** | utilidad |
| **useless** | **uselessness** | inutilidad |
| **meaningless** | **meaninglessness** | falta de sentido |

| Spanish | English |
|---|---|
| La utilidad del informe no compensa la brevedad de su análisis. | The report's usefulness doesn't compensate for the shortness of its analysis. |

The natural Spanish translation depends on what the quality describes; English **shortness** does not normally translate as *cortedad*.
