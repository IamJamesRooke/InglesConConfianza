# **Thank You, Thanks**, and Responses

| Spanish | English | Use |
|---|---|---|
| gracias | thank you | neutral |
| gracias | thanks | more informal |
| con gusto / de nada | you're welcome | standard response |
| no hay problema | no problem | informal response |

| Spanish | English |
|---|---|
| Gracias por el café. | Thank you for the coffee. |
| Gracias. | Thanks. |
| De nada. | You're welcome. |

Write **you're welcome**, not *your welcome*. **You're** is the contraction of **you are**.
