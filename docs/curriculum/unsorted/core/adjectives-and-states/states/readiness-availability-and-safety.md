# Readiness, Availability, and Safety

| Spanish | English |
|---|---|
| estar ocupado | to be busy |
| estar seguro / a salvo | to be safe |
| estar seguro de algo | to be sure |
| estar listo | to be ready |
| estar dispuesto a | to be willing to |
| estar disponible | to be available |
| estar libre | to be free |

| Spanish | English |
|---|---|
| Estoy ocupado ahora. | I am busy now. |
| Laura está a salvo en casa. | Laura is safe at home. |
| Estoy seguro de que la reunión es hoy. | I am sure that the meeting is today. |
| Estoy listo para empezar. | I am ready to start. |
| Estoy dispuesto a hacerlo. | I am willing to do it. |
| Diana está disponible esta tarde. | Diana is available this afternoon. |
| Estoy libre después de la reunión. | I am free after the meeting. |

**Safe** means protected from danger. **Sure** means certain. Spanish **seguro** can express either meaning.
