# **So** and **Then**

Spanish uses several expressions that can look similar but connect ideas differently.

| Spanish | English | Function |
|---|---|---|
| así que | so | result |
| entonces | then / so | next step or conclusion |
| para que | so that | intended result |

| Spanish | English |
|---|---|
| No tengo tiempo, así que voy a hacerlo mañana. | I don't have time, so I am going to do it tomorrow. |
| Primero termino el informe; luego te llamo. | First I finish the report; then I call you. |
| Hablo despacio para que puedas entender. | I speak slowly so that you can understand. |

**So** introduces a result. **So that** introduces a purpose or intended result.
