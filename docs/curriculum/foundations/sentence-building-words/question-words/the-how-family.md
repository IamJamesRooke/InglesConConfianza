# The **How** Family

English combines **how** with different quantity and measurement words.

| Spanish | English |
|---|---|
| ¿cómo? | how? |
| ¿qué tan grande? / ¿cuán grande? | how big? |
| ¿cuánto? | how much? |
| ¿cuántos / cuántas? | how many? |
| ¿cuánto tiempo? | how long? |
| ¿cuánto tiempo? | how much time? |

| Spanish | English |
|---|---|
| ¿Cómo lo haces? | How do you do it? |
| ¿Qué tan grande es la oficina? | How big is the office? |
| ¿Cuánto tiempo necesitas? | How much time do you need? |
| ¿Cuántos libros necesitas? | How many books do you need? |
| ¿Cuánto tiempo has estado aquí? | How long have you been here? |

Use **how many** with countable plural nouns and **how much** with uncountable nouns. Use **how long** to ask about duration.
