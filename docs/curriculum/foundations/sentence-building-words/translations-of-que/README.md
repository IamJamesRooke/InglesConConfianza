# Translations of **Que**

Spanish **que** and accented **qué** have several foundational English equivalents.

| Spanish function | English | Example |
|---|---|---|
| question **qué** | what | ¿Qué quieres? → What do you want? |
| comparison **que** | than | mejor que → better than |
| idea connector **que** | that or no separate word | Creo que... → I think (that)... |
| relative **que**: person | who / that | la persona que... → the person who... |
| relative **que**: thing | that / which | el libro que... → the book that... |
| **lo que** | what | lo que necesito → what I need |
| **lo cual** | which | lo cual entiendo → which I understand |
| **para que** | so that | para que entiendas → so that you understand |
| exclamative **qué** | what / how | ¡Qué interesante! → How interesting! |
| verb structure | no separate word | quiero que Laura... → I want Laura to... |

The accent matters: interrogative or exclamative **qué** carries an accent; connector or relative **que** does not.
