# People: Somebody, Anybody, Nobody and Everybody

Learn this sequence as one complete pattern.

| Spanish | English |
|---|---|
| **Creo que hay alguien en la casa.** | I think somebody is in the house. |
| **¿Hay alguien en la casa?** | Is anybody in the house? |
| **Nadie está en la casa.** | Nobody is in the house. |
| **No hay nadie en la casa.** | There isn't anybody in the house. |
| **No creo que haya nadie en la casa.** | I don't think anybody is in the house. |
| **Cualquiera puede entrar en la casa.** | Anybody can enter the house. |
| **Todo el mundo está en la casa.** | Everybody is in the house. |

## Pattern

| Context | Spanish | English |
|---|---|---|
| Positive | **alguien** | somebody / someone |
| Question | **alguien** | anybody / anyone |
| Negative pronoun | **nadie** | nobody / no one |
| Negative sentence | **no...nadie** | not anybody / not anyone |
| Any possible person | **cualquiera** | anybody / anyone |
| All people | **todo el mundo** | everybody / everyone |
