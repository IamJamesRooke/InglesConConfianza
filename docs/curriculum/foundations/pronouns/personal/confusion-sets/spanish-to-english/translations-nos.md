# Translations of **nos**

**Nos** refers to a group that includes the speaker.

| Use | Spanish | English |
|---|---|---|
| Direct object | **Juan nos ve.** | Juan sees **us**. |
| Indirect object | **Juan nos da el libro.** | Juan gives the book **to us**. |
| Reflexive | **Nos vemos en el espejo.** | We see **ourselves** in the mirror. |
| Reciprocal | **Nos ayudamos.** | We help **each other**. |
| Combined with **lo** | **Juan nos lo da.** | Juan gives **it to us**. |

Context determines whether **nos** means **us**, **to us**, **ourselves**, or **each other**.
