# Third-Person Singular: Masculine

> **he · him · his · himself**

| Spanish | English | |
|---|---|---|
| él | **he** | *Él lo hace.*<br>He does it. |
| lo | **him** | *Yo lo veo.*<br>I see him. |
| le | **him** | *Yo le doy el libro.*<br>I give him the book. |
| para él | **for him** | *Es para él.*<br>It is for him. |
| con él | **with him** | *Yo lo hago con él.*<br>I do it with him. |
| se lo | **it to him** | *Yo se lo doy.*<br>I give it to him. |
| se los | **them to him** | *Yo se los doy.*<br>I give them to him. |
| el libro de John | **John's book** | *Yo veo el libro de John.*<br>I see John's book. |
| su libro | **his book** | *Yo veo su libro.*<br>I see his book. |
| suyo | **his** | *Es suyo.*<br>It is his. |
| él mismo, sí mismo | **himself** | *Él mismo lo hace.*<br>He does it himself. |
