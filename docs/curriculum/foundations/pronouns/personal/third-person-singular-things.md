# Third-Person Singular: Things

> **it · its · itself**

| Spanish | English | |
|---|---|---|
| ello, ella | **it** | *Ello es importante.*<br>It is important. |
| lo, la | **it** | *Yo lo veo.*<br>I see it. |
| le | **it** | *Yo le doy un nombre.*<br>I give it a name. |
| para ello | **for it** | *Es para ello.*<br>It is for it. |
| con ello | **with it** | *Yo lo hago con ello.*<br>I do it with it. |
| el nombre de la tienda | **the store's name** | *Yo veo el nombre de la tienda.*<br>I see the store's name. |
| su nombre | **its name** | *Yo veo su nombre.*<br>I see its name. |
| suyo | **its / belonging to it** | *Yo veo una parte suya.*<br>I see one of its parts. |
| sí mismo | **itself** | *Lo hace por sí mismo.*<br>It does it by itself. |
