# **More, Fewer**, and **Less**

| Meaning | Countable | Uncountable |
|---|---|---|
| greater quantity | more cars | more traffic |
| smaller quantity | fewer cars | less traffic |

| Spanish | English |
|---|---|
| Necesitamos más carros. | We need more cars. |
| Hay más tráfico hoy. | There is more traffic today. |
| Necesitamos menos carros. | We need fewer cars. |
| Hay menos tráfico hoy. | There is less traffic today. |

In careful standard usage, choose **fewer** for countable plurals and **less** for uncountable nouns.
