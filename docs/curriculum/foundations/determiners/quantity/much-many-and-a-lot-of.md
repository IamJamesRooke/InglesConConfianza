# **Much, Many**, and **A Lot Of**

| Noun type | Quantity word | Example |
|---|---|---|
| countable plural | many | many cars |
| uncountable | much | much traffic |
| either type | a lot of / lots of | a lot of cars / a lot of traffic |

In everyday affirmative statements, **a lot of** is usually more natural than **much**:

- **There is a lot of traffic.**
- **There isn't much traffic.**
- **Is there much traffic?**

Use **many** naturally in affirmative, negative, and question forms:

- **There are many cars.**
- **There aren't many cars.**
