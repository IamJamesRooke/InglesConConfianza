# **Some, Any**, and **No**

These determiners work with plural countable nouns and uncountable nouns.

| Pattern | Countable | Uncountable |
|---|---|---|
| affirmative **some** | some cats | some traffic |
| question/negative **any** | any cats | any traffic |
| determiner **no** | no cats | no traffic |

| Spanish | English |
|---|---|
| Tengo algunos libros. | I have some books. |
| ¿Tienes algunos libros? | Do you have any books? |
| No tengo ningún libro. | I don't have any books. |
| No tengo libros. | I have no books. |

Use either **not ... any** or **no**, but do not combine them:

- **I don't have any books.**
- **I have no books.**
- Not: *I don't have no books.*

**Any** can also mean **cualquier** in an unrestricted affirmative:

**Puedes elegir cualquier libro.**<br>
You can choose any book.

## Related families

The same opening words build related expressions:

| Family | **some** | **any** | **no** | **every** |
|---|---|---|---|---|
| place | [somewhere](places.md) | [anywhere](places.md) | [nowhere](places.md) | [everywhere](places.md) |
| time | [sometime](time.md) | [anytime](time.md) | [no time](time.md) | [every time](time.md) |

These related words do not determine a following noun, but the shared family makes their meanings and question/negative patterns easier to remember.
