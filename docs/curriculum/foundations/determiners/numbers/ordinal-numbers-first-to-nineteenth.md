# Ordinal Numbers: First to Nineteenth

Cardinal numbers express quantity; ordinal numbers express position.

| Number | Spanish | English |

| 11th | undécimo | eleventh |
| 12th | duodécimo | twelfth |

| 14th | decimocuarto | fourteenth |
| 15th | decimoquinto | fifteenth |
| 16th | decimosexto | sixteenth |
| 17th | decimoséptimo | seventeenth |
| 18th | decimoctavo | eighteenth |
| 19th | decimonoveno | nineteenth |

| Spanish | English |
|---|---|
| Laura fue la primera persona en llegar. | Laura was the first person to arrive. |
| La oficina está en el octavo piso. | The office is on the eighth floor. |

Most written ordinals end in **-th**, but **first, second**, and **third** are irregular.
