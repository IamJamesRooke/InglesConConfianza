# **The**

Use **the** when the listener can identify which person, thing, or group you mean.

| Spanish | English |
|---|---|
| el gato | the cat |
| la tienda | the store |
| los gatos | the cats |
| las tiendas | the stores |

English **the** does not change for gender or number.

| Spanish | English |
|---|---|
| Quiero un libro. El libro está en la tienda. | I want a book. The book is at the store. |

The first mention introduces **a book**. The second uses **the book** because it is now identifiable.
