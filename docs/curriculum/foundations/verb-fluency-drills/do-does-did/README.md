# Fluency Drills: **Do**, **Does**, and **Did**

Use **do** and **does** to build present questions and negations. Use **did** for the past.

| Subject or time | Auxiliary | Main verb |
|---|---|---|
| I, you, we, they — present | **do** | base form |
| he, she, it — present | **does** | base form |
| any subject — past | **did** | base form |

The tense or third-person marker moves to the auxiliary:

- **He does it. → Does he do it?**
- **They did it. → Did they do it?**

After **does** or **did**, use the base form **do**:

- **Does he do it?**
- **Did they do it?**
- Not: *Does he does it?*
- Not: *Did they did it?*

The first **do/does/did** can be an auxiliary while the second **do** is the main verb.
