# Regular Past Participle Pronounced `/d/`

When the form does not end in **-ted** or **-ded**, the written **e** is silent. The participles in this lesson finish with the sound `/d/`.

## Core forms

| Spanish | English | Pronunciation bridge |
|---|---|---|
| estudiado | **studied** | study + `/d/` |
| intentado, tratado, probado | **tried** | try + `/d/` |
| llamado | **called** | call + `/d/` |
| escuchado | **listened to** | listen + `/d/` |
| explicado | **explained** | explain + `/d/` |
| recordado | **remembered** | remember + `/d/` |
| llegado | **arrived** | arrive + `/d/` |
| vivido | **lived** | live + `/d/` |
| quedado | **stayed** | stay + `/d/` |
| mostrado | **showed** | show + `/d/` |
| creído | **believed** | believe + `/d/` |
| cerrado | **closed** | close + `/d/` |
| funcionado | **functioned** | function + `/d/` |
| obtenido | **obtained** | obtain + `/d/` |
| abierto | **opened** | open + `/d/` |
| pedido en un restaurante | **ordered** | order + `/d/` |
| recibido | **received** | receive + `/d/` |

**He estudiado la explicación y he tratado de recordarla.**<br>
I have studied the explanation and tried to remember it.

**La aplicación ha sido abierta y el mensaje ha sido recibido.**<br>
The application has been opened, and the message has been received.

There is no extra syllable in these endings.

## Similar sound families

- **studied, tried** end in written **-ied**, but the ending is still pronounced `/d/`.
- **listened, explained, obtained, opened** finish with `/nd/`.
- **arrived, lived, believed, received** finish with `/vd/`.
- **stayed** and **showed** attach `/d/` directly to their final vowel sounds.
