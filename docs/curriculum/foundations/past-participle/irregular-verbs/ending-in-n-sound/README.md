# Irregular Past Participles Ending in `/n/`

Every participle in this group finishes with the sound `/n/`, even though the spelling patterns differ.

The source idea “present form + N” is a useful memory bridge for forms such as **know → known** and **show → shown**. It is not a universal spelling rule: **done, taken**, and **written** also change inside the word.

Learn the forms in small sound and spelling families.
