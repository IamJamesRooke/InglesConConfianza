# Days Around Today

| Spanish | English |
|---|---|
| día | day |
| hoy | today |
| mañana | tomorrow |
| pasado mañana | the day after tomorrow |
| ayer | yesterday |
| anteayer | the day before yesterday |

| Spanish | English |
|---|---|
| Tengo que terminarlo hoy. | I have to finish it today. |
| La reunión es mañana. | The meeting is tomorrow. |
| Lo preparé ayer. | I prepared it yesterday. |

Spanish **mañana** can mean either **tomorrow** or **morning**. English always distinguishes them.
