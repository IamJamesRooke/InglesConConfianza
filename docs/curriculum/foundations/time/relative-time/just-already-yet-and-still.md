# **Just, Already, Yet**, and **Still**

These words locate an action relative to what someone expected.

| Spanish | English | Core use |
|---|---|---|
| acabar de hacer algo | to have just done something | a very recent action |
| ya | already | sooner than expected or completed by now |
| todavía no / aún no | not yet | expected, but not completed |
| todavía / aún | still | continuing now |

| Spanish | English |
|---|---|
| Acabo de terminarlo. | I have just finished it. |
| Ya lo he terminado. | I have already finished it. |
| Todavía no lo he terminado. | I haven't finished it yet. |
| Todavía lo estoy haciendo. | I am still doing it. |

In these foundational patterns, **already** and **still** normally go before the main verb, while **yet** normally goes at the end.
