# Days of the Week

| Spanish | English |
|---|---|
| lunes | Monday |
| martes | Tuesday |
| miércoles | Wednesday |
| jueves | Thursday |
| viernes | Friday |
| sábado | Saturday |
| domingo | Sunday |

English days begin with a capital letter. Use **on** with a day:

| Spanish | English |
|---|---|
| La reunión es el lunes. | The meeting is on Monday. |
| Trabajo los lunes. | I work on Mondays. |
| Te llamé el lunes pasado. | I called you last Monday. |
| Voy a llamarte el próximo lunes. | I am going to call you next Monday. |

Do not add **on** before **last** or **next**: **last Monday**, not *on last Monday*.

## Memory bridges in the English names

The English names preserve old names for the sun, moon, planets, and Germanic or Norse gods:

| Day | Memory bridge |
|---|---|
| Sunday | sun day |
| Monday | moon day |
| Tuesday | Tiw's day |
| Wednesday | Woden's day |
| Thursday | Thor's day |
| Friday | Frigg's or Freya's day |
| Saturday | Saturn's day |

These origins are memory aids, not modern definitions of the days.
