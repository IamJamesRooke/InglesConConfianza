# Vowel-Shift Pasts

In this course, **vowel-shift pasts** are irregular verbs whose main vowel changes in the past.

Listen to the forms. Verbs can share a past-vowel pattern even when their spelling does not match:

- **come → came**
- **eat → ate**
- **give → gave**

The three past forms share the vowel sound `/eɪ/`.

These are memory families, not rules for predicting every irregular past form.
