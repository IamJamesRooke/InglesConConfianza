# Irregular Past: **Send → Sent** and **Spend → Spent**

Learn these similar changes together:

- **send → sent**
- **spend → spent**

Both past forms end in the sound `/ɛnt/`.

| Spanish | Base form | Past |
|---|---|---|
| enviar, envió | **send** | **sent** |
| gastar dinero, gastó dinero | **spend money** | **spent money** |
| pasar tiempo, pasó tiempo | **spend time** | **spent time** |

**Envié el documento y pasé tiempo con el equipo.**<br>
I sent the document and spent time with the team.
