# Cognates: **-ico → -ic**

In these cognates, Spanish **-ico** corresponds to English **-ic**. English spelling may require an additional adjustment.

| Spanish | English | Example |
|---|---|---|
| tráfico | **traffic** | **El tráfico es más pesado durante la hora pico.**<br>Traffic is heavier during rush hour. |
| básico | **basic** | **El curso comienza con vocabulario básico.**<br>The course begins with basic vocabulary. |
| público | **public** | **La biblioteca está abierta al público.**<br>The library is open to the public. |
| específico | **specific** | **Necesitamos un ejemplo específico para explicar la regla.**<br>We need a specific example to explain the rule. |
| exótico | **exotic** | **El jardín tiene varias plantas exóticas.**<br>The garden has several exotic plants. |
| orgánico | **organic** | **La tienda vende café orgánico de Colombia.**<br>The store sells organic coffee from Colombia. |
| científico | **scientific** | **El informe presenta evidencia científica.**<br>The report presents scientific evidence. |
