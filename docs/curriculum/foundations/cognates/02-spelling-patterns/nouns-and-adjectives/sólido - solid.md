# Cognates: **-ido → -id**

In these cognates, remove the final **-o** from Spanish **-ido** to find English **-id**.

| Spanish | English | Example |
|---|---|---|
| sólido | **solid** | **El hielo es agua en estado sólido.**<br>Ice is water in a solid state. |
| líquido | **liquid** | **El recipiente contiene un líquido transparente.**<br>The container holds a transparent liquid. |
| fluido | **fluid** | **El médico tomó una muestra del fluido.**<br>The doctor took a sample of the fluid. |
| válido | **valid** | **Tu pasaporte debe ser válido durante todo el viaje.**<br>Your passport must be valid throughout the trip. |
| vívido | **vivid** | **Conservo un recuerdo vívido de aquella tarde.**<br>I retain a vivid memory of that afternoon. |
| estúpido | **stupid** | **Fue un error estúpido que pudimos evitar.**<br>It was a stupid mistake that we could have avoided. |
