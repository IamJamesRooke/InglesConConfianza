# Verb Cognates: **-ease**

These English verbs share the ending **-ease**. Their Spanish cognates do not follow one single ending, so learn each pair through the shared English pattern.

| Spanish | English | Example |
|---|---|---|
| incrementar | **to increase** | **La empresa quiere incrementar sus ventas este año.**<br>The company wants to increase its sales this year. |
| decrementar | **to decrease** | **El sistema decrementa el valor en una unidad cada minuto.**<br>The system decreases the value by one unit every minute. |
| liberar | **to release** | **Las autoridades decidieron liberar al detenido esa mañana.**<br>The authorities decided to release the detainee that morning. |
