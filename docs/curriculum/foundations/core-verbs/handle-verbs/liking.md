# Handle Verbs: Liking

## Liking something

| Spanish | English |
|---|---|
| gustar algo | **to like something** |

**Me gusta esta canción.**<br>
I like this song.

## Liking an action

Use **like + full infinitive** when the thing you like is an action.

| Spanish | English |
|---|---|
| gustar hacer algo | **to like to do something** |

**Me gusta practicar inglés con mis amigos.**<br>
I like to practice English with my friends.

## Saying what you would like

| Spanish | English |
|---|---|
| gustaría hacer algo, quisiera hacer algo | **would like to do something** |

**Me gustaría reservar una mesa para esta noche.**<br>
I would like to reserve a table for tonight.
