# Communication Verbs: Asking a Question

Use **ask** to request information.

| Spanish | English |
|---|---|
| preguntar | **to ask** |
| hacer una pregunta | **to ask a question** |

**Le hago una pregunta a la profesora sobre la tarea.**<br>
I ask the teacher a question about the homework.

English uses **ask a question**, not *make a question*.
