# Conversation and Basic Nouns

| Spanish | English |
|---|---|
| una cosa | a thing |
| un lugar | a place |
| una pregunta | a question |
| una respuesta | an answer |
| una película | a movie |
| un libro | a book |
| una llave | a key |
| una mesa | a table |
| una casa | a house |
| una reservación / una reserva | a reservation |

| Spanish | English |
|---|---|
| Tengo una pregunta. | I have a question. |
| Sé la respuesta. | I know the answer. |
| Necesito una reservación para esta noche. | I need a reservation for tonight. |
| La llave está sobre la mesa. | The key is on the table. |

These nouns act as replaceable slots in the foundational sentence patterns.
