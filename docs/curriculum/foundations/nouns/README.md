# Nouns

This folder contains a deliberately small noun vocabulary. Its purpose is to make grammar, verb, location, and conversation examples concrete—not to teach large themed word lists.

| Area | Core examples |
|---|---|
| general conversation | **thing, place, question, answer** |
| everyday objects | **book, key, table** |
| situations and ideas | **problem, opinion, difference** |
| money and business | **money, price, cost, company** |
| people and family | **person, friend, child, family** |
| language and identity | **English, Spanish, nationality** |

Most additional nouns can be acquired through cognates and context. The focused lessons here preserve only high-reuse vocabulary and contrasts that benefit from explicit instruction.
