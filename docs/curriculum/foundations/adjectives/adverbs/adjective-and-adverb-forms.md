# Adjective and Adverb Forms

An adjective describes a noun or subject. An adverb describes how an action happens.

| Adjective | Adverb | Spanish |
|---|---|---|
| slow | slowly | lento / despacio |
| logical | logically | lógico / lógicamente |
| practical | practically | práctico / prácticamente |
| good | well | bueno / bien |
| fast | fast | rápido / rápidamente |
| hard | hard | duro / con esfuerzo |

| Spanish | English |
|---|---|
| El carro es lento. | The car is slow. |
| El carro va despacio. | The car goes slowly. |
| Es una buena decisión. | It is a good decision. |
| Laura trabaja bien. | Laura works well. |
| Es un carro rápido. | It is a fast car. |
| El carro va rápido. | The car goes fast. |

Many adverbs use **-ly**, but **well, fast**, and **hard** are essential exceptions.
