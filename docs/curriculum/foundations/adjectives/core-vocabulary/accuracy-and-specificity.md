# Accuracy and Specificity

| Spanish | English |
|---|---|
| correcto | correct / right |
| incorrecto | incorrect / wrong |
| exacto | exact |
| específico | specific |
| especial | special |

| Spanish | English |
|---|---|
| Tu respuesta es correcta. | Your answer is correct. |
| Ese número está equivocado. | That number is wrong. |
| Necesito la hora exacta. | I need the exact time. |
| Laura dio una razón específica. | Laura gave a specific reason. |
| Esta ocasión es especial para nuestra familia. | This occasion is special for our family. |

**Specific** means clearly identified or precise. **Special** means unusual, important, or personally meaningful. Spanish **especial** normally maps to **special**, not **specific**.
