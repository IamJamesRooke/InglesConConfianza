# Possibility, Importance, and Difference

| Spanish | English |
|---|---|
| ser posible | to be possible |
| ser capaz de | to be able to |
| importante | important |
| necesario | necessary |
| diferente | different |
| parecido / similar | similar |
| el mismo / la misma | the same |

| Spanish | English |
|---|---|
| Es posible terminar hoy. | It is possible to finish today. |
| Puedo hacerlo. / Soy capaz de hacerlo. | I am able to do it. |
| Esta reunión es importante y necesaria. | This meeting is important and necessary. |
| Este libro es diferente de ese. | This book is different from that one. |
| Los dos libros son similares. | The two books are similar. |
| Necesitamos el mismo libro. | We need the same book. |

Use **the same**, not simply *same*, before a noun in this pattern.
