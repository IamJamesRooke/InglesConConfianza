# Irregular Comparisons

These common adjectives do not follow the normal **-er/-est** pattern.

| Base | Comparative | Superlative |
|---|---|---|
| good | better | the best |
| bad | worse | the worst |
| far | farther / further | the farthest / the furthest |

| Spanish | English |
|---|---|
| Esta opción es mejor que esa. | This option is better than that one. |
| Esta opción es peor que esa. | This option is worse than that one. |
| Esta es la mejor opción. | This is the best option. |

Do not use *gooder* or *badder* for these comparisons.
