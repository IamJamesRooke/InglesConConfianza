# Word Building: English **-ity**

English often changes an adjective ending to **-ity** to form a noun describing its quality or state.

| Adjective | **-ity** noun | Spanish |
|---|---|---|
| possible | **possibility** | posibilidad |
| active | **activity** | actividad |
| secure | **security** | seguridad |
| responsible | **responsibility** | responsabilidad |
| curious | **curiosity** | curiosidad |

| Spanish | English |
|---|---|
| **Existe la posibilidad de que llueva esta tarde.** | There is a **possibility** that it will rain this afternoon. |
| **La seguridad del sistema es nuestra responsabilidad.** | System **security** is our **responsibility**. |
| **La curiosidad llevó al niño a hacer otra pregunta.** | **Curiosity** led the child to ask another question. |
