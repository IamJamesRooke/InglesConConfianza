# Word Building: English **-ful** and **-less**

Add **-ful** to express having a quality and **-less** to express lacking it. The two suffixes often build a useful contrast from one base word.

| Base word | With **-ful** | With **-less** |
|---|---|---|
| care | **careful** — cuidadoso | **careless** — descuidado |
| help | **helpful** — útil, servicial | **helpless** — indefenso, incapaz de actuar |
| hope | **hopeful** — esperanzado | **hopeless** — sin esperanza |
| use | **useful** — útil | **useless** — inútil |

| Spanish | English |
|---|---|
| **Ten cuidado al cruzar esta avenida.** | Be **careful** when crossing this avenue. |
| **Un error por descuido borró todo el archivo.** | A **careless** mistake deleted the entire file. |
| **Esta guía es útil, pero el mapa viejo es inútil.** | This guide is **useful**, but the old map is **useless**. |

## Additional Examples

| Base word | With **-ful** | With **-less** |
|---|---|---|
| power | **powerful** — poderoso | **powerless** — impotente, sin poder |
| harm | **harmful** — dañino | **harmless** — inofensivo |
| thought | **thoughtful** — considerado | **thoughtless** — desconsiderado |
