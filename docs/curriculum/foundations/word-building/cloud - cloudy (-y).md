# Word Building: English **-y**

Add **-y** to many nouns to form an adjective meaning “having” or “characterized by” that noun.

| Noun | **-y** adjective | Spanish |
|---|---|---|
| cloud | **cloudy** | nublado |
| health | **healthy** | saludable |
| luck | **lucky** | afortunado |
| noise | **noisy** | ruidoso |
| rain | **rainy** | lluvioso |

| Spanish | English |
|---|---|
| **La mañana está nublada, pero no hace frío.** | The morning is **cloudy**, but it is not cold. |
| **El restaurante ofrece varias opciones saludables.** | The restaurant offers several **healthy** options. |
| **La avenida es muy ruidosa durante la hora pico.** | The avenue is very **noisy** during rush hour. |
