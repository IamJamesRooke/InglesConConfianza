# Fluency Drill: **Would**

Use **would + base verb** to talk about a hypothetical action.

| Drill step | Spanish | English |
|---|---|---|
| embedded **if** clause | Quiero saber si tú lo harías. | I want to know if you would do it. |
| direct question | ¿Lo harías? | Would you do it? |
| affirmative answer | Sí, lo haría. | Yes, I would do it. |
| negative answer | No, no lo haría. | No, I wouldn't do it. |
| negative **why** question | ¿Por qué no lo harías? | Why wouldn't you do it? |
| embedded **why** clause | Quiero saber por qué no lo harías. | I want to know why you wouldn't do it. |

The direct question uses **would you**. The embedded clauses use statement order: **if you would** and **why you wouldn't**.
