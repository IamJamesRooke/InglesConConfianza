# Perfect Forms

Perfect forms use a form of **have + past participle**.

| Form | Spanish | English |
|---|---|---|
| present | Lo he hecho. | I have done it. |
| past | Lo había hecho. | I had done it. |
| future | Lo habré hecho. | I will have done it. |
| conditional | Lo habría hecho. | I would have done it. |
| with **could** | Podría haberlo hecho. | I could have done it. |
| with **should** | Debería haberlo hecho. | I should have done it. |
