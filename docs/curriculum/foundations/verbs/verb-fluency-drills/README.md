# Verb Fluency Drills

These drills build rapid control of English statements, questions, emphatic answers, and negations.

English auxiliaries can change the word order and the form of the main verb:

- **Have you done it?**
- **Do you have to do it?**
- **Can you do it?**
- **Does she have it?**
- **Yes, she has it.**

Recognizing the vocabulary is not enough. Learners need to produce these transformations quickly and accurately in real conversation.

Each drill uses a coherent master sentence set. The meaning changes as little as possible so the learner can focus on structure.

## Drill Groups

- `do-does-did/`: simple-present and simple-past support
- `be/`: present and past continuous forms, plus **be going to**
- `modals/`: **will, would, can, could, must**, and **should**
- `perfect-auxiliaries/`: **have, has**, and **had** with a past participle
- `high-confusion-structures/`: the different jobs of **have**, **have to**, and existential **there + be**
- `form-comparisons/`: progressive, perfect, and perfect-progressive form families
