# Fluency Drill: **Were You Doing It?**

Use **were + verb-ing** for an action that **you** were doing at a past moment.

| Drill step | Spanish | English |
|---|---|---|
| embedded **if** clause | Quiero saber si tú lo estabas haciendo. | I want to know if you were doing it. |
| direct question | ¿Lo estabas haciendo? | Were you doing it? |
| affirmative answer | Sí, lo estaba haciendo. | Yes, I was doing it. |
| negative answer | No, no lo estaba haciendo. | No, I wasn't doing it. |
| negative **why** question | ¿Por qué no lo estabas haciendo? | Why weren't you doing it? |
| embedded **why** clause | Quiero saber por qué no lo estabas haciendo. | I want to know why you weren't doing it. |

The question addresses **you**, so it uses **were**. The answer changes perspective to **I**, so it uses **was**.

The embedded clauses use statement order: **if you were** and **why you weren't**.
