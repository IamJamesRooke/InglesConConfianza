# Fluency Drill: **Were You Going to Do It?**

Use **were going to + base verb** to ask **you** about a past plan or intention.

| Drill step | Spanish | English |
|---|---|---|
| embedded **if** clause | Quiero saber si tú lo ibas a hacer. | I want to know if you were going to do it. |
| direct question | ¿Lo ibas a hacer? | Were you going to do it? |
| affirmative answer | Sí, lo iba a hacer. | Yes, I was going to do it. |
| negative answer | No, no lo iba a hacer. | No, I wasn't going to do it. |
| negative **why** question | ¿Por qué no lo ibas a hacer? | Why weren't you going to do it? |
| embedded **why** clause | Quiero saber por qué no lo ibas a hacer. | I want to know why you weren't going to do it. |

The question addresses **you**, so it uses **were**. The answer changes perspective to **I**, so it uses **was**.

The embedded clauses use statement order: **if you were going to** and **why you weren't going to**.
