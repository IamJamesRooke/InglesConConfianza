# Fluency Drill: **Have**

Use **have + past participle** with **I, you, we**, and **they** in the present perfect.

| Drill step | Spanish | English |
|---|---|---|
| embedded **if** clause | Quiero saber si tú lo has hecho. | I want to know if you have done it. |
| direct question | ¿Lo has hecho? | Have you done it? |
| affirmative answer | Sí, lo he hecho. | Yes, I have done it. |
| negative answer | No, no lo he hecho. | No, I haven't done it. |
| negative **why** question | ¿Por qué no lo has hecho? | Why haven't you done it? |
| embedded **why** clause | Quiero saber por qué no lo has hecho. | I want to know why you haven't done it. |

The direct question uses **have you**. The embedded clauses use statement order: **if you have** and **why you haven't**.
