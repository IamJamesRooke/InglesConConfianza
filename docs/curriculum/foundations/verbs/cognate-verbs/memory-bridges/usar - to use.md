# Verb Cognates: **-use**

These Spanish and English cognates correspond to English verbs ending in **-use**.

| Spanish | English | Example |
|---|---|---|
| usar, utilizar | **to use** | **Puedes usar esta aplicación para practicar inglés.**<br>You can use this application to practice English. |
| excusar | **to excuse** | **La profesora decidió excusar la ausencia de Mateo.**<br>The teacher decided to excuse Mateo's absence. |
| acusar | **to accuse** | **Nadie debe acusar a otra persona sin pruebas.**<br>No one should accuse another person without evidence. |
| confundir | **to confuse** | **Las instrucciones contradictorias pueden confundir a los estudiantes.**<br>The contradictory instructions may confuse the students. |
| rehusar, rechazar | **to refuse** | **El cliente puede rehusar la oferta sin dar una explicación.**<br>The client may refuse the offer without giving an explanation. |
