# Cognate Verbs

This section gathers the verb lessons from the foundation cognate curriculum inside the larger verb curriculum.

The overlap is intentional:

- In `/foundations/cognates`, students encounter these verbs as a way to infer English vocabulary from Spanish.
- In `/foundations/verbs`, the same verbs become part of the usable verb inventory and can be combined with the six English verb forms.

Start with `selected-verbs.md` for the closed, high-frequency foundation inventory. Use the lesson folders when a cognate rule needs more examples, exceptions, or false-cognate contrasts.

The folders progress from the most reliable inference patterns to the least mechanical material:

| Folder | Focus |
|---|---|
| `direct` | forms found by removing the Spanish infinitive ending |
| `spelling-patterns` | visible, reusable spelling changes |
| `past-and-progressive` | cognate bridges for **-ed** and **-ing** forms |
| `word-families` | shared roots and prefixes |
| `memory-bridges` | useful associations that are not dependable spelling rules |
| `confusion-sets` | false cognates and context-dependent translations |

Teach the reliable pattern first, then its exceptions and false cognates.
