# The Past Participle

This section teaches the past-participle forms needed for the foundational core verbs.

For regular verbs, the simple past and past participle have the same form:

| Base form | Simple past | Past participle |
|---|---|---|
| work | **worked** | **worked** |
| like | **liked** | **liked** |
| need | **needed** | **needed** |

The form overlaps with the past curriculum, but the teaching purpose differs: the past lessons teach completed past actions, while these lessons identify the form used in several constructions:

| Construction | Example |
|---|---|
| perfect | I have **done** it. |
| passive with **be** | It was **done** by Laura. |
| event-focused passive with **get** | It got **done** on time. |
| arranged result | I got it **done** before Friday. |
