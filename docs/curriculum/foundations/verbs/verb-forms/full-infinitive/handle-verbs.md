# Handle Verbs + Full Infinitive

In this course, **handle verbs** are verbs that can be followed by another action. Use:

**subject + handle verb + to + bare infinitive**

| Spanish | English |
|---|---|
| Quiero hacerlo. | I want to do it. |
| Necesito hacerlo. | I need to do it. |
| Me gustaría hacerlo. | I would like to do it. |
| Decidí hacerlo. | I decided to do it. |
| Elegí hacerlo. | I chose to do it. |
| Intenté hacerlo. | I tried to do it. |
| Prefiero hacerlo temprano. | I prefer to do it early. |
| Ella comenzó a hacerlo. | She began to do it. |

The next verb uses the full infinitive:

- **I want to do it.**
- Not: *I want do it.*

## **Like**

**Like** can take either the full infinitive or an **-ing** form in foundational conversation:

| Full infinitive | Gerund |
|---|---|
| I like to do it. | I like doing it. |

Other lessons in this verb-forms folder distinguish verbs that select an infinitive, an **-ing** form, or either form.
