# The Full Infinitive

The **full infinitive** is **to + bare infinitive**:

| Bare infinitive | Full infinitive |
|---|---|
| do | to do |
| make | to make |
| go | to go |

The foundation course uses the full infinitive in four core patterns:

| Pattern | Example |
|---|---|
| handle verb + full infinitive | I want **to do** it. |
| another person + full infinitive | I want you **to do** it. |
| purpose | I am calling **to confirm** the meeting. |
| adjective connector | It is important **to do** it. |

This is a closed foundation inventory. More detailed infinitive meanings and verb-selection patterns belong in the advanced curriculum.
