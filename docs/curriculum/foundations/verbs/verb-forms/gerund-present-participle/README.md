# Gerunds and Present Participles

English uses the same **verb + -ing** form for several different jobs.

| Job | Structure | Example |
|---|---|---|
| present participle | **be + verb-ing** | I am doing it. |
| gerund naming an activity | **verb-ing + verb** | Doing it is difficult. |
| gerund after a preposition | **preposition + verb-ing** | before doing it |
| complement after selected verbs | **like + verb-ing** | I like doing it. |
| noun derived from a verb | **the + -ing noun** | the meeting |

The form is identical, but its role in the sentence changes.

The lessons in this folder develop these **-ing** jobs separately, including the verbs that select an **-ing** form and the contrast between infinitive **to** and prepositional **to**.
