# Gerund: An Activity as a Noun

An **-ing** form can name an activity and function as a noun.

| Spanish | English |
|---|---|
| Hacerlo es difícil. | Doing it is difficult. |
| Leer en inglés es práctico. | Reading in English is practical. |
| Esperar es difícil. | Waiting is difficult. |

The complete **-ing** phrase can be the subject of the sentence:

| Activity | Verb | Description |
|---|---|---|
| Doing it | is | difficult. |

Use **doing**, not *to doing*, in this subject pattern.
