# Forming the **-ing** Form

| Pattern | Base verb | **-ing** form |
|---|---|---|
| usually add **-ing** | do | doing |
| remove final silent **-e** | make | making |
| keep final **-ee** | see | seeing |
| double the final consonant in some short verbs | run | running |

The **-ing** form does not change with the subject:

| Spanish | English |
|---|---|
| estoy haciendo | I am doing |
| está haciendo | he is doing |
| estamos haciendo | we are doing |

Only the form of **be** changes. The cognate lessons for Spanish **-ando/-iendo** and English **-ing** contain additional spelling examples.
