# Spanish **Guardar**

| Spanish | English |
|---|---|
| Guarda las llaves aquí. | Keep the keys here. |
| Guarda el archivo. | Save the file. |
| Guarda la camisa en el armario. | Put the shirt away in the closet. |
| Guardó el secreto durante años. | She kept the secret for years. |
| Guardaron silencio. | They remained silent. |

**Guardar** can become **keep, save, put away**, or a complete expression such as **keep a secret** or **remain silent**.
