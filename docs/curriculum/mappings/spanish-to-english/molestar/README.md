# Translations of Spanish **Molestar**

Spanish **molestar** can become **mind**, **bother**, **disturb**, **annoy**, or **irritate** according to context.

| Lesson | Spanish | English |
|---|---|---|
| [mind](01-mind.md) | ¿Te molesta si abro la ventana? | Do you mind if I open the window? |
| [bother](02-bother.md) | Perdón por molestarte. | Sorry to bother you. |
| [disturb](03-disturb.md) | No molestes a Ana mientras trabaja. | Don't disturb Ana while she's working. |
| [annoy / irritate](04-annoy-and-irritate.md) | Ese ruido me molesta. | That noise annoys me. |
