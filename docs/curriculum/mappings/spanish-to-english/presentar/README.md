# Spanish **Presentar**

| Spanish | English |
|---|---|
| Presentó el informe ayer. | She presented the report yesterday. |
| Te presento a Laura. | Let me introduce you to Laura. |
| Presenté la solicitud en línea. | I submitted the application online. |
| Presenté el examen el lunes. | I took the exam on Monday. |
| El sistema presenta un problema. | The system has a problem. |

**Presentar** can become **present, introduce, submit, take** an exam, or **have/display** a characteristic or problem.
