# Spanish **Llamado**

| Spanish | English |
|---|---|
| Un hombre llamado Mateo vino. | A man named/called Mateo came. |
| El llamado experto no respondió. | The so-called expert did not answer. |
| Sentí un llamado a enseñar. | I felt a calling to teach. |
| Hicieron un llamado a la calma. | They called for calm. |

**Llamado** can become **called/named, so-called, calling**, or part of **call for**.
