# Spanish **Adelante**

| Spanish | English |
|---|---|
| Sigue adelante. | Keep going. |
| Mira hacia adelante. | Look ahead. |
| ¡Adelante! | Come in! / Go ahead! |
| De ahora en adelante, llama primero. | From now on, call first. |

**Adelante** can become **ahead, forward, keep going, come in, go ahead**, or part of **from now on**.
