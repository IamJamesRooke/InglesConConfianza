# **Volver A + Infinitive**

Spanish **volver a + infinitive** usually becomes **verb + again** in English. The English verb does not need a separate translation of **volver**.

| Lesson | Spanish | English |
|---|---|---|
| [again](01-again.md) | Volvió a llamar. | She called again. |
| [negative](02-negative.md) | No volvió a escribir. | He didn't write again. |
| [question](03-question.md) | ¿Vas a volver a intentarlo? | Are you going to try again? |
