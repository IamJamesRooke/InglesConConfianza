# Translations of Spanish **Volver** and **Volverse**

Spanish **volver** and **volverse** express return, repeated action, restoration, and changes of state.

| Lesson | Spanish | English |
|---|---|---|
| [**Volver → Return**](01-return.md) | Volví a Bogotá el lunes. | I returned to Bogotá on Monday. |
| [**Volver → Come / Go Back**](02-come-or-go-back.md) | Vuelve aquí y luego vuelve a casa. | Come back here, and then go back home. |
| [**Volver A → Do Again**](03-do-again.md) | Volvió a llamar esta mañana. | She called again this morning. |
| [**Volver A Poner / Devolver**](04-restore-or-put-back.md) | Vuelve a poner el libro en el estante. | Put the book back on the shelf. |
| [**Volverse → Become / Get**](05-become.md) | El problema se volvió difícil. | The problem became difficult. |
| [**Volverse / Convertirse → Turn Into**](06-turn-into.md) | El agua se volvió hielo. | The water turned into ice. |
| [**Volverse → Turn Around**](07-turn-around.md) | Se volvió para mirarme. | She turned around to look at me. |
