# Spanish **Devolver**

| Spanish | English |
|---|---|
| Devuelve el libro mañana. | Return the book tomorrow. |
| Te devuelvo las llaves esta tarde. | I will give your keys back this afternoon. |
| La tienda me devolvió el dinero. | The store refunded my money. |
| Laura me devolvió la llamada. | Laura returned my call. |

**Devolver** can mean **return, give back, refund**, or **return a call**, depending on what comes back.
