# Spanish **Dentro**

| Spanish | English |
|---|---|
| Está dentro de la caja. | It is inside the box. |
| Vuelve dentro de una hora. | Come back in an hour. |
| Debes responder dentro del plazo. | You must respond within the deadline. |
| Muy dentro de sí, sabía la verdad. | Deep down, she knew the truth. |

**Dentro** can become **inside, in, within**, or figurative **deep down**.
