# Spanish **Solo**

| Spanish | English |
|---|---|
| Vivo solo. | I live alone. |
| Solo necesito cinco minutos. | I only need five minutes. |
| Es un solo pago. | It is a single payment. |
| Lo hizo él solo. | He did it by himself. |

**Solo** can mean **alone, only, single**, or **by oneself**. Context—not the optional modern accent—determines the meaning.
