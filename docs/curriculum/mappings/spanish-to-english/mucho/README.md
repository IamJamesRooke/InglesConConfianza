# Translations of Spanish **Mucho**

Spanish **mucho** changes form with the noun when necessary: **mucho, mucha, muchos, muchas**. Depending on context, the family can become **much**, **many**, **a lot of**, **lots of**, **a lot**, or **plenty of**.

| Lesson | Spanish | English |
|---|---|---|
| [much](01-much.md) | No tengo mucho tiempo. | I don't have much time. |
| [many](02-many.md) | Hay muchos carros en la avenida. | There are many cars on the avenue. |
| [a lot of](03-a-lot-of.md) | Tomé muchas notas. | I took a lot of notes. |
| [lots of](04-lots-of.md) | Tenemos muchos libros. | We've got lots of books. |
| [a lot](05-a-lot.md) | Trabajo mucho entre semana. | I work a lot during the week. |
| [plenty of](06-plenty-of.md) | Tenemos mucho tiempo; no hay que apurarnos. | We have plenty of time; there's no need to rush. |
