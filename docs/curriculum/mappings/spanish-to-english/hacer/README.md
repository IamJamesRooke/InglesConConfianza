# Translations of Spanish **Hacer**

Beyond the core **do/make** contrast, Spanish **hacer** builds weather, elapsed-time, causative, effect, and fixed-expression structures that English reorganizes.

| Lesson | Spanish | English |
|---|---|---|
| [**Hacer → Do / Make**](01-do-and-make.md) | Hago la tarea y hago café. | I do the homework and make coffee. |
| [Weather with **Hacer**](02-weather.md) | Hace frío, pero hace sol. | It's cold, but it's sunny. |
| [**Hace + Time → Ago**](03-ago.md) | Llegué hace dos años. | I arrived two years ago. |
| [**Hace + Time + Que → For / Since**](04-for-and-since.md) | Hace dos años que vivo aquí. | I've lived here for two years. |
| [Time-relation contrast: **ago / in / for / since / until**](hace%20%2B%20tiempo%20%28time%20relations%29.md) | hace / en / durante / desde / hasta | ago / in / for / since / until |
| [**Hacer + Infinitive → Make**](05-causative-make.md) | La película me hizo llorar. | The movie made me cry. |
| [**Hacer Que Hagan Algo → Have It Done**](06-have-something-done.md) | Hice reparar el carro. | I had the car repaired. |
| [Effects and Fixed Combinations with **Hacer**](07-effect-and-fixed-combinations.md) | El ejercicio me hace bien. | Exercise is good for me. |
