# Spanish **Además**

| Spanish | English |
|---|---|
| Laura también viene y, además, trae café. | Laura is coming too, and she is also bringing coffee. |
| Además de inglés, habla francés. | Besides English, she speaks French. |
| Es caro; además, queda lejos. | It is expensive; moreover, it is far away. |

**Además** can become **also, besides, in addition**, or formal **moreover**.
