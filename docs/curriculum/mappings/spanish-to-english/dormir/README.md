# Spanish **Dormir**

| Spanish | English |
|---|---|
| Dormí ocho horas. | I slept for eight hours. |
| El bebé se durmió. | The baby fell asleep. |
| Dormí en casa de Laura. | I stayed overnight at Laura's house. |
| Dormí al bebé. | I put the baby to sleep. |

Basic **dormir** is **sleep**. Pronominal, overnight-stay, and causative uses require **fall asleep, stay overnight**, or **put to sleep**.
