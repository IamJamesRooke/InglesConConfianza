# Spanish **Encender**

| Spanish | English |
|---|---|
| Enciende la luz. | Turn on the light. |
| Encendió una vela. | She lit a candle. |
| Enciende el carro. | Start the car. |
| La noticia encendió el debate. | The news sparked the debate. |

**Encender** can become **turn on, light, start**, or **spark**, depending on what begins producing light, power, motion, or controversy.
