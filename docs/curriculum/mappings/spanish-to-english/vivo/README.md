# Spanish **Vivo**

| Spanish | English |
|---|---|
| El animal está vivo. | The animal is alive. |
| Es una transmisión en vivo. | It is a live broadcast. |
| Lleva una camisa de color vivo. | She is wearing a brightly colored shirt. |
| Es un niño muy vivo. | He is a very sharp/clever child. |

**Vivo** can become **alive, live, bright**, or **sharp/clever**.
