# Spanish **Fuerte**

| Spanish | English |
|---|---|
| Es una persona fuerte. | She is a strong person. |
| Habla muy fuerte. | She speaks very loudly. |
| Es un olor fuerte. | It is a strong smell. |
| Tuvimos una discusión fuerte. | We had a heated argument. |

**Fuerte** can become **strong, loud/loudly, intense**, or **heated**, depending on what has force.
