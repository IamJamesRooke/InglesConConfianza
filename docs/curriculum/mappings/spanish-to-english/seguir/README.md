# Translations of Spanish **Seguir**

Spanish **seguir** can become **follow, continue, keep doing, still be**, or a direction such as **keep going straight**.

| Lesson | Spanish | English |
|---|---|---|
| [follow](01-follow.md) | Sígueme. | Follow me. |
| [continue / keep doing](02-continue-or-keep-doing.md) | Sigue trabajando. | Keep working. |
| [still be](03-still-be.md) | Sigue enfermo. | He's still sick. |
| [directions](04-directions.md) | Sigue recto. | Keep going straight. |
| [follow online](05-follow-online.md) | Sigo esa cuenta. | I follow that account. |
| [keep doing](01-keep-ing.md) | Sigue trabajando. | He keeps working. |
| [still doing](02-still-ing.md) | Sigue trabajando. | He's still working. |
| [still in a state](03-still-state.md) | Sigue enfermo. | He's still sick. |

## Mastery Phrases

| Spanish | English |
|---|---|
| Sígueme y sigue recto. | Follow me and keep going straight. |
| Sigue trabajando, pero sigue cansado. | He keeps working, but he's still tired. |
| Sigo esa cuenta porque sigue publicando consejos útiles. | I follow that account because it keeps posting useful advice. |
