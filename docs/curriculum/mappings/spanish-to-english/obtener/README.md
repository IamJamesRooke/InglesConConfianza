# Spanish **Obtener**

| Spanish | English |
|---|---|
| Obtuve el permiso. | I got the permit. |
| Obtuvo buenos resultados. | She achieved good results. |
| La empresa obtuvo una ganancia. | The company made a profit. |
| Puedes obtener ayuda aquí. | You can receive help here. |

**Obtener** can become everyday **get**, formal **obtain**, or context-specific **achieve, make**, or **receive**.
