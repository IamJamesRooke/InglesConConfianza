# Spanish **Desde**

| Spanish | English |
|---|---|
| Vengo desde Bogotá. | I am coming from Bogotá. |
| Vivo aquí desde enero. | I have lived here since January. |
| Desde mañana, abriremos más temprano. | Starting tomorrow, we will open earlier. |
| Desde mi punto de vista, es correcto. | From my point of view, it is correct. |

**Desde** can become **from, since, starting**, or a viewpoint expression.
