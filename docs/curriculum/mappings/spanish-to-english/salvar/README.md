# Spanish **Salvar**

| Spanish | English |
|---|---|
| El bombero salvó al niño. | The firefighter saved the child. |
| El médico le salvó la vida. | The doctor saved her life. |
| Logramos salvar el obstáculo. | We managed to overcome the obstacle. |
| La nueva inversión salvó la empresa. | The new investment rescued the company. |

**Salvar** can become **save, rescue**, or **overcome**, depending on whether a person, organization, or obstacle is involved.
