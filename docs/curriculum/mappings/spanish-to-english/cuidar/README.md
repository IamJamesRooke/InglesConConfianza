# Spanish **Cuidar**

| Spanish | English |
|---|---|
| Cuido a mi abuela. | I take care of my grandmother. |
| ¿Puedes cuidar a los niños? | Can you look after the children? |
| Cuida la puerta. | Watch the door. |
| ¡Cuídate! | Take care! |
| Cuidado con el perro. | Be careful with the dog. |

**Cuidar** can become **take care of, look after**, or **watch**. Imperative and warning forms use **take care** or **be careful**.
