# **Dinero** → **Money**, **Cash**, or **Funds**

| Spanish | English |
|---|---|
| Necesito dinero para el viaje. | I need money for the trip. |
| No tengo efectivo. | I don't have any cash. |
| El proyecto necesita más fondos. | The project needs more funds. |

Use **money** generally, **cash** for physical or immediately available money, and **funds** for money reserved for a purpose.
