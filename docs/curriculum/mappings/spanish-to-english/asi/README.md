# Spanish **Así**

| Spanish | English |
|---|---|
| Hazlo así. | Do it like this. |
| Así funciona. | That is how it works. |
| Estaba cansado; aun así, salió. | He was tired; even so, he went out. |
| Así que nos fuimos. | So we left. |

**Así** can become **like this/that, how, even so**, or, in **así que**, consequence **so**.
