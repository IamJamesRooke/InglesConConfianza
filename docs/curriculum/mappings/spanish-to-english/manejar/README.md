# Spanish **Manejar**

| Spanish | English |
|---|---|
| Manejo al trabajo todos los días. | I drive to work every day. |
| Ella maneja una empresa pequeña. | She manages a small company. |
| No sé cómo manejar esta situación. | I don't know how to handle this situation. |
| Él maneja la máquina. | He operates the machine. |

**Manejar** can become **drive, manage, handle**, or **operate**, according to what is controlled.
