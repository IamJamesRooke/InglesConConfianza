# Translations of Spanish **Si No**

Two-word **si no** combines conditional **si** with negation **no**. In context, English uses **if not** or **otherwise**.

| Lesson | Spanish | English |
|---|---|---|
| [if not](01-if-not.md) | Si no vienes, avísame. | If you don't come, let me know. |
| [otherwise](02-otherwise.md) | Date prisa; si no, llegaremos tarde. | Hurry; otherwise, we'll be late. |
