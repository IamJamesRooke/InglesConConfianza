# **Si** → **If** and **Whether**

| Function | Spanish | English |
|---|---|---|
| condition | si | if |
| indirect yes/no question | si | if / whether |
| explicit alternatives | si...o no | whether...or not |

| Spanish | English |
|---|---|
| Si tengo tiempo, voy a hacerlo. | If I have time, I am going to do it. |
| Quiero saber si tienes tiempo. | I want to know if you have time. |
| Quiero saber si vas o no. | I want to know whether you are going or not. |

In indirect questions, **if** and **whether** can often overlap. **Whether** is especially useful before **or not**.

Do not confuse unaccented **si** with accented **sí**, which means **yes**.
