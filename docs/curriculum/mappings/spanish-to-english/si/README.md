# Translations of Spanish **Si**

Spanish **si** without an accent introduces a condition or an indirect yes/no question. The two-word expression [**si no**](sino/si-no/README.md) means **if not** or **otherwise**.

- [**Si** → **If** and **Whether**](01-si-if-and-whether.md)
- [**Sí** → **Yes**](<sí (yes).md>)
- [**Sino** → **but rather, but also**, or **except**](sino/README.md)

Accented **sí** is kept here with unaccented **si** because the visible contrast is the teaching point.
