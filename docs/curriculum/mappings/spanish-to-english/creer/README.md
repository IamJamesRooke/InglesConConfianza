# Translations of Spanish **Creer**

Spanish **creer** maps to English **think**, **believe**, and **believe in** according to what follows it and how certain the speaker sounds.

| Lesson | Spanish | English |
|---|---|---|
| [think for an opinion](01-think-for-an-opinion.md) | Creo que el plan funcionará. | I think the plan will work. |
| [believe someone or something](02-believe-something-or-someone.md) | Le creo a Ana. | I believe Ana. |
| [believe in](03-believe-in.md) | Creo en el proyecto. | I believe in the project. |
| [related nouns](04-related-nouns.md) | Es una creencia común. | It's a common belief. |
