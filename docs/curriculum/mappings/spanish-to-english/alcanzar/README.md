# Spanish **Alcanzar**

| Spanish | English |
|---|---|
| Alcancé el estante más alto. | I reached the highest shelf. |
| Alcancé el bus. | I caught the bus. |
| El dinero no alcanza. | There isn't enough money. |
| No me alcanza para ese apartamento. | I can't afford that apartment. |
| Alcanzó su meta. | She achieved her goal. |

**Alcanzar** can become **reach, catch, be enough, afford**, or **achieve**, depending on what is attained.
