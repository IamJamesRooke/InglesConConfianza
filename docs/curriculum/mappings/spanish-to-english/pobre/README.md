# Spanish **Pobre**

| Spanish | English |
|---|---|
| Es una familia pobre. | It is a poor family. |
| Tuvimos una cosecha pobre. | We had a poor harvest. |
| ¡Pobre Laura! | Poor Laura! |
| Es pobre en hierro. | It is low in iron. |

**Pobre** can describe limited money, low quality, sympathy, or a low amount of a substance.
