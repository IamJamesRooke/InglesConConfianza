# Spanish **Muerto**

| Spanish | English |
|---|---|
| El animal está muerto. | The animal is dead. |
| Se ha muerto la batería. | The battery has died. |
| Estoy muerto de cansancio. | I am exhausted/dead tired. |
| Es la hora muerta. | It is the slow/dead period. |

**Muerto** can become **dead, died**, emphatic **exhausted/dead tired**, or figurative **dead/slow**.
