# Spanish **Pesar**

| Spanish | English |
|---|---|
| La caja pesa diez kilos. | The box weighs ten kilograms. |
| Me pesa haber mentido. | I regret having lied. |
| A pesar de la lluvia, salimos. | Despite the rain, we went out. |
| La decisión pesó mucho en el resultado. | The decision weighed heavily on the result. |

Literal **pesar** is **weigh**. Regret, concession with **a pesar de**, and figurative influence use different English expressions.
