# Translations of Spanish **Pedir**

English chooses a different verb according to what is requested: information, a thing, an action, food, permission, a service, or formal approval.

| Lesson | Spanish | English |
|---|---|---|
| [**Pedir Algo → Ask For**](01-ask-for-something.md) | Pedí ayuda y una copia. | I asked for help and a copy. |
| [**Pedirle A Alguien Que... → Ask Someone To**](02-ask-someone-to.md) | Le pedí a Ana que llamara. | I asked Ana to call. |
| [**Pedir En Un Restaurante → Order**](03-order-food-or-drink.md) | Pedí café y una arepa. | I ordered coffee and an arepa. |
| [**Pedir/Solicitar → Request**](04-request.md) | Solicité una copia del informe. | I requested a copy of the report. |
| [**Pedir Prestado → Borrow**](05-borrow.md) | Le pedí prestado el carro a Ana. | I borrowed Ana's car. |
| [Permission, Appointments, and Applications](06-permission-appointments-and-applications.md) | Pedí permiso, pedí una cita y solicité una visa. | I asked for permission, made an appointment, and applied for a visa. |
| [Nouns: **Order, Request**, and **Application**](07-related-nouns.md) | Revisé el pedido, la solicitud y la postulación. | I reviewed the order, request, and application. |
| [**Ask, Ask For, Order**, and **Request**](confusion-sets/README.md) | Hice una pregunta, pedí ayuda y pedí el almuerzo. | I asked a question, asked for help, and ordered lunch. |
