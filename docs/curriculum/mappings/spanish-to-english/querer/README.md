# Translations of **Querer**

Spanish **querer** changes its English pattern according to what follows it and what the speaker means. These are different mapping choices, not one translation to memorize.

| Spanish pattern | Natural English pattern |
|---|---|
| querer algo | want something |
| querer hacer algo | want to do something |
| querer que alguien haga algo | want somebody to do something |
| querer a alguien | love somebody |
| querer decir | mean |

## Mastery sentence

**Quiero un café, quiero preparar el café y quiero que Laura lo sirva.**  
**I want a coffee, I want to make the coffee, and I want Laura to serve it.**
