# Spanish **Sonar**

| Spanish | English |
|---|---|
| La música suena bien. | The music sounds good. |
| Sonó el teléfono. | The phone rang. |
| Esa palabra me suena. | That word sounds familiar. |
| La alarma sonó a las seis. | The alarm went off at six. |

**Sonar** can become **sound, ring, sound familiar**, or **go off**. Do not confuse it with **soñar**, meaning dream.
