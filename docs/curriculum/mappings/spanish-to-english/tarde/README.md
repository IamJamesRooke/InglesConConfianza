# Spanish **Tarde**

| Spanish | English |
|---|---|
| Llegué tarde. | I arrived late. |
| Nos vemos esta tarde. | See you this afternoon. |
| Trabaja por la tarde. | She works in the afternoon/evening. |
| Más vale tarde que nunca. | Better late than never. |

**Tarde** can be adverb **late** or noun **afternoon/evening**, with the boundary depending on context.
