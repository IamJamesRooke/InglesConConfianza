# Spanish **Aparecer**

| Spanish | English |
|---|---|
| Apareció un problema. | A problem appeared. |
| Laura apareció a las nueve. | Laura showed up at nine. |
| Mi nombre aparece en la lista. | My name is on the list. |
| El artículo apareció ayer. | The article came out yesterday. |

**Aparecer** can become **appear, show up, be listed**, or **come out** when something is published.
