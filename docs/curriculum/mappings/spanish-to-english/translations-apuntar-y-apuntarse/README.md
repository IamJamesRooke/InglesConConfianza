# Translations of Spanish **Apuntar** and **Apuntarse**

Spanish **apuntar** and **apuntarse** cover pointing, aiming, writing down, indicating, signing up, and joining plans.

| Lesson | Spanish | English |
|---|---|---|
| [**Apuntar → Point**](01-point.md) | Apuntó hacia la salida. | She pointed toward the exit. |
| [**Apuntar → Aim**](02-aim.md) | Apunta al centro del blanco. | Aim at the center of the target. |
| [**Apuntar → Write Down / Note**](03-write-down.md) | Apunta mi número de teléfono. | Write down my phone number. |
| [**Apuntar A → Point To / Suggest**](04-indicate-or-suggest.md) | La evidencia apunta a otra causa. | The evidence points to another cause. |
| [**Apuntarse → Sign Up**](05-sign-up.md) | Me apunté al curso de inglés. | I signed up for the English course. |
| [**Apuntarse → Join In / Be In**](06-join-in.md) | Vamos al cine; ¿te apuntas? | We're going to the movies; are you in? |
| [**Apuntar A → Aim To**](07-aim-to.md) | El proyecto apunta a reducir costos. | The project aims to reduce costs. |
| [**Apuntar → Record**](08-score-or-record.md) | La secretaria apuntó dos cambios en el acta. | The secretary recorded two changes in the minutes. |
