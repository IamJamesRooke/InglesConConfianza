# Spanish **Atrás**

| Spanish | English |
|---|---|
| Mira atrás. | Look back. |
| Está atrás de la casa. | It is behind the house. |
| Se quedó atrás. | She fell behind. |
| Años atrás, vivía en Cali. | Years ago, I lived in Cali. |

**Atrás** can become **back, behind, fall behind**, or **ago** in a past-time expression.
