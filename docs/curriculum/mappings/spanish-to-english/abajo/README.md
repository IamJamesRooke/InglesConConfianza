# Spanish **Abajo**

| Spanish | English |
|---|---|
| Mira abajo. | Look down. |
| Vive abajo. | She lives downstairs. |
| El nombre aparece más abajo. | The name appears below. |
| ¡Abajo el impuesto! | Down with the tax! |

**Abajo** can become **down, downstairs, below**, or part of a protest expression **down with**.
