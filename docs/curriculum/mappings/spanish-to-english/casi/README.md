# Spanish **Casi**

| Spanish | English |
|---|---|
| Casi terminé. | I almost finished. |
| Hay casi cien personas. | There are nearly one hundred people. |
| Casi nunca salgo de noche. | I hardly ever go out at night. |
| Por poco me caigo. | I almost fell. |

**Casi** normally becomes **almost** or **nearly**. With negative frequency it can become **hardly ever**.
