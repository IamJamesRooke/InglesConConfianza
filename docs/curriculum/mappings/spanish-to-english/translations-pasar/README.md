# Translations of Spanish **Pasar**

Spanish **pasar** changes meaning with its object and setting. English may use **happen, pass, spend, come in, hand**, or a concern structure.

| Lesson | Spanish | English |
|---|---|---|
| [**Pasar → Happen**](01-happen.md) | ¿Qué pasó anoche? | What happened last night? |
| [**Pasar → Pass / Cross**](02-pass-or-cross.md) | El bus pasó por el puente. | The bus crossed the bridge. |
| [**Pasar → Spend** Time](03-spend-time.md) | Pasamos la tarde juntos. | We spent the afternoon together. |
| [**Pasar → Come / Go In**](04-come-or-go-in.md) | Pasa, la puerta está abierta. | Come in; the door is open. |
| [**Pasar → Hand / Pass**](05-hand-or-pass-something.md) | Pásame la sal, por favor. | Pass me the salt, please. |
| [**Pasarlo Bien o Mal**](06-have-a-good-or-bad-time.md) | Lo pasamos muy bien en la fiesta. | We had a great time at the party. |
| [**¿Qué Te Pasa? → What's Wrong?**](07-what-is-wrong.md) | ¿Qué te pasa? Te ves preocupado. | What's wrong? You look worried. |
