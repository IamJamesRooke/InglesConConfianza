# **Hay Que**

Impersonal Spanish **hay que** does not identify one fixed subject. Natural English chooses **you**, **we**, **one**, or **it is necessary** from context.

| Lesson | Spanish | English |
|---|---|---|
| [you](01-you.md) | Hay que registrarse primero. | You have to register first. |
| [we](02-we.md) | Hay que salir temprano. | We need to leave early. |
| [one](03-one.md) | Hay que tener cuidado. | One must be careful. |
| [necessary](04-necessary.md) | Hay que cambiar el plan. | It is necessary to change the plan. |
