# Translations of Spanish **Seguir**

Spanish **seguir** expresses physical following, continuation, persistence of a state, directions, and following people or topics.

| Lesson | Spanish | English |
|---|---|---|
| [**Seguir → Follow**](01-follow.md) | Sígueme hasta la estación. | Follow me to the station. |
| [**Seguir + Gerund → Keep Doing**](02-continue-or-keep-doing.md) | Sigue trabajando aunque esté cansado. | He keeps working even though he's tired. |
| [**Seguir + State → Still Be**](03-still-be.md) | Sigue enfermo, pero sigue de buen humor. | He's still sick, but he's still in a good mood. |
| [**Seguir → Keep Going / Continue**](04-directions.md) | Sigue recto dos cuadras. | Keep going straight for two blocks. |
| [**Seguir → Follow** Online](05-follow-online.md) | Sigo a esa profesora en redes sociales. | I follow that teacher on social media. |
