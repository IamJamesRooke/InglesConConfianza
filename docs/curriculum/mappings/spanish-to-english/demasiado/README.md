# Spanish **Demasiado**

| Spanish | English |
|---|---|
| Es demasiado caro. | It is too expensive. |
| Hay demasiado ruido. | There is too much noise. |
| Hay demasiadas personas. | There are too many people. |
| Trabaja demasiado. | She works too much. |

**Demasiado** can become **too, too much**, or **too many**, with agreement determined by the Spanish noun.
