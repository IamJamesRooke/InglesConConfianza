# Translations of Spanish **Acabar** and **Acabar De**

Spanish **acabar** changes with its complement to express finishing, recent events, final outcomes, depletion, and destruction.

| Lesson | Spanish | English |
|---|---|---|
| [**Acabar → Finish**](01-finish.md) | Acabé el informe esta mañana. | I finished the report this morning. |
| [**Acabar De Hacer → Finish Doing**](02-finish-doing.md) | Acabé de leer el libro. | I finished reading the book. |
| [**Acabar De → Have Just**](03-have-just-done.md) | Acabo de llegar. | I've just arrived. |
| [**Acababa De → Had Just**](04-had-just-done.md) | Acababa de salir cuando llamaste. | I had just left when you called. |
| [**Acabar + Gerund / Acabar Por → End Up**](05-end-up.md) | Acabó trabajando toda la noche. | He ended up working all night. |
| [**Acabar Con → Finish / Use Up**](06-use-up.md) | Acabaron con toda la comida. | They finished all the food. / They used up all the food. |
| [**Acabar Con → Put an End To**](07-put-an-end-to.md) | Tenemos que acabar con ese problema. | We have to put an end to that problem. |
| [**Acabarse → End / Be Over**](08-end-or-be-over.md) | La reunión se acabó a las cinco. | The meeting ended at five. / The meeting was over at five. |
