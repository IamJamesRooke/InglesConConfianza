# **Tener** → **Be** for Physical States

| Spanish structure | English structure |
|---|---|
| tener hambre | to be hungry |
| tener sed | to be thirsty |
| tener calor | to be hot |
| tener frío | to be cold |

| Spanish | English |
|---|---|
| Tengo hambre. | I am hungry. |
| Laura tiene sed. | Laura is thirsty. |
| Tenemos calor. | We are hot. |
| Ellos tienen frío. | They are cold. |

Do not translate these expressions word for word as *I have hunger*.
