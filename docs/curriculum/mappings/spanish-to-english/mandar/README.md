# Translations of Spanish **Mandar**

Spanish **mandar** covers sending, ordering, being in charge, arranging services, and emphatic direction.

| Lesson | Spanish | English |
|---|---|---|
| [**Mandar → Send**](01-send.md) | Mándame el archivo por correo. | Send me the file by email. |
| [**Mandar → Order / Tell**](02-order-someone-to.md) | El jefe me mandó terminar el informe. | The boss ordered me to finish the report. |
| [**Mandar → Be In Charge / Run**](03-be-in-charge.md) | Aquí manda Ana. | Ana is in charge here. |
| [**Mandar A Hacer → Have Something Done**](04-have-something-done.md) | Mandé arreglar el carro. | I had the car repaired. |
| [**Mandar A Buscar → Send For / Have Picked Up**](05-send-for.md) | Mandaron a buscar al médico. | They sent for the doctor. |
| [**Mandar Para / A → Send Away / Send To**](06-send-away.md) | Lo mandaron a otra oficina. | They sent him to another office. |
| [**Mandar A Alguien A Hacer Algo**](07-mandar-a-alguien-a.md) | Mandé a Luis a comprar pan. | I sent Luis to buy bread. |
| [**Mandar Parar / Callar → Tell To Stop / Be Quiet**](08-mandar-parar.md) | La profesora los mandó callar. | The teacher told them to be quiet. |
