# Spanish **Ofrecer**

| Spanish | English |
|---|---|
| Me ofreció café. | She offered me coffee. |
| La empresa ofrece cursos nocturnos. | The company provides evening courses. |
| El hotel ofrece una buena vista. | The hotel has a good view. |
| Se ofreció a ayudar. | He volunteered to help. |

**Ofrecer** can become **offer, provide, have**, or, pronominally, **volunteer**.
