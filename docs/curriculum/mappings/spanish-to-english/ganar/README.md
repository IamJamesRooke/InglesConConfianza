# Spanish **Ganar**

| Spanish | English |
|---|---|
| Ganamos el partido. | We won the game. |
| Gano dos millones al mes. | I earn two million pesos a month. |
| El proyecto ganó apoyo. | The project gained support. |
| Bogotá le ganó a Cali. | Bogotá beat Cali. |

Competitions, income, acquiring an advantage, and defeating an opponent require **win, earn, gain**, or **beat**.
