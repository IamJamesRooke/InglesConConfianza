# Spanish **Bastante**

| Spanish | English |
|---|---|
| Tenemos bastante comida. | We have enough food. |
| Es bastante difícil. | It is quite difficult. |
| Trabajó bastante. | She worked a lot. |
| Hay bastantes sillas. | There are plenty of chairs. |

**Bastante** can become **enough, quite, a lot**, or **plenty of**, depending on position and agreement.
