# Spanish **Bastar**

| Spanish | English |
|---|---|
| Eso basta. | That is enough. |
| Basta con una llamada. | All it takes is one call. |
| Basta con leer el primer párrafo. | All you need to do is read the first paragraph. |
| ¡Basta ya! | That's enough! |

English normally restructures **bastar** through **be enough, all it takes**, or **all you need to do**.
