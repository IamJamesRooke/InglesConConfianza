# Translations of Spanish **Sino**

One-word **sino** corrects or replaces an idea after a negative statement. Keep it distinct from two-word **si no**, which is nested here because the spelling contrast is the teaching point.

| Lesson | Spanish | English |
|---|---|---|
| [but rather](01-but-rather.md) | No es azul, sino verde. | It isn't blue but green. |
| [but also](02-but-also.md) | No solo vino, sino que ayudó. | She not only came but also helped. |
| [except](03-except.md) | No hace nada sino quejarse. | He does nothing but complain. |

- [**si no** → if not / otherwise](si-no/README.md)
