# Translations of **Para**

Spanish **para** can express a recipient, purpose, destination, or intended result.

| Function | Spanish | English |
|---|---|---|
| recipient | Este café es para Laura. | This coffee is for Laura. |
| purpose with a verb | Necesito tiempo para hacerlo. | I need time to do it. |
| emphasized purpose | Voy a la oficina para hablar con Laura. | I am going to the office in order to speak with Laura. |
| destination after **leave** | Salgo para la oficina. | I am leaving for the office. |
| intended result | Hablo despacio para que puedas entender. | I speak slowly so that you can understand. |

In normal purpose phrases, English usually uses **to + base verb**, not **for + verb**:

- **to do it**
- Not: *for do it*

**In order to** is possible when the purpose needs emphasis.
