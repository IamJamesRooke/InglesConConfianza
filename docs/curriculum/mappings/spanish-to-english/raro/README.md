# Spanish **Raro**

| Spanish | English |
|---|---|
| Es un error raro. | It is a rare error. |
| Ese ruido es raro. | That noise is strange. |
| Me siento raro. | I feel weird. |
| Rara vez salgo de noche. | I rarely go out at night. |

**Raro** can become **rare, strange**, or **weird**; **rara vez** becomes adverb **rarely**.
