# Translations of Spanish **Pues**

| Lesson | Spanish | English |
|---|---|---|
| [well](01-well.md) | Pues, no sé. | Well, I don't know. |
| [then](02-then.md) | Pues hazlo tú. | Then do it yourself. |
| [because](03-because.md) | No fui, pues estaba enfermo. | I didn't go because I was sick. |
| [therefore](04-therefore.md) | Estaba cerrado; no pudimos, pues, entrar. | It was closed; therefore, we couldn't enter. |
| [softening](05-softening.md) | Es un poco difícil, pues. | It's a little difficult, you know. |
