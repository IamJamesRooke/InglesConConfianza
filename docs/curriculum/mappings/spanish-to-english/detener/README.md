# Spanish **Detener**

| Spanish | English |
|---|---|
| Detén el carro. | Stop the car. |
| La policía detuvo al sospechoso. | The police arrested the suspect. |
| Lo detuvieron durante dos horas. | They detained him for two hours. |
| Nada puede detenernos. | Nothing can hold us back. |

**Detener** can mean stop movement, arrest someone, detain someone, or hold someone back from progress.

See also [**detenerse para hacer algo** → **stop to do something**](detenerse-para-stop-to.md).
