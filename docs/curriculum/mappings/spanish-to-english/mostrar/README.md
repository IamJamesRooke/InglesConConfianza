# Spanish **Mostrar**

| Spanish | English |
|---|---|
| Muéstrame la foto. | Show me the photo. |
| La pantalla muestra el total. | The screen displays the total. |
| Los resultados muestran una mejora. | The results demonstrate an improvement. |
| No mostró sus verdaderas intenciones. | He did not reveal his true intentions. |

**Mostrar** can become **show, display, demonstrate**, or **reveal**, according to what becomes visible or evident.
