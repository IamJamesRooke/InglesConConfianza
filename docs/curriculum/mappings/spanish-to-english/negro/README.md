# Spanish **Negro**

| Spanish | English |
|---|---|
| El carro es negro. | The car is black. |
| Fue un día negro para la empresa. | It was a dark day for the company. |
| Compraron el producto en el mercado negro. | They bought the product on the black market. |
| Tomo el café negro. | I take my coffee black. |

**Negro** can become **black** or figurative **dark**, with several fixed English combinations.
