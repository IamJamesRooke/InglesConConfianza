# Spanish **Genial**

| Spanish | English |
|---|---|
| ¡Genial! Nos vemos mañana. | Great! See you tomorrow. |
| Fue una idea genial. | It was a brilliant idea. |
| La pasamos genial. | We had a great time. |
| Tiene un talento genial. | He has extraordinary talent. |

Everyday **genial** usually means **great, brilliant**, or **wonderful**, not English *genial* meaning friendly and cheerful.
