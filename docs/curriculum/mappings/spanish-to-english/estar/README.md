# Spanish **Estar**

| Spanish | English |
|---|---|
| Estoy cansado. | I am tired. |
| Bogotá está en Colombia. | Bogotá is in Colombia. |
| Estoy de acuerdo. | I agree. |
| Estamos por salir. | We are about to leave. |
| ¿Cómo estás? | How are you feeling? |

State and location normally use **be**. Common **estar** combinations may instead become **agree, be about to**, or **feel**.
