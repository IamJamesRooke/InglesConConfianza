# Spanish **Más**

Spanish **más** can become **more**, **the most**, **most**, or a related English phrase depending on the surrounding words.

| Lesson | Spanish | English |
|---|---|---|
| [Más → more](01-more.md) | Necesito más tiempo. | I need more time. |
| [El más → the most](02-the-most.md) | Es el más útil. | It is the most useful. |
| [Más de → more than](03-more-than.md) | Hay más de cien personas. | There are more than one hundred people. |
| [Lo más → what is most](04-lo-mas.md) | Lo más importante es practicar. | The most important thing is to practice. |
