# Translations of Spanish **Llevar**

Spanish **llevar** can become **take, carry, wear, have been doing, take time, get along**, or **take away**. Duration constructions receive their own atomic review lessons below.

| Lesson | Spanish | English |
|---|---|---|
| [take or carry](01-take-or-carry.md) | Lleva esta caja a la oficina. | Take this box to the office. |
| [wear](02-wear.md) | Lleva una chaqueta azul. | She's wearing a blue jacket. |
| [have been doing](03-have-been-doing.md) | Llevo dos años trabajando aquí. | I've been working here for two years. |
| [take time](04-take-time.md) | El viaje lleva dos horas. | The trip takes two hours. |
| [get along](05-get-along.md) | Se llevan bien. | They get along well. |
| [take away](06-take-away.md) | Llévate estos papeles. | Take these papers away. |
| [duration: progressive](01-present-perfect-progressive.md) | Llevo dos años trabajando aquí. | I've been working here for two years. |
| [duration: state](02-state.md) | Lleva una semana enfermo. | He's been sick for a week. |
| [duration: question](03-question.md) | ¿Cuánto llevas esperando? | How long have you been waiting? |
| [duration: negative](04-negative.md) | No llevo mucho viviendo aquí. | I haven't been living here long. |

## Mastery Phrases

| Spanish | English |
|---|---|
| Lleva esta caja; ella lleva una chaqueta azul. | Take this box; she's wearing a blue jacket. |
| Llevo dos años trabajando aquí y el viaje me lleva dos horas. | I've been working here for two years, and the trip takes me two hours. |
| Se llevan bien, así que se llevaron los papeles. | They get along well, so they took the papers away. |
