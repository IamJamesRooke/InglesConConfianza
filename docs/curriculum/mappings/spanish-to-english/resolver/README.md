# Spanish **Resolver**

| Spanish | English |
|---|---|
| Resolvimos el problema. | We solved the problem. |
| El juez resolvió el caso. | The judge decided the case. |
| Resolvieron cancelar la reunión. | They resolved to cancel the meeting. |
| Tenemos que resolver esta situación. | We need to sort out this situation. |

**Resolver** can become **solve, decide, resolve to**, or **sort out**.
