# Spanish **Traer**

| Spanish | English |
|---|---|
| Trae el café aquí. | Bring the coffee here. |
| Laura trae puesta una chaqueta azul. | Laura is wearing a blue jacket. |
| Ese cambio traerá problemas. | That change will cause problems. |
| No traigo dinero. | I don't have any money with me. |

Physical movement uses **bring**. Clothing, consequences, and possessions carried with someone require other English expressions.
