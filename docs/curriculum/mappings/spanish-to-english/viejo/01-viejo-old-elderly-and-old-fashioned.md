# **Viejo** → **Old**, **Elderly**, and **Old-Fashioned**

| Spanish | English |
|---|---|
| viejo / vieja | old / elderly / old-fashioned |

| Spanish | English |
|---|---|
| El edificio es viejo. | The building is old. |
| Una señora mayor vive aquí. | An elderly woman lives here. |
| Es una costumbre vieja. | It is an old-fashioned custom. |

**Old** is the general translation. Use **elderly** respectfully for a person. **Old-fashioned** describes something associated with an earlier style or time.
