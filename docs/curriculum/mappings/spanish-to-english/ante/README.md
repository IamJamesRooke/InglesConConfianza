# Spanish **Ante**

| Spanish | English |
|---|---|
| Compareció ante el juez. | He appeared before the judge. |
| Ante el peligro, salieron. | Faced with danger, they left. |
| Se arrodilló ante la estatua. | She knelt in front of the statue. |
| Ante todo, mantén la calma. | Above all, stay calm. |

**Ante** can become **before, faced with, in front of**, or part of **above all**.
