# Spanish **Atender**

| Spanish | English |
|---|---|
| La empleada atendió al cliente. | The employee helped the customer. |
| El médico atiende pacientes por la tarde. | The doctor sees patients in the afternoon. |
| Atiende el teléfono, por favor. | Answer the phone, please. |
| Atiende a lo que estoy diciendo. | Pay attention to what I am saying. |
| Debemos atender este problema. | We must address this problem. |

**Atender** can become **help, see, answer, pay attention to**, or **address**, depending on what receives attention.
