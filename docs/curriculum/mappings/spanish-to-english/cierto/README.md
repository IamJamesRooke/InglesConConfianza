# Spanish **Cierto**

| Spanish | English |
|---|---|
| Es cierto. | It is true. |
| Cierta persona llamó. | A certain person called. |
| Por cierto, Laura llamó. | By the way, Laura called. |
| ¿Cierto? | Right? |

**Cierto** can become **true**, indefinite **a certain**, conversational **right?**, or part of **por cierto → by the way**.
