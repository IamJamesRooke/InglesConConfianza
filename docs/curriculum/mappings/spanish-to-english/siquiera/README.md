# Spanish **Siquiera**

| Spanish | English |
|---|---|
| No llamó siquiera una vez. | She didn't call even once. |
| Ni siquiera lo intentó. | He didn't even try. |
| Dame siquiera cinco minutos. | Give me at least five minutes. |

Negative **siquiera/ni siquiera** becomes **even/not even**. In a minimum request it can become **at least**.
