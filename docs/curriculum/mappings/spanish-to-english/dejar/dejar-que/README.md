# **Dejar Que**

Spanish **dejar** and **dejar que** can become **let** or **allow**. English changes the structure after each verb.

| Lesson | Spanish | English |
|---|---|---|
| [**Dejar → Let**](01-let.md) | Déjame hablar. | Let me speak. |
| [**Dejar Que → Allow**](02-allow.md) | Dejó que Ana entrara. | She allowed Ana to enter. |
