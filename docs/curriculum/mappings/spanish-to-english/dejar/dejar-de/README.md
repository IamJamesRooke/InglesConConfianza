# **Dejar De**

Spanish **dejar de + infinitive** normally maps to **stop + -ing**, **stop working**, or a natural **no longer** construction. The contrasting **stop to do something** uses a different Spanish structure and is included to prevent a frequent error.

| Lesson | Spanish | English |
|---|---|---|
| [stop-ing](01-stop-ing.md) | Dejó de fumar. | He stopped smoking. |
| [stop-to](02-stop-to.md) | Se detuvo para fumar. | He stopped to smoke. |
| [no-longer](03-no-longer.md) | Dejó de funcionar. | It stopped working. |
