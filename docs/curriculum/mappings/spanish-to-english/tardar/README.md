# Spanish **Tardar**

| Spanish | English |
|---|---|
| El viaje tarda dos horas. | The trip takes two hours. |
| Tardé una hora en terminar. | It took me an hour to finish. |
| No tardes. | Don't be late. |
| La respuesta tardó en llegar. | The response was slow to arrive. |

English normally restructures **tardar** through **take time, be late**, or **be slow to** do something.
