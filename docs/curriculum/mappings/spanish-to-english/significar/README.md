# Spanish **Significar**

| Spanish | English |
|---|---|
| ¿Qué significa esta palabra? | What does this word mean? |
| La paloma significa paz. | The dove symbolizes peace. |
| ONU significa Organización de las Naciones Unidas. | UN stands for United Nations. |
| Tu apoyo significa mucho para mí. | Your support means a lot to me. |

**Significar** usually becomes **mean**, but symbols and abbreviations often use **symbolize** and **stand for**.
