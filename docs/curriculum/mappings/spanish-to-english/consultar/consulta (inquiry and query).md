# **Consulta** → **Inquiry** or **Query**

| Spanish | English |
|---|---|
| Recibimos una consulta sobre el proceso. | We received an inquiry about the process. |
| El sistema no encontró la consulta. | The system could not find the query. |

**Inquiry** is more formal, and **query** is common for a technical or specific request for information.

This noun lesson is retained for a future **consultar / consulta** family audit.
