# Spanish **Enseñar**

| Spanish | English |
|---|---|
| Enseño inglés. | I teach English. |
| Enséñame la foto. | Show me the photo. |
| Mi abuelo me enseñó a manejar. | My grandfather taught me to drive. |
| La experiencia me enseñó a ser paciente. | Experience taught me to be patient. |

**Enseñar** can mean either **teach** or **show**, and a learned action uses **teach someone to do something**.
