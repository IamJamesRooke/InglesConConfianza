# Translations of Spanish **Intentar**

Spanish **intentar** maps to English **try** when someone attempts an action, task, or challenge.

- [**intentar hacer algo** → try to do something](01-try-to-do-something.md)
- [**intentar algo** → try something](02-try-a-task.md)

For testing or sampling something, see the separate source map for [**probar**](../probar/README.md).
