# Spanish **Nunca**

| Spanish | English |
|---|---|
| Nunca llego tarde. | I never arrive late. |
| No he estado nunca en Cali. | I have never been to Cali. |
| Nunca más lo haré. | I will never do it again. |
| ¿Nunca has viajado solo? | Haven't you ever traveled alone? |

**Nunca** can become **never, not ever**, or **never again**, and English question structure may prefer **ever**.
