# Spanish **Usar**

| Spanish | English |
|---|---|
| Uso esta aplicación todos los días. | I use this application every day. |
| Laura usa gafas. | Laura wears glasses. |
| No usamos efectivo. | We don't take cash. |
| Puedes usar mi oficina. | You can have/use my office. |

Tools use **use**, clothing **wear**, accepted payment **take**, and temporary availability may use **have** or **use**.
