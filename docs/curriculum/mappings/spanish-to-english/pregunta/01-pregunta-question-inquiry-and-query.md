# **Pregunta** → **Question**, **Inquiry**, or **Query**

| Spanish | English |
|---|---|
| Tengo una pregunta. | I have a question. |
| Recibimos una consulta sobre el proceso. | We received an inquiry about the process. |
| El sistema no encontró la consulta. | The system could not find the query. |

**Question** is the neutral everyday word. **Inquiry** is more formal, and **query** is common for a technical or specific request for information.
