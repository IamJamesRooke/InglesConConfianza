# Spanish **Desear**

| Spanish | English |
|---|---|
| Deseo hablar con Laura. | I wish/want to speak with Laura. |
| Te deseo buena suerte. | I wish you good luck. |
| ¿Qué desea ordenar? | What would you like to order? |
| Es un resultado deseable. | It is a desirable result. |

**Desear** can become **wish, want**, or polite **would like**, depending on the object and register.
