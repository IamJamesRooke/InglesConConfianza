# Spanish **Parar**

| Spanish | English |
|---|---|
| Para el carro aquí. | Stop the car here. |
| Paró de llover. | It stopped raining. |
| Paramos en un hotel pequeño. | We stayed at a small hotel. |
| No para de hablar. | She won't stop talking. |
| El bus para en la esquina. | The bus stops at the corner. |

**Parar** can become **stop** or, in travel, **stay**. **No parar de** emphasizes continuous repeated action.
