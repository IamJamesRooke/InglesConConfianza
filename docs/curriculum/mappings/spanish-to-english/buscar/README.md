# Translations of Spanish **Buscar**

Spanish **buscar** maps to **look for, search for**, or formal **seek**. English separates the process of searching from the result **find**.

| Lesson | Spanish | English |
|---|---|---|
| [Look For, Search For, Seek](01-look-for-search-and-seek.md) | Busco una solución. | I'm looking for / seeking a solution. |
| [Look For vs Find](confusion-sets/README.md) | Busco las llaves y luego las encuentro. | I look for the keys and then find them. |
