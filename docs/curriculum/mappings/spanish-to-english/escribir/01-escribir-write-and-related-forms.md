# **Escribir** → **Write**, **Write Down**, and **Write Up**

| Spanish | English |
|---|---|
| escribir | **to write** |
| anotar | write down |
| redactar un informe | write up a report |

| Spanish | English |
|---|---|
| Escribo un mensaje en inglés todos los días. | I write a message in English every day. |

**Write down** records information; **write up** develops notes or results into a complete report.
