# Translations of Spanish **Llamar** and **Llamarse**

Spanish **llamar** and **llamarse** cover calling, phoning, naming, summoning, attracting attention, and identifying a name.

| Lesson | Spanish | English |
|---|---|---|
| [**Llamar → Call**](01-call-someone.md) | Llama a Ana antes de salir. | Call Ana before leaving. |
| [**Llamar → Call / Phone**](02-phone.md) | Te llamo esta noche. | I'll call you tonight. |
| [**Llamarse → Be Called**](03-be-called.md) | Me llamo Laura y el restaurante se llama El Patio. | My name is Laura, and the restaurant is called El Patio. |
| [**Llamar → Call / Name**](04-name-something.md) | Llamaron al perro Bruno. | They named the dog Bruno. |
| [**Llamar → Call / Send For**](05-summon.md) | Llamaron al médico de inmediato. | They called the doctor immediately. |
| [**Llamar La Atención → Attract Attention**](06-attract-attention.md) | El color rojo llama la atención. | The red color attracts attention. |
| [**Llamarle La Atención A Alguien**](07-tell-someone-off.md) | La profesora le llamó la atención por llegar tarde. | The teacher told him off for arriving late. |
| [**Llamar Algo De Cierta Manera**](08-call-something.md) | A eso lo llamo una buena idea. | That's what I call a good idea. |
| [**Llamado** → **Called / So-Called / Calling / Call For**](<llamado (called, so-called, calling, call for).md>) | Hicieron un llamado a la calma. | They called for calm. |
