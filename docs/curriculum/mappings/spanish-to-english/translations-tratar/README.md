# Translations of Spanish **Tratar**

Spanish **tratar** changes with its complement: it can describe treatment, handling a subject, an attempt, what something is about, or how people relate to one another.

| Lesson | Spanish | English |
|---|---|---|
| [**Tratar → Treat** Someone](01-treat-someone.md) | Me trataron muy bien en el hotel. | They treated me very well at the hotel. |
| [**Tratar → Treat** a Condition](02-treat-a-condition.md) | El médico trató la infección. | The doctor treated the infection. |
| [**Tratar → Deal With / Address**](03-deal-with.md) | La reunión trató el problema de seguridad. | The meeting addressed the security problem. |
| [**Tratar De → Try To**](04-tratar-de.md) | Trata de dormir un poco. | Try to get some sleep. |
| [**Tratarse De → Be About**](05-tratarse-de.md) | ¿De qué se trata el libro? | What is the book about? |
| [**Tratar a Alguien de → Call / Accuse**](06-tratar-a-alguien-de.md) | Lo trataron de mentiroso. | They called him a liar. |
