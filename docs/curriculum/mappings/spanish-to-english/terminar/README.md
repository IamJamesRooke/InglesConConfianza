# Spanish **Terminar**

| Spanish | English |
|---|---|
| Terminé el informe. | I finished the report. |
| La reunión terminó a las cinco. | The meeting ended at five. |
| Terminamos quedándonos en casa. | We ended up staying home. |
| Laura terminó con Mateo. | Laura broke up with Mateo. |

Completion uses **finish** or **end**. An eventual result and ending a relationship use **end up** and **break up with**.
