# Spanish **Siempre**

| Spanish | English |
|---|---|
| Siempre llego temprano. | I always arrive early. |
| Siempre que llama, estoy ocupado. | Whenever she calls, I am busy. |
| Puedes llamarme siempre que quieras. | You can call me whenever/as long as you want. |
| Se fue para siempre. | She left forever/for good. |

**Siempre** can become **always, whenever, as long as**, or, in **para siempre**, **forever/for good**.
