# Spanish **Levantar**

| Spanish | English |
|---|---|
| Levanta la caja. | Lift the box. |
| Levanta la mano. | Raise your hand. |
| Me levanto a las seis. | I get up at six. |
| Levantaron una carpa. | They set up a tent. |
| El gobierno levantó la prohibición. | The government lifted the ban. |

**Levantar** can become **lift, raise, get up, set up**, or **remove/lift** a restriction.
