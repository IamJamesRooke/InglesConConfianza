# Translations of Spanish **Subir**

Spanish **subir** can become **go up, come up, raise, get on, upload, turn up, rise, bring up**, or **gain weight**. Each lesson keeps **bajar** visible as the useful inverse contrast; the same contrasts are indexed under [**bajar**](../bajar/README.md).

| Lesson | Main English mappings |
|---|---|
| [movement](01-go-or-come-up-and-down.md) | go up / come up |
| [moving something](02-raise-or-lower.md) | raise |
| [transport](03-get-on-or-off-transport.md) | get on |
| [files](04-upload-or-download.md) | upload |
| [settings](05-volume-and-settings.md) | turn up |
| [prices and levels](06-prices-and-levels.md) | rise |
| [bring something up](07-pick-up-or-drop-off.md) | bring up |
| [weight](08-weight.md) | gain weight |
