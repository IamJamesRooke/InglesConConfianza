# Spanish **Confiar**

| Spanish | English |
|---|---|
| Confío en Laura. | I trust Laura. |
| Confío en que llegará a tiempo. | I trust that she will arrive on time. |
| Puedes confiar en mí. | You can rely on me. |
| Le confié el secreto. | I confided the secret to her. |
| Le confiaron el proyecto. | They entrusted the project to her. |

**Confiar en** can mean trust or rely on. Giving private information or responsibility uses **confide** or **entrust**.
