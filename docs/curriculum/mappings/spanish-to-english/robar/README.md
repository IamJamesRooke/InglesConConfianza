# Spanish **Robar**

| Spanish | English |
|---|---|
| Robaron mi teléfono. | They stole my phone. |
| Robaron el banco. | They robbed the bank. |
| Me robaron cien mil pesos. | They stole one hundred thousand pesos from me. |
| Esa canción se robó el show. | That song stole the show. |

Use **steal** for the thing taken and **rob** for the person or place deprived. English changes the object pattern.
