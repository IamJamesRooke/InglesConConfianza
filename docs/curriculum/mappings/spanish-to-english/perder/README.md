# Spanish **Perder**

| Spanish | English |
|---|---|
| Perdí las llaves. | I lost my keys. |
| Perdimos el bus. | We missed the bus. |
| No pierdas el tiempo. | Don't waste time. |
| Me perdí en el centro. | I got lost downtown. |
| La llave pierde agua. | The faucet leaks. |

**Perder** can become **lose, miss, waste, get lost**, or **leak**, depending on what is lost or escaping.
