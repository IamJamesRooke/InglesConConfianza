# Spanish **Mal**

| Spanish | English |
|---|---|
| Es un mal plan. | It is a bad plan. |
| Dormí mal. | I slept badly. |
| Algo salió mal. | Something went wrong. |
| Me siento mal. | I feel sick/unwell. |

**Mal** can become **bad, badly, wrong**, or **sick/unwell**, depending on its grammatical and physical context.
