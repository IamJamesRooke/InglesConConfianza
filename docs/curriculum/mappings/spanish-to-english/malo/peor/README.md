# Spanish **Peor**

| Spanish | English |
|---|---|
| Este plan es peor. | This plan is worse. |
| Fue el peor día del año. | It was the worst day of the year. |
| Se siente peor hoy. | She feels worse today. |
| Lo peor es esperar. | The worst part is waiting. |

**Peor** can become comparative **worse**, superlative **worst**, or the noun phrase **the worst part/thing**.
