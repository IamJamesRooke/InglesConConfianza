# Spanish **Averiguar**

| Spanish | English |
|---|---|
| Averigua la dirección. | Find out the address. |
| Voy a averiguar qué pasó. | I am going to find out what happened. |
| Averigua si la puerta está cerrada. | Check whether the door is locked. |
| La policía está averiguando el caso. | The police are investigating the case. |

**Averiguar** can become **find out, check**, or **investigate**, according to the depth and purpose of the inquiry.
