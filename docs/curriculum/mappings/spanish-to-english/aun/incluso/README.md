# Spanish **Incluso**

| Spanish | English |
|---|---|
| Incluso Laura vino. | Even Laura came. |
| Todos, incluso Mateo, estuvieron de acuerdo. | Everyone, including Mateo, agreed. |
| Incluso si llueve, iremos. | Even if it rains, we will go. |

**Incluso** can become **even, including**, or part of **even if**.
