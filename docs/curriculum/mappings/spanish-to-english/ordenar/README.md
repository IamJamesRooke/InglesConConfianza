# Spanish **Ordenar**

| Spanish | English |
|---|---|
| Ordené un café. | I ordered a coffee. |
| El jefe ordenó que saliéramos. | The boss ordered us to leave. |
| Ordena los documentos por fecha. | Sort the documents by date. |
| Ordena tu cuarto. | Tidy your room. |

**Ordenar** can become **order, tell/order someone to, sort**, or **tidy**.
