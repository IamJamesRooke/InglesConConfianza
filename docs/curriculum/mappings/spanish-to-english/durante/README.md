# Spanish **Durante**

| Spanish | English |
|---|---|
| Dormí durante la película. | I slept during the movie. |
| Viví allí durante dos años. | I lived there for two years. |
| Llovió durante toda la noche. | It rained throughout the night. |

**Durante** can become **during, for**, or **throughout**, depending on whether it introduces an event, duration, or complete span.
