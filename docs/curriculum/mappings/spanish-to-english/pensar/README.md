# Translations of Spanish **Pensar**

Spanish **pensar** maps to English opinion, reflection, planning, and consideration expressions.

| Lesson | Spanish | English |
|---|---|---|
| [think for an opinion](01-think-for-an-opinion.md) | Pienso que el plan funcionará. | I think the plan will work. |
| [think about](02-think-about.md) | Estoy pensando en el problema. | I'm thinking about the problem. |
| [plan / intend to](03-plan-and-intend-to.md) | Pienso viajar en diciembre. | I plan to travel in December. |
| [consider doing](04-consider-doing.md) | Estoy pensando en cambiar de trabajo. | I'm considering changing jobs. |
| [related nouns](05-related-nouns.md) | Es un pensamiento interesante. | It's an interesting thought. |
