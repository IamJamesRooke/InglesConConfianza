# Spanish **Último**

| Spanish | English |
|---|---|
| Fue el último en llegar. | He was the last to arrive. |
| Leí su último libro. | I read her latest book. |
| Esta es la última pregunta. | This is the final question. |
| Últimamente trabajo desde casa. | Lately, I have been working from home. |

**Último** can become **last, latest**, or **final**; related **últimamente** means **lately**, not *ultimately*.
