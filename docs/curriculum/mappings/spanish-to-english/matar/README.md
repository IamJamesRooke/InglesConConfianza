# Spanish **Matar**

| Spanish | English |
|---|---|
| El veneno mató al insecto. | The poison killed the insect. |
| Matamos el tiempo jugando cartas. | We killed time by playing cards. |
| Ese ruido me mata. | That noise is killing me. |

Literal **matar** is **kill**. Time and intense annoyance can also use figurative **kill** in English.
