# Spanish-to-English Mappings

These maps begin with a Spanish word, form, or construction whose natural English changes with meaning, function, or context. The folders are intentionally flat: a learner starts with the Spanish form, not with a grammatical category.

Each `translations-*` folder is one mapping family. Its README gives the complete map, and its micro-lessons teach the individual choices.
