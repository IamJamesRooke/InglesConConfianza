# Spanish-to-English Mappings

These maps begin with a frequent Spanish source word whose natural English changes with meaning, function, or context. Inflected forms and multiword expressions live under their canonical source word.

Personal-pronoun and article maps remain intentionally complete top-level reference families. Common prepositional expressions such as **para él** and **con él** stay inside the corresponding pronoun folder even when the basic subject translation is one-to-one.
