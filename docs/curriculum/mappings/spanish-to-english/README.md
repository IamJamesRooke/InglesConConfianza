# Spanish-to-English Mappings

These maps begin with a Spanish word, form, or construction whose natural English changes with meaning, function, or context.

Each folder represents one source form or one deliberate pedagogical family. A family remains together when its shared sound, contrast, or construction is itself the teaching point.
