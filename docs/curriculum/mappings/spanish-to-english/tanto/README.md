# Translations of Spanish **Tanto**

Spanish **tanto**, including its agreeing forms **tanta, tantos**, and **tantas**, maps to English quantity, comparison, and fixed expressions.

| Lesson | Spanish | English |
|---|---|---|
| [so much / so many](01-so-much-many.md) | Tengo tanto trabajo y tantas reuniones. | I have so much work and so many meetings. |
| [as much / as many as](02-as-much-many-as.md) | Trabaja tanto como yo. | She works as much as I do. |
| [meanwhile](03-meanwhile.md) | Mientras tanto, espera aquí. | Meanwhile, wait here. |

See [**tan**](../tan/README.md) for adjective and adverb comparisons.
