# Order Words

| Spanish | English |
|---|---|
| primero | first / 1st |
| segundo | second / 2nd |
| tercero | third / 3rd |
| próximo / siguiente | next |
| último | last |

| Spanish | English |
|---|---|
| Esta es mi primera reunión del día. | This is my first meeting of the day. |
| La próxima reunión es a las tres. | The next meeting is at three. |
| Esta es la última reunión. | This is the last meeting. |

**Second** can mean the time unit **segundo** or the order word **segundo**. Context resolves the meaning.
