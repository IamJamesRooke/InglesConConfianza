# Spanish **Servir**

| Spanish | English |
|---|---|
| Sirvieron la cena a las siete. | They served dinner at seven. |
| Esta llave no sirve. | This key doesn't work. |
| Esta mesa sirve de escritorio. | This table serves as a desk. |
| ¿Te sirve el martes? | Does Tuesday work for you? |
| Sírvete café. | Help yourself to some coffee. |

**Servir** can mean serve, work or be useful, function as something, suit a schedule, or invite someone to help themselves.
