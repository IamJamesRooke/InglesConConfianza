# Spanish **Cobrar**

| Spanish | English |
|---|---|
| Cobran diez dólares por la entrada. | They charge ten dollars for admission. |
| Voy a cobrar el cheque. | I am going to cash the check. |
| Cobro el viernes. | I get paid on Friday. |
| El accidente cobró dos vidas. | The accident claimed two lives. |

**Cobrar** can become **charge, collect/cash, get paid**, or **claim** a life.
