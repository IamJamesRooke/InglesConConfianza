# Spanish **Solicitar**

| Spanish | English |
|---|---|
| Solicité una copia certificada. | I requested a certified copy. |
| Solicité una visa de trabajo. | I applied for a work visa. |
| La solicitud fue aprobada. | The request was approved. |

Use **request** for a formally requested thing. Applications for a visa, job, or program normally use **apply for**. The related noun **la solicitud** can be **request** or **application** according to purpose.
