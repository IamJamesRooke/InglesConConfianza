# Spanish **Conseguir**

| Spanish | English |
|---|---|
| Conseguí un trabajo nuevo. | I got a new job. |
| Conseguimos terminar a tiempo. | We managed to finish on time. |
| No consigo mis llaves. | I can't find my keys. |
| Consiguieron el permiso. | They secured permission. |

**Conseguir** may mean obtain something, manage to do something, find something, or secure an agreement or resource.
