# Translations of Spanish **Elegir**

Spanish **elegir** can map to choosing a thing or choosing to perform an action.

| Spanish | English |
|---|---|
| elegir algo | **to choose something** |
| elegir hacer algo | **to choose to do something** |

- [**elegir algo** → choose something](01-choose-something.md)
- [**elegir hacer algo** → choose to do something](02-choose-to-do-something.md)
