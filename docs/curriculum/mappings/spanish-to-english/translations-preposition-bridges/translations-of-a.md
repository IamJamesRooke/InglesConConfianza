# Translations of **A**

Spanish **a** changes according to its function.

| Function | Spanish | English |
|---|---|---|
| destination | Voy a la oficina. | I am going to the office. |
| clock time | La reunión es a las tres. | The meeting is at three. |
| personal **a** with a direct object | Veo a Laura. | I see Laura. |
| recipient | Le doy el libro a Laura. | I give the book to Laura. |

The Spanish personal **a** before a person is not translated separately when that person is the direct object:

- **Veo a Laura.** → **I see Laura.**
- Not: *I see to Laura.*

Use **to** when the person is a recipient: **I give the book to Laura.**
