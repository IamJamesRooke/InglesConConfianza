# Translations of Spanish **Lucir** and **Lucirse**

Spanish **lucir** and **lucirse** map to shining, looking, wearing, displaying, showing off, and performing exceptionally well.

| Lesson | Spanish | English |
|---|---|---|
| [**Lucir → Shine**](01-shine.md) | Las estrellas lucían sobre la montaña. | The stars shone above the mountain. |
| [**Lucir → Look**](02-look.md) | Luces muy elegante hoy. | You look very elegant today. |
| [**Lucir → Wear / Sport**](03-wear.md) | Lucía un vestido rojo. | She was wearing a red dress. |
| [**Lucir → Display / Show Off**](04-display-or-show.md) | El museo luce una colección nueva. | The museum is displaying a new collection. |
| [**Lucirse → Show Off**](05-show-off.md) | Le encanta lucirse frente a sus amigos. | He loves showing off in front of his friends. |
| [**Lucirse → Do Brilliantly / Excel**](06-do-brilliantly.md) | Ana se lució en la presentación. | Ana did brilliantly in the presentation. |
| [**Lucirle Bien A Alguien → Look Good On**](07-look-good-on.md) | Ese color te luce bien. | That color looks good on you. |
| [**Hacer Lucir → Make Look / Bring Out**](08-bring-out.md) | La luz hace lucir más grande el salón. | The lighting makes the room look bigger. |
