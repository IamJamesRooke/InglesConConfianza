# Spanish **Pronto**

| Spanish | English |
|---|---|
| Vuelve pronto. | Come back soon. |
| Terminó más pronto de lo esperado. | She finished earlier than expected. |
| De pronto empezó a llover. | Suddenly, it started raining. |
| De pronto está en casa. | Maybe she is at home. |

**Pronto** is usually **soon**. **De pronto** can mean **suddenly** or, especially in Colombian speech, **maybe**.
