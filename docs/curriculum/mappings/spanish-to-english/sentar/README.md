# Spanish **Sentar**

| Spanish | English |
|---|---|
| Sentaron a los niños juntos. | They seated the children together. |
| Siéntate aquí. | Sit down here. |
| La decisión sentó un precedente. | The decision set a precedent. |
| Esa experiencia sentó las bases del proyecto. | That experience laid the foundation for the project. |

Transitive **sentar** seats someone; **sentarse** means sit down. Fixed combinations may require **set** or **lay**.
