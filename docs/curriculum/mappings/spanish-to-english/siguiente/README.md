# Spanish **Siguiente**

| Spanish | English |
|---|---|
| Nos vemos la semana siguiente. | See you the following week. |
| La siguiente persona puede entrar. | The next person may enter. |
| Haz lo siguiente. | Do the following. |
| Al día siguiente, llamó Laura. | The next day, Laura called. |

**Siguiente** can become **next** or **following**, with English position determined by the complete phrase.
