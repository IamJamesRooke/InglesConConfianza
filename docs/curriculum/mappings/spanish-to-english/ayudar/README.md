# Spanish **Ayudar**

| Spanish | English |
|---|---|
| Ayudé a Laura con el informe. | I helped Laura with the report. |
| Esta medicina ayuda a reducir el dolor. | This medicine helps reduce pain. |
| Ayúdate de esta herramienta. | Use this tool to help yourself. |

Ordinary assistance uses **help**. Reflexive **ayudarse de** may become **use** or **make use of** a tool or resource.
