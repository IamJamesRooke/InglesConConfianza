# Ability, Permission, and Possibility

| Meaning | Spanish | English |
|---|---|---|
| Ability | Ana puede conducir. | Ana can drive. |
| Permission | Ana puede usar mi carro. | Ana can use my car. |
| Possibility | Ana podría llegar tarde. | Ana might arrive late. |

The surrounding context—not **poder** alone—determines which English structure expresses the intended meaning.
