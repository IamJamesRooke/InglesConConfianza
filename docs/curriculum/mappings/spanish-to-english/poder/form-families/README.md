# Compressed Form Families of Spanish **Poder**

Each file is one curriculum family. Its `forms` are independently trackable surface forms, while its nested `mappings` retain the stable atomic translation IDs used by reverse links.

An exercise can therefore count exposure at four levels: the lemma **poder**, a family such as **present indicative**, a specific form such as **puedo** or **puede**, and the atomic meaning exercised in that sentence.
