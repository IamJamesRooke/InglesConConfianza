# Spanish **Soportar**

| Spanish | English |
|---|---|
| No soporto el ruido. | I can't stand the noise. |
| La mesa soporta mucho peso. | The table supports a lot of weight. |
| Soportó años de presión. | She endured years of pressure. |
| El puente puede soportar el camión. | The bridge can bear the truck's weight. |

**Soportar** can become **stand, support, endure**, or **bear**. English **support** is not always the natural choice.
