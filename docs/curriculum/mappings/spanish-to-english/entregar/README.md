# Spanish **Entregar**

| Spanish | English |
|---|---|
| Entregaron el paquete. | They delivered the package. |
| Entrega la tarea mañana. | Hand in the assignment tomorrow. |
| Le entregó las llaves al dueño. | She handed the keys over to the owner. |
| El sospechoso se entregó. | The suspect turned himself in. |

**Entregar** can become **deliver, hand in, hand over**, or, pronominally, **turn oneself in/surrender**.
