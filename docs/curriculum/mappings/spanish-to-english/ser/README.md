# Spanish **Ser**

| Spanish | English |
|---|---|
| Laura es médica. | Laura is a doctor. |
| La reunión es mañana. | The meeting takes place tomorrow. |
| La mesa es de madera. | The table is made of wood. |
| Este libro es de Mateo. | This book belongs to Mateo. |
| Este regalo es para ti. | This gift is meant for you. |

Spanish **ser** often becomes **be**, but ownership, material, purpose, and events may require a fuller English expression.
