# Spanish **Asegurar**

| Spanish | English |
|---|---|
| Asegura que la puerta esté cerrada. | Make sure the door is locked. |
| Te aseguro que es verdad. | I assure you that it is true. |
| Aseguraron el carro. | They insured the car. |
| Asegura bien la cuerda. | Secure the rope firmly. |
| El testigo aseguró que lo vio. | The witness stated that he saw him. |

**Asegurar** can mean make sure, assure, insure, secure, or state something confidently.
