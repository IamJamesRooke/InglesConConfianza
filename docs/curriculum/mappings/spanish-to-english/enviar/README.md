# Spanish **Enviar**

| Spanish | English |
|---|---|
| Envié un mensaje. | I sent a message. |
| La tienda envió el paquete ayer. | The store shipped the package yesterday. |
| Te envié el correo de Laura. | I forwarded Laura's email to you. |
| El médico me envió a un especialista. | The doctor referred me to a specialist. |

**Enviar** can become **send, ship, forward**, or **refer**, according to what is being directed and where.
