# Spanish **Ir**

| Spanish | English |
|---|---|
| Voy al trabajo. | I am going to work. |
| Voy a llamar a Laura. | I am going to call Laura. |
| Esa camisa te va bien. | That shirt suits you. |
| ¿Cómo va el proyecto? | How is the project going? |
| Ya me voy. | I am leaving now. |

Movement uses **go**, while **ir a**, **irle bien**, progress, and **irse** map to different English constructions.
