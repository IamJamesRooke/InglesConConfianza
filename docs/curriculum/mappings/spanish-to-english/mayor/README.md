# Spanish **Mayor**

| Spanish | English |
|---|---|
| Mi hermana mayor vive en Cali. | My older sister lives in Cali. |
| Es mayor que yo. | She is older than I am. |
| Es un problema mayor. | It is a major problem. |
| La mayoría votó a favor. | The majority voted in favor. |

**Mayor** can become **older, larger/greater**, or **major**; related **mayoría** is **majority**.
