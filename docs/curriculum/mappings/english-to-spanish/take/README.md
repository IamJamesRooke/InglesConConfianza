# Spanish Translations of English **Take**

The remaining English **take** sources map to different unprocessed Spanish verbs for carrying away, time, transport, photographs, exams, and acceptance.

| Lesson | English | Spanish |
|---|---|---|
| [**Take → Tardar**](02-take-time.md) | It takes an hour. | Tarda una hora. |
| [**Take → Coger** Transport](03-transport.md) | We take the bus to work. | Cogemos el bus para ir al trabajo. |
| [**Take → Sacar** a Photo](05-photos.md) | Can you take a photo of us? | ¿Puedes sacarnos una foto? |
| [**Take → Presentar** an Exam](06-courses-and-exams.md) | I'm taking an exam tomorrow. | Mañana presento un examen. |
| [**Take → Aceptar / Requerir**](07-accept-or-require.md) | The job takes patience, and I won't take excuses. | El trabajo requiere paciencia y no aceptaré excusas. |
