# English **Draw**

| English | Spanish |
|---|---|
| Draw a picture of the house. | Dibuja la casa. |
| Draw the curtains. | Cierra las cortinas. |
| The teams drew two to two. | Los equipos empataron dos a dos. |
| The event drew a large crowd. | El evento atrajo a mucha gente. |
| What conclusion can we draw? | ¿Qué conclusión podemos sacar? |

**Draw** can mean create a picture, pull something, tie a contest, attract attention, or derive a conclusion.
