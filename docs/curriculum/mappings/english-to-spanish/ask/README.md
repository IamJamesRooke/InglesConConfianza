# English **Ask**

| English | Spanish |
|---|---|
| Ask a question. | Haz una pregunta. |
| Ask Laura what happened. | Pregúntale a Laura qué pasó. |
| Ask for the bill. | Pide la cuenta. |
| Ask him to wait. | Pídele que espere. |
| Mateo asked Diana out. | Mateo invitó a Diana a salir. |

Requests for information use **preguntar**; requests for things or actions use **pedir**. English **ask out** normally becomes **invitar a salir**.
