# English **Lose**

| English | Spanish |
|---|---|
| I lost my keys. | Perdí mis llaves. |
| We missed the bus. | Perdimos el bus. |
| I got lost downtown. | Me perdí en el centro. |
| She lost weight. | Bajó de peso. |
| I lost track of time. | Perdí la noción del tiempo. |

General loss and missed transport use **perder**. Getting lost is **perderse**, while weight and other fixed combinations may choose another verb.
