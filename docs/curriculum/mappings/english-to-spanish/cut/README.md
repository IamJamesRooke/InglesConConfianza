# English **Cut**

| English | Spanish |
|---|---|
| Cut the paper. | Corta el papel. |
| They cut the budget. | Redujeron el presupuesto. |
| The storm cut the power. | La tormenta interrumpió la electricidad. |
| Cut the sentence from the report. | Elimina la oración del informe. |
| The road cuts through the forest. | La carretera atraviesa el bosque. |

Physical cutting, reduction, interruption, deletion, and crossing a space require different Spanish choices.
