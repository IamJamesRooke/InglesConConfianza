# English **Hear**

| English | Spanish |
|---|---|
| I can hear music. | Oigo música. |
| Hear me out before you decide. | Escúchame antes de decidir. |
| I heard about the change yesterday. | Me enteré del cambio ayer. |
| Have you heard from Mateo? | ¿Has sabido algo de Mateo? |

Perceiving sound uses **oír**. Deliberate attention, receiving news, and receiving contact use **escuchar, enterarse de**, or **saber de**.
