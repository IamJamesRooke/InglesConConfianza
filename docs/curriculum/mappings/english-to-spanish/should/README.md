# English **Should**

| English | Spanish |
|---|---|
| You should rest. | Deberías descansar. |
| The bus should arrive at eight. | El bus debería llegar a las ocho. |
| You should have called me. | Deberías haberme llamado. |
| If you should need help, call me. | Si llegaras a necesitar ayuda, llámame. |

**Should** can express advice, expectation, criticism of the past, or a remote condition. Spanish changes the complete structure accordingly.
