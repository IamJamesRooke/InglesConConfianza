# Spanish Translations of English **Call**

English **call** covers telephone contact, naming, summoning, describing, decisions, cancellation, brief visits, and demands.

| Lesson | English | Spanish |
|---|---|---|
| [**Call → Llamar** by Phone](01-phone.md) | Call Ana when you arrive. | Llama a Ana cuando llegues. |
| [**Be Called → Llamarse**](02-name.md) | This dish is called a tamal, and the restaurant is called El Patio. | Este plato se llama tamal y el restaurante se llama El Patio. |
| [**Call → Llamar / Mandar Llamar**](03-summon.md) | Call the doctor immediately. | Llama al médico de inmediato. |
| [**Call → Llamar / Considerar**](04-describe-as.md) | I call that a serious mistake. | Yo considero que eso es un error grave. |
| [**Call Off → Cancelar**](05-call-off.md) | They called off the meeting. | Cancelaron la reunión. |
| [**Call On → Pedir / Visitar**](06-call-on.md) | The teacher called on me to answer. | La profesora me pidió que respondiera. |
| [**Call For → Requerir / Exigir**](07-call-for.md) | This situation calls for patience. | Esta situación requiere paciencia. |
| [**Call Back → Devolver La Llamada**](08-call-back.md) | I'll call you back after lunch. | Te devuelvo la llamada después del almuerzo. |
