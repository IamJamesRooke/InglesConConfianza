# English **Maybe**

## Atomic mappings

- [**maybe** → **quizá / quizás**](<maybe (quizá - uncertain possibility).md>)

## Teaching overview

| English | Spanish |
|---|---|
| Maybe Laura is at home. | Quizás Laura esté en casa. |
| Maybe we should call first. | Tal vez deberíamos llamar primero. |
| Maybe he forgot. | A lo mejor se le olvidó. |

**Maybe** can become **quizás, tal vez**, or conversational **a lo mejor**, with mood choices determined by certainty and style.
