# English **Might**

| English | Spanish |
|---|---|
| It might rain. | Podría llover. / Quizás llueva. |
| She might have forgotten. | Podría haberlo olvidado. |
| We might as well leave now. | Más vale que salgamos ya. |
| They fought with all their might. | Lucharon con todas sus fuerzas. |

Modal **might** expresses uncertain possibility. **Might as well** is a practical conclusion, while noun **might** means strength or power.
