# English **Watch**

| English | Spanish |
|---|---|
| We watched a movie. | Vimos una película. |
| Watch the screen carefully. | Mira la pantalla con atención. |
| Watch the door. | Vigila la puerta. |
| Can you watch the children? | ¿Puedes cuidar a los niños? |
| Watch out! | ¡Cuidado! |

Entertainment may use **ver**, deliberate viewing **mirar**, guarding **vigilar**, and caring for someone **cuidar**.
