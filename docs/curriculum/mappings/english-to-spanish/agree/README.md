# English **Agree**

| English | Spanish |
|---|---|
| I agree with Laura. | Estoy de acuerdo con Laura. |
| We agreed on a date. | Acordamos una fecha. |
| I agreed to the proposal. | Acepté la propuesta. |
| The two reports agree. | Los dos informes coinciden. |

Personal agreement uses **estar de acuerdo**. Decisions, acceptance, and matching information use **acordar, aceptar**, or **coincidir**.
