# English **New**

| English | Spanish |
|---|---|
| I bought a new phone. | Compré un teléfono nuevo. |
| Are you new here? | ¿Eres nuevo aquí? |
| We need a new plan. | Necesitamos otro plan. |
| What is new? | ¿Qué hay de nuevo? |

**New** can become **nuevo** for novelty or **otro** when replacing an earlier option; fixed questions such as **what is new?** require a complete expression.
