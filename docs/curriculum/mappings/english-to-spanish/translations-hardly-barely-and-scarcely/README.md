# False-Friend and Interference Map: **hardly barely and scarcely**

| Lesson | English | Spanish |
|---|---|---|
| [hardly](01-hardly.md) | I hardly know him. | Casi no lo conozco. |
| [barely](02-barely.md) | We barely arrived on time. | Apenas llegamos a tiempo. |
| [scarcely](03-scarcely.md) | There was scarcely any food. | Casi no había comida. |
| [inversion](04-inversion.md) | Hardly had I arrived when she left. | Apenas había llegado cuando ella se fue. |
| [not-hardly](05-not-hardly.md) | I can hardly wait. | Estoy ansioso por que llegue. |
