# English **Again**

| English | Spanish |
|---|---|
| Please say it again. | Dilo otra vez, por favor. |
| She called again. | Volvió a llamar. |
| We are together again. | Estamos juntos de nuevo. |
| Then again, the cheaper option may be better. | Aunque, pensándolo bien, la opción más barata puede ser mejor. |

Repetition uses **otra vez, de nuevo**, or **volver a + infinitive**. Discourse **then again** requires a separate reconsideration expression.
