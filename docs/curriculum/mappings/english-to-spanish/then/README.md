# English **Then**

| English | Spanish |
|---|---|
| If you agree, then sign here. | Si estás de acuerdo, entonces firma aquí. |
| We ate and then left. | Comimos y luego nos fuimos. |
| Back then, I lived in Cali. | En aquel entonces, vivía en Cali. |
| See you then. | Nos vemos a esa hora. |

Consequence **then** is usually **entonces**; sequence often uses **luego** or **después**. A previously established time may need **a esa hora**.
