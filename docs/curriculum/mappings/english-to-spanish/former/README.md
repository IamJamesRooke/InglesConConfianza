# English **Former**

| English | Spanish |
|---|---|
| My former boss called. | Me llamó mi antiguo jefe. |
| The former president spoke. | Habló el expresidente. |
| Of coffee and tea, I prefer the former. | Entre café y té, prefiero el primero. |

Previous roles use **antiguo/anterior** or prefix **ex-**. Contrastive noun **the former** means **el primero**.
