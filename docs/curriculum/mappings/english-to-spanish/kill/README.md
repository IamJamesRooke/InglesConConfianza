# English **Kill**

| English | Spanish |
|---|---|
| The poison killed the insect. | El veneno mató al insecto. |
| We killed time by talking. | Matamos el tiempo hablando. |
| Turn off the engine. | Apaga el motor. |
| That joke killed the conversation. | Ese chiste acabó con la conversación. |

Literal and figurative death may use **matar**. Stopping machinery or ending an activity naturally uses **apagar** or **acabar con**.
