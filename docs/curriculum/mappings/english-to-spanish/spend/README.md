# Uses of **Spend**

English **spend** changes according to what is being used: money is **gastar**, while time is commonly **pasar** or **compartir**.

| Lesson | Spanish | English |
|---|---|---|
| [Spend Money](01-spend-money.md) | Gasté veinte mil pesos. | I spent twenty thousand pesos. |
| [Spend Time](02-spend-time.md) | Paso tiempo con mi familia. | I spend time with my family. |
