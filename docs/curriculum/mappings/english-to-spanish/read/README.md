# English **Read**

| English | Spanish |
|---|---|
| I read the report yesterday. | Leí el informe ayer. |
| The sign reads “No entry.” | El letrero dice «Prohibido entrar». |
| Read the sentence aloud. | Lee la oración en voz alta. |
| The technician read the results. | El técnico interpretó los resultados. |

Ordinary **read** uses **leer**. Signs often **dicen** something, and technical readings may require **interpretar**.

| English family | Spanish |
|---|---|
| read | leer |
| read up on something | informarse sobre algo leyendo |
| read through something | leer algo completo |

**I read the news in English every morning. → Leo las noticias en inglés todas las mañanas.**

**Read up on** means study a subject through reading; **read through** means read something from beginning to end or carefully.
