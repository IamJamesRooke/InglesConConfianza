# **Which** for a Known Set

| Spanish | English |
|---|---|
| ¿Cuál libro quieres, este o ese? | Which book do you want, this one or that one? |
| ¿Qué opción prefieres de estas tres? | Which option do you prefer out of these three? |

Use **which** when the speaker and listener can identify a limited or understood set of choices. Spanish may use **cuál** or **qué** depending on the sentence.
