# English **Provide**

| English | Spanish |
|---|---|
| The company provides training. | La empresa ofrece capacitación. |
| We provide food to the families. | Les damos alimentos a las familias. |
| The law provides that payments must be monthly. | La ley establece que los pagos deben ser mensuales. |

Supplying, offering a service, and formally establishing a rule use **proporcionar/dar, ofrecer**, or **establecer**.
