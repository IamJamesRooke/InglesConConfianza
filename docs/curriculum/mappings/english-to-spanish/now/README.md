# English **Now**

| English | Spanish |
|---|---|
| I am busy now. | Estoy ocupado ahora. |
| Do it now. | Hazlo ya. |
| Now that you are here, we can begin. | Ahora que estás aquí, podemos empezar. |
| For now, this is enough. | Por ahora, esto es suficiente. |

**Ahora** locates the present moment. Urgent **now** often becomes **ya**, while **now that** and **for now** map as complete expressions.
