# English **Remain**

| English | Spanish |
|---|---|
| Two tickets remain. | Quedan dos entradas. |
| Please remain seated. | Por favor, permanezca sentado. |
| She remained calm. | Siguió tranquila. |
| The question remains unanswered. | La pregunta sigue sin respuesta. |

Quantity uses **quedar**, formal continuation **permanecer**, and a continuing state often **seguir**.
