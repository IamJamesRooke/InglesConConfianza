# English **Care**

| English | Spanish |
|---|---|
| I care about this project. | Este proyecto me importa. |
| She cares for her father. | Ella cuida a su padre. |
| Would you care for some coffee? | ¿Te gustaría un café? |
| I don't care which one we choose. | No me importa cuál elijamos. |

Concern uses **importar** or **preocuparse por**; caregiving uses **cuidar**. Polite offers with **care for** normally use **gustaría**.
