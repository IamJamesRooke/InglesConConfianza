# English **Real**

| English | Spanish |
|---|---|
| Is the story real? | ¿La historia es real? |
| The real problem is time. | El verdadero problema es el tiempo. |
| She is a real expert. | Es toda una experta. |
| For real? | ¿En serio? |

Existence uses **real**, truth or identity **verdadero**, emphasis a fuller phrase, and informal confirmation **en serio**.
