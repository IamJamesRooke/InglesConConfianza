# English **Hope**

| English | Spanish |
|---|---|
| I hope Laura comes. | Espero que Laura venga. |
| Hopefully, it won't rain. | Ojalá no llueva. |
| We hope for a better result. | Deseamos un resultado mejor. |
| I hope so. | Eso espero. |

**Hope** may use **esperar que + subjunctive, ojalá**, or **desear**, and short responses reverse normal word order.
