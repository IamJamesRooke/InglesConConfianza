# English **Must**

| English | Spanish |
|---|---|
| You must show your ID. | Tienes que mostrar tu documento. |
| She must be at home. | Debe de estar en casa. |
| You must not enter. | No debes entrar. / Está prohibido entrar. |
| They must have forgotten. | Deben de haberlo olvidado. |

Obligation uses **tener que** or **deber**. Logical deduction often uses **deber de** or **seguro que**. Negative **must not** normally expresses prohibition.
