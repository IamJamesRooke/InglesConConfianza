# English **Big**

| English | Spanish |
|---|---|
| They live in a big house. | Viven en una casa grande. |
| It was a big decision. | Fue una decisión importante. |
| She is a big fan of the team. | Es muy aficionada al equipo. |
| The news became a big deal. | La noticia se volvió algo muy importante. |

Physical size uses **grande**. Importance, enthusiasm, and **big deal** require a different Spanish expression.
