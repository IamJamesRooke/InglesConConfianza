# English **Pull**

| English | Spanish |
|---|---|
| Pull the door. | Jala la puerta. |
| Pull the paper out. | Saca el papel. |
| The advertisement pulled in new customers. | El anuncio atrajo clientes nuevos. |
| Pull over here. | Oríllate aquí. |

Physical pulling, removal, attraction, and moving a vehicle to the side use different Spanish verbs.
