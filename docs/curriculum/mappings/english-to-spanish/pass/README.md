# Spanish Translations of English **Pass**

English **pass** covers movement, transfer, exams, overtaking, time, opportunities, enactment, and death.

| Lesson | English | Spanish |
|---|---|---|
| [**Pass → Dar**](02-hand-something.md) | Pass me the salt, please. | Dame la sal, por favor. |
| [**Pass → Aprobar**](03-pass-an-exam.md) | She passed the exam on her first try. | Aprobó el examen en el primer intento. |
| [**Pass → Adelantar / Sobrepasar**](04-overtake.md) | A truck passed us on the highway. | Un camión nos adelantó en la carretera. |
| [**Pass → Transcurrir**](05-time-passes.md) | Time passed quickly. | El tiempo transcurrió rápido. |
| [**Pass Up → Dejar Pasar**](06-pass-up.md) | Don't pass up that opportunity. | No dejes pasar esa oportunidad. |
| [**Pass → Aprobar** a Law](07-pass-a-law.md) | Congress passed the law. | El Congreso aprobó la ley. |
| [**Pass Away → Fallecer**](08-pass-away.md) | Her grandfather passed away last year. | Su abuelo falleció el año pasado. |
