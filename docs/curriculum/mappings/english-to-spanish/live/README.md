# English **Live**

| English | Spanish |
|---|---|
| I live in Bogotá. | Vivo en Bogotá. |
| The concert is live. | El concierto es en vivo. |
| The wire is live. | El cable tiene corriente. |
| We must live with the decision. | Tenemos que aceptar la decisión. |
| Live up to your promise. | Cumple tu promesa. |

Verb **live**, broadcast **live**, energized equipment, and the fixed expressions **live with/up to** require different Spanish mappings.
