# English **Same**

| English | Spanish |
|---|---|
| We have the same book. | Tenemos el mismo libro. |
| The two prices are the same. | Los dos precios son iguales. |
| It is all the same to me. | Me da igual. |
| At the same time, it is risky. | Al mismo tiempo, es arriesgado. |

Shared identity uses **mismo**, equality **igual**, indifference **dar igual**, and fixed time expressions **al mismo tiempo**.
