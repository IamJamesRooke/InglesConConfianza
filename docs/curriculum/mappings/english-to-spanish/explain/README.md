# English **Explain**

| English | Spanish |
|---|---|
| Explain the rule to me. | Explícame la regla. |
| Can you explain what happened? | ¿Puedes aclarar qué pasó? |
| How do you explain the missing money? | ¿Cómo justificas el dinero que falta? |

Ordinary explanation uses **explicar**, clarification **aclarar**, and giving an account for suspicious facts **justificar**.
