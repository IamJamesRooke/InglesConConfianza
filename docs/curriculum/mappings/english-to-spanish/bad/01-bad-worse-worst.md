# **Bad → Worse → the Worst**

| Spanish | English |
|---|---|
| Esta opción es mala. | This option is bad. |
| Esta opción es peor que esa. | This option is worse than that one. |
| Esta es la peor opción. | This is the worst option. |

These are irregular comparison forms. Do not use *badder* or *the baddest* for the ordinary comparison.
