# English **Cover**

| English | Spanish |
|---|---|
| Cover the food. | Tapa la comida. |
| The course covers five topics. | El curso abarca cinco temas. |
| Insurance covers the damage. | El seguro cubre los daños. |
| Can you cover my shift? | ¿Puedes reemplazarme en mi turno? |
| We covered twenty kilometers. | Recorrimos veinte kilómetros. |

Physical covering, including a scope, paying a cost, substituting for someone, and traveling a distance require different Spanish choices.
