# English **Know**

| English | Spanish |
|---|---|
| I know the answer. | Sé la respuesta. |
| I know Bogotá well. | Conozco bien Bogotá. |
| I know how to drive. | Sé manejar. |
| I know the poem by heart. | Me sé el poema de memoria. |
| I want to get to know your family. | Quiero conocer a tu familia. |

Use **saber** for facts and learned abilities, and **conocer** for people, places, and familiarity. Some familiar material can use pronominal **saberse**.
