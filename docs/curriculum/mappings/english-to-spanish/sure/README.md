# English **Sure**

| English | Spanish |
|---|---|
| I am sure that she called. | Estoy seguro de que llamó. |
| Make sure the door is locked. | Asegúrate de que la puerta esté cerrada. |
| Sure, I can help. | Claro, puedo ayudar. |
| Are you sure? | ¿Estás seguro? |

Certainty uses **seguro**, verification **asegurarse**, and conversational agreement **claro**.
