# English **Next**

This canonical source bucket owns **next** and expressions built from it. Depending on context, **next** points to sequence, the nearest future time, what happens afterward, or an adjacent position.

| English use | Common Spanish |
|---|---|
| the next item | el siguiente elemento |
| next week | la próxima semana |
| What happened next? | ¿Qué pasó después? |
| [next to the office](<next to.md>) | al lado de / junto a la oficina |

The individual **next** meanings will become atomic YAML objects during the later normalization pass. This phase establishes their canonical physical owner without inventing a separate `next-to` source bucket.
