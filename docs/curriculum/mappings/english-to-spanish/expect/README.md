# English **Expect**

| English | Spanish |
|---|---|
| I expect Laura at eight. | Espero a Laura a las ocho. |
| We expect prices to rise. | Prevemos que subirán los precios. |
| I expect you to arrive on time. | Espero que llegues a tiempo. |
| She is expecting a baby. | Está embarazada. |

Waiting for an arrival, forecasting, setting an expectation, and pregnancy all use **esperar** or a more precise verb such as **prever**, with different patterns.
