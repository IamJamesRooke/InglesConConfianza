# English **Great**

| English | Spanish |
|---|---|
| That is a great idea. | Es una idea excelente. |
| We had a great time. | La pasamos muy bien. |
| Bolívar was a great leader. | Bolívar fue un gran líder. |
| Great! See you tomorrow. | ¡Genial! Nos vemos mañana. |

Quality, enjoyment, historical importance, and enthusiastic reaction use **excelente, muy bien, gran**, or **genial**.
