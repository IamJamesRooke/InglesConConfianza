# English **Save**

| English | Spanish |
|---|---|
| The firefighter saved the child. | El bombero salvó al niño. |
| Save the file before closing it. | Guarda el archivo antes de cerrarlo. |
| We are saving money for a trip. | Estamos ahorrando dinero para un viaje. |
| This method saves time. | Este método ahorra tiempo. |
| The museum saved the old building. | El museo conservó el edificio antiguo. |

Rescue uses **salvar**, storage **guardar**, avoiding expenditure **ahorrar**, and preservation **conservar**.
