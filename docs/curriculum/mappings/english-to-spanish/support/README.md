# English **Support**

| English | Spanish |
|---|---|
| I support the proposal. | Apoyo la propuesta. |
| She supports her family. | Mantiene a su familia. |
| This wall supports the roof. | Esta pared sostiene el techo. |
| The evidence supports his claim. | La evidencia respalda su afirmación. |
| I can't support that weight. | No puedo soportar ese peso. |

Approval, financial maintenance, physical weight, evidence, and endurance use different Spanish verbs.
