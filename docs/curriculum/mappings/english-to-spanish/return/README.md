# English **Return**

| English | Spanish |
|---|---|
| Return the book tomorrow. | Devuelve el libro mañana. |
| The store returned my money. | La tienda me reembolsó el dinero. |
| Laura returned my call. | Laura me devolvió la llamada. |

Returning oneself with **volver** is now in the curriculum database; **regresar** remains a future family. Returning an object, money, or a call uses **devolver** or **reembolsar** and remains here.
