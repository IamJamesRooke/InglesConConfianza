# English **Return**

| English | Spanish |
|---|---|
| I returned home early. | Volví a casa temprano. |
| Return the book tomorrow. | Devuelve el libro mañana. |
| The store returned my money. | La tienda me reembolsó el dinero. |
| Laura returned my call. | Laura me devolvió la llamada. |

Returning oneself uses **volver** or **regresar**. Returning an object, money, or a call uses **devolver** or **reembolsar**.
