# English **And**

| English | Spanish |
|---|---|
| Laura and Mateo arrived. | Laura y Mateo llegaron. |
| Spanish and English are useful. | El español e inglés son útiles. |
| Try and call me tonight. | Intenta llamarme esta noche. |
| The noise grew louder and louder. | El ruido se hizo cada vez más fuerte. |

Ordinary **and** is **y**, but it changes to **e** before an **i/hi** sound. Some English coordination patterns require restructuring rather than a separate conjunction.
