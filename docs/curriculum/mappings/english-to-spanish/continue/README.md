# English **Continue**

| English | Spanish |
|---|---|
| Continue straight ahead. | Sigue derecho. |
| She continued working. | Siguió trabajando. |
| The meeting continued after lunch. | La reunión continuó después del almuerzo. |
| We will continue with the next topic. | Seguiremos con el siguiente tema. |

English **continue** may become **continuar** or **seguir**, and the form that follows changes with the construction.
