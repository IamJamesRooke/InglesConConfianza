# English **Late**

| English | Spanish |
|---|---|
| I arrived late. | Llegué tarde. |
| It is getting late. | Se está haciendo tarde. |
| The late professor wrote this book. | El profesor fallecido escribió este libro. |
| Her latest book is excellent. | Su último libro es excelente. |

Time uses **tarde**. Deceased **late** uses **fallecido**, while the latest item often maps to **último/más reciente**.
