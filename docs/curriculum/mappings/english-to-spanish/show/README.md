# Uses of **Show**

English **show** maps to **mostrar** for making something visible, **demostrar** for evidence, and **enseñar** for a procedure.

| Lesson | Spanish | English |
|---|---|---|
| [Show Something](01-show-somebody-something.md) | Le muestro la foto. | I show her the photo. |
| [Show Evidence](02-show-proof.md) | Los resultados lo demuestran. | The results show it. |
| [Show How](03-show-how.md) | Le enseño a usarla. | I show her how to use it. |
