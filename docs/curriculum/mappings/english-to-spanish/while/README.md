# Uses of **While**

| Lesson | Spanish | English |
|---|---|---|
| [**While** for Simultaneous Actions](01-while-for-simultaneous-actions.md) | Laura revisó el contrato mientras yo preparaba la presentación. | Laura reviewed the contract while I was preparing the presentation. |
| [**While** Versus **When**](02-while-versus-when.md) | Mientras conducía al trabajo, recibí una llamada cuando llegué al peaje. | While I was driving to work, I got a call when I reached the tollbooth. |
| [**While** for Contrast](03-while-meaning-although-or-whereas.md) | Aunque el apartamento es pequeño, tiene mucha luz; el otro, en cambio, es grande pero oscuro. | While the apartment's small, it's bright, while the other one's large but dark. |
| [**Meanwhile**](04-meanwhile.md) | Laura habló con el cliente; mientras tanto, yo corregí las cifras. | Laura spoke with the client; meanwhile, I corrected the figures. |
| [**Once in a While**](05-once-in-a-while.md) | De vez en cuando trabajo desde una cafetería para cambiar de ambiente. | Once in a while, I work from a café for a change of scenery. |
| [**For a While**](06-for-a-while.md) | Esperemos aquí un rato porque todavía está lloviendo. | Let's wait here for a while because it's still raining. |
| [**In a While**](07-in-a-while.md) | Estoy ocupada ahora, pero te llamo dentro de un rato. | I'm busy now, but I'll call you in a while. |
| [**It's Been a While**](08-its-been-a-while.md) | Ha pasado mucho tiempo desde que hablamos; deberíamos tomar un café. | It's been a while since we talked; we should grab a coffee. |
| [**After a While**](09-after-a-while.md) | Al principio el ruido me molestaba, pero después de un rato dejé de notarlo. | The noise bothered me at first, but after a while, I stopped noticing it. |
| [**All the While**](10-all-the-while.md) | Dijo que no sabía la respuesta, aunque la había sabido todo el tiempo. | He said he didn't know the answer, although he'd known it all the while. |
| [**A While** Versus **Awhile**](11-a-while-versus-awhile.md) | Quédate un rato; hace tiempo que no hablamos. | Stay awhile; it's been a while since we talked. |
| [**Worthwhile**](12-worthwhile.md) | El curso fue exigente, pero valió la pena porque conseguí un trabajo mejor. | The course was demanding, but it was worthwhile because I got a better job. |
| [Pronunciation: **While, Wild**, and **Whale**](13-pronunciation-while-wild-and-whale.md) | Mientras la ballena salvaje nadaba, esperamos un rato. | While the wild whale swam, we waited for a while. |

## Mastery Phrases

| Spanish | English |
|---|---|
| Mientras Laura hablaba con el cliente, yo corregí las cifras; mientras tanto, Carlos preparó el informe. | While Laura was talking to the client, I corrected the figures; meanwhile, Carlos prepared the report. |
| De vez en cuando nos quedamos un rato, pero ha pasado mucho tiempo desde la última vez. | Once in a while, we stay for a while, but it's been a while since the last time. |
| Mientras la ballena salvaje nadaba, esperamos un rato y, después de un tiempo, decidimos que la espera había valido la pena. | While the wild whale swam, we waited for a while, and after a while, decided the wait had been worthwhile. |
