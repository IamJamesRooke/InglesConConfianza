# English **Find**

| English | Spanish |
|---|---|
| I found my keys. | Encontré mis llaves. |
| We found out the truth. | Averiguamos la verdad. |
| I find this exercise difficult. | Este ejercicio me parece difícil. |
| The jury found him guilty. | El jurado lo declaró culpable. |

Physical discovery normally uses **encontrar**. Learning information, judging an experience, and reaching a formal verdict use different Spanish verbs.
