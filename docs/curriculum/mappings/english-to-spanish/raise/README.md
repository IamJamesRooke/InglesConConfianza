# English **Raise**

| English | Spanish |
|---|---|
| Raise your hand. | Levanta la mano. |
| They raised the price. | Subieron el precio. |
| She raised three children. | Crio a tres hijos. |
| We raised money for the school. | Recaudamos dinero para la escuela. |
| Laura raised an important question. | Laura planteó una pregunta importante. |

Lifting, increasing, raising children, collecting funds, and introducing a topic use five different common Spanish verbs.
