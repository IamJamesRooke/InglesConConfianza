# Spanish Translations of English **Work**

English **work** maps to labor, operation, suitability, successful results, exercise, calculation, and problem-solving.

| Lesson | English | Spanish |
|---|---|---|
| [**Work → Trabajar**](01-labor.md) | I work from home three days a week. | Trabajo desde casa tres días a la semana. |
| [**Work → Funcionar**](02-function.md) | The printer doesn't work. | La impresora no funciona. |
| [**Work → Servir / Funcionar**](03-suit-or-be-possible.md) | Friday works for me. | El viernes me sirve. |
| [**Work → Dar Resultado / Funcionar**](04-succeed.md) | The plan worked. | El plan funcionó. / El plan dio resultado. |
| [**Work Out → Hacer Ejercicio**](05-exercise.md) | I work out before breakfast. | Hago ejercicio antes del desayuno. |
| [**Work Out → Calcular / Resolver**](06-calculate.md) | We worked out the total together. | Calculamos el total juntos. |
| [**Work Out → Resolver / Salir Bien**](07-resolve-or-develop.md) | We worked out the problem, and everything worked out well. | Resolvimos el problema y todo salió bien. |
| [**Work On → Trabajar En**](08-work-on.md) | She's working on a new project. | Está trabajando en un proyecto nuevo. |
