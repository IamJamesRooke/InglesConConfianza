# English **Old**

| English | Spanish |
|---|---|
| The building is old. | El edificio es viejo. |
| It is an old tradition. | Es una tradición antigua. |
| My old job was stressful. | Mi trabajo anterior era estresante. |
| She is ten years old. | Tiene diez años. |

Age, antiquity, a former role, and age expressions require **viejo, antiguo, anterior**, or **tener + years**.
