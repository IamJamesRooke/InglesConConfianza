# English **Change**

| English | Spanish |
|---|---|
| Change the plan. | Cambia el plan. |
| I need to change clothes. | Necesito cambiarme de ropa. |
| Can you change a twenty-dollar bill? | ¿Puedes cambiar un billete de veinte dólares? |
| Keep the change. | Quédate con el cambio. |
| We changed buses downtown. | Hicimos transbordo en el centro. |

Alteration, clothing, exchanging money, coins returned, and switching transport do not all use the same Spanish structure.
