# English **Write**

| English | Spanish |
|---|---|
| Write your name here. | Escribe tu nombre aquí. |
| Write down the address. | Anota la dirección. |
| Write to me when you arrive. | Escríbeme cuando llegues. |
| She writes reports for the company. | Redacta informes para la empresa. |

General **write** uses **escribir**. Recording brief information and producing formal texts commonly use **anotar** and **redactar**.

| English family | Spanish |
|---|---|
| write | escribir |
| write down | anotar |
| write up a report | redactar un informe |

**I write a message in English every day. → Escribo un mensaje en inglés todos los días.**

**Write down** records information; **write up** develops notes or results into a complete report.
