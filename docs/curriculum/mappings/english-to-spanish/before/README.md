# English **Before**

| English | Spanish |
|---|---|
| We ate before the meeting. | Comimos antes de la reunión. |
| Call me before you leave. | Llámame antes de que salgas. |
| I had seen her before. | Ya la había visto. |
| The case came before the court. | El caso llegó ante el tribunal. |

Time before a noun uses **antes de** and before a clause **antes de que**. Earlier experience and formal presence before an authority use other structures.
