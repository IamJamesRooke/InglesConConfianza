# English **Report**

| English | Spanish |
|---|---|
| Report the problem to your manager. | Infórmale del problema a tu jefe. |
| She reported the theft to the police. | Denunció el robo ante la policía. |
| Report for work at eight. | Preséntate a trabajar a las ocho. |
| The newspaper reported that prices rose. | El periódico informó que subieron los precios. |

Providing information uses **informar**; reporting wrongdoing **denunciar**; presenting oneself **presentarse**.
