# Uses of **Feel**

English **feel** maps to **sentirse** for a state, **sentir** for a sensation, and **parecer/se siente** for an impression or physical quality.

| Lesson | Spanish | English |
|---|---|---|
| [Feel a State](01-feel-a-state.md) | Me siento más seguro. | I feel more confident. |
| [Physical Sensation](02-physical-sensation.md) | Siento frío. | I feel cold. |
| [It Feels](03-it-feels.md) | Parece difícil. | It feels difficult. |
