# Uses of **Send**

English **send** maps to **enviar, mandar**, or **hacer llegar**, depending on the object and delivery focus.

| Lesson | Spanish | English |
|---|---|---|
| [Send Something](01-send-something.md) | Le envío el documento. | I send her the document. |
| [Send or Have Delivered](02-send-or-have-delivered.md) | Le hice llegar el documento. | I sent him the document. |
