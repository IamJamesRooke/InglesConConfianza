# English **Wear**

| English | Spanish |
|---|---|
| Laura is wearing a blue jacket. | Laura lleva puesta una chaqueta azul. |
| Put on your glasses. | Ponte las gafas. |
| These shoes are wearing out. | Estos zapatos se están desgastando. |
| The pain will wear off soon. | El dolor se pasará pronto. |

Clothing uses **llevar, usar**, or **tener puesto**. Putting something on, physical deterioration, and an effect fading use different Spanish verbs.
