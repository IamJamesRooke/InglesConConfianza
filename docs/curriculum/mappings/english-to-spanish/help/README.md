# Uses of **Help**

English **help** maps to **ayudar**, but **help yourself** uses **servirse** and **can't help doing** uses **no poder evitar**.

| Lesson | Spanish | English |
|---|---|---|
| [Help Somebody](01-help-somebody.md) | Ayudo a mi compañero. | I help my classmate. |
| [Help Yourself](02-help-yourself.md) | Sírvase café. | Help yourself to coffee. |
| [Can't Help](03-cant-help.md) | No puedo evitar reírme. | I can't help laughing. |
