# English **Buy**

| English | Spanish |
|---|---|
| I bought a new phone. | Compré un teléfono nuevo. |
| I don't buy that excuse. | No me creo esa excusa. |
| She bought into the idea. | Se convenció de la idea. |
| This money can buy us time. | Este dinero puede darnos tiempo. |

Purchasing uses **comprar**. Believing an explanation, accepting an idea, and gaining an advantage require other Spanish verbs.
