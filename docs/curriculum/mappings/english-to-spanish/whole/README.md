# English **Whole**

| English | Spanish |
|---|---|
| I read the whole book. | Leí todo el libro. |
| She ate a whole apple. | Se comió una manzana entera. |
| The whole family came. | Vino toda la familia. |
| On the whole, the plan worked. | En general, el plan funcionó. |

**Whole** can become **todo** or **entero**, while **on the whole** means **en general**.
