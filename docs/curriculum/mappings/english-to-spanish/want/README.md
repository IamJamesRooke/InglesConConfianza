# English **Want**

| English | Spanish |
|---|---|
| I want coffee. | Quiero café. |
| I want to leave. | Quiero salir. |
| I want Laura to call me. | Quiero que Laura me llame. |
| The police want him for questioning. | La policía lo busca para interrogarlo. |

Ordinary **want** becomes **querer**. English **want + person + to** requires **querer que + subjunctive**, while the sense of being sought uses **buscar**.
