# English **Allow**

| English | Spanish |
|---|---|
| They allow children to enter. | Permiten que entren los niños. |
| Let me explain. | Déjame explicar. |
| Allow two hours for the trip. | Calcula dos horas para el viaje. |
| This card allows access to the building. | Esta tarjeta da acceso al edificio. |

Permission uses **permitir** or **dejar**. Reserving time and enabling access require **calcular** or **dar acceso**.
