# English **Build**

| English | Spanish |
|---|---|
| They built a house. | Construyeron una casa. |
| We are building a new team. | Estamos formando un equipo nuevo. |
| Pressure is building. | La presión está aumentando. |
| Build on what you already know. | Desarrolla lo que ya sabes. |

Construction uses **construir**. Forming groups, accumulation, and developing an existing base use different Spanish verbs.
