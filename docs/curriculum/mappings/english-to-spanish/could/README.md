# English **Could**

| English | Spanish |
|---|---|
| When I was young, I could run fast. | Cuando era joven, podía correr rápido. |
| I managed to open the door yesterday. | Ayer pude abrir la puerta. |
| It could rain later. | Podría llover más tarde. |
| Could you help me? | ¿Podrías ayudarme? |
| She could have called. | Podría haber llamado. |

Past ability, successful completion, possibility, politeness, and unreal past possibility do not all use the same Spanish form.
