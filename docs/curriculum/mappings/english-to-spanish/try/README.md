# English **Try**

| English | Spanish |
|---|---|
| Try to arrive early. | Intenta llegar temprano. |
| I want to try the soup. | Quiero probar la sopa. |
| Try on this jacket. | Pruébate esta chaqueta. |
| We are trying to solve the problem. | Estamos tratando de resolver el problema. |

Effort uses **intentar** or **tratar de**. Testing, tasting, and trying on use **probar** or **probarse**.
