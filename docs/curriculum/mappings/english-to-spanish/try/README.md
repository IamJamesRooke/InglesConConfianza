# English **Try**

| English | Spanish |
|---|---|
| Try to arrive early. | Intenta llegar temprano. |
| I want to try the soup. | Quiero probar la sopa. |
| Try on this jacket. | Pruébate esta chaqueta. |
| We are trying to solve the problem. | Estamos tratando de resolver el problema. |

Effort uses **intentar** or **tratar de**. Testing, tasting, and trying on use **probar** or **probarse**.

## Complete contrast

| Spanish | English |
|---|---|
| intentar hacer algo / tratar de hacer algo | try to do something |
| probar algo | try something by testing or sampling it |
| intentar algo | try or attempt a task |

**Intento hablar en inglés durante la clase. → I try to speak English during class.**

**Prueba esta sopa antes de pedirla. → Try this soup before you order it.**

**Voy a intentar el ejercicio otra vez. → I am going to try the exercise again.**
