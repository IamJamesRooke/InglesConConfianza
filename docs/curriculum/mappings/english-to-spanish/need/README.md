# English **Need**

| English | Spanish |
|---|---|
| I need more time. | Necesito más tiempo. |
| We need to leave now. | Tenemos que salir ya. |
| We need two more chairs. | Nos hacen falta dos sillas más. |
| The report needs to be corrected. | Hay que corregir el informe. |

Personal need often uses **necesitar**. Obligation, something missing, and impersonal necessity commonly use **tener que**, **hacer falta**, **hay que**, or **se necesita**.
