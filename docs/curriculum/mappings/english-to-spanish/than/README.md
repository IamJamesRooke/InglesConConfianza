# English **Than**

| English | Spanish |
|---|---|
| Laura is taller than Mateo. | Laura es más alta que Mateo. |
| I have more than ten dollars. | Tengo más de diez dólares. |
| It cost less than expected. | Costó menos de lo esperado. |
| Rather than wait, we left. | En vez de esperar, nos fuimos. |

Comparison with a person or thing usually uses **que**; comparison before a number uses **de**. **Than expected** and **rather than** require complete expressions.
