# English **See**

| English | Spanish |
|---|---|
| I see what you mean. | Entiendo lo que quieres decir. |
| I need to see a doctor. | Necesito consultar a un médico. |
| See that the door is locked. | Asegúrate de que la puerta esté cerrada. |
| Mateo is seeing someone. | Mateo está saliendo con alguien. |

Visual **see** headed by **ver** is now in the curriculum database. Understanding, consulting a professional, making sure, and dating require different Spanish verbs and remain here.
