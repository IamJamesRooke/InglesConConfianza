# English **Understand**

| English | Spanish |
|---|---|
| I understand the question. | Entiendo la pregunta. |
| I understand how the system works. | Comprendo cómo funciona el sistema. |
| I understand that the meeting was canceled. | Tengo entendido que cancelaron la reunión. |
| Make yourself understood. | Hazte entender. |

Direct comprehension uses **entender** or **comprender**. Reported information and making meaning clear use different Spanish constructions.
