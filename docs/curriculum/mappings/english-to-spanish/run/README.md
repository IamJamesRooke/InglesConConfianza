# Spanish Translations of English **Run**

English **run** covers physical movement, operation, management, duration, candidacy, flow, routes, and depletion.

| Lesson | English | Spanish |
|---|---|---|
| [**Run → Correr**](01-run-physically.md) | I run in the park every morning. | Corro en el parque todas las mañanas. |
| [**Run → Funcionar**](02-function.md) | The machine runs on batteries. | La máquina funciona con pilas. |
| [**Run → Dirigir / Administrar**](03-manage.md) | She runs a small company. | Ella dirige una empresa pequeña. |
| [**Run → Durar**](04-duration.md) | The movie runs for two hours. | La película dura dos horas. |
| [**Run → Postularse / Lanzarse**](05-run-for-office.md) | He's running for mayor. | Se está postulando para alcalde. |
| [**Run → Correr / Fluir**](06-flow.md) | Water ran down the wall. | El agua corrió por la pared. |
| [**Run → Ir / Circular**](07-route-or-service.md) | The buses run every ten minutes. | Los buses pasan cada diez minutos. |
| [**Run Out → Acabarse / Quedarse Sin**](08-run-out.md) | We ran out of coffee. | Se nos acabó el café. / Nos quedamos sin café. |
