# English **Suggest**

| English | Spanish |
|---|---|
| I suggest leaving early. | Sugiero salir temprano. |
| The evidence suggests that he knew. | La evidencia indica que él sabía. |
| Are you suggesting that I lied? | ¿Estás dando a entender que mentí? |
| She suggested a different date. | Propuso otra fecha. |

Advice, evidence, implication, and proposals use **sugerir, indicar, dar a entender**, or **proponer**.
