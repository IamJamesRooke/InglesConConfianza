# English **Along**

| English | Spanish |
|---|---|
| We walked along the river. | Caminamos a lo largo del río. |
| There are cafés along this street. | Hay cafés por esta calle. |
| Bring Laura along. | Trae a Laura contigo. |
| The project is coming along well. | El proyecto va bien. |

Movement beside a line, distribution, accompanying someone, and progress require different Spanish expressions.
