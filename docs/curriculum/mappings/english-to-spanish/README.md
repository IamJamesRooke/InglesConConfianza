# English-to-Spanish Mappings

These maps begin with an English word, form, or construction whose natural Spanish changes with meaning, function, or context.

A canonical folder exists only when the English source is frequent and has multiple useful Spanish mappings. Related forms may be nested under the source word, and deliberate sound families remain together when the contrast itself is the teaching point.
