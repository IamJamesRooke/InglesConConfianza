# English-to-Spanish Mappings

> **Even a pretty familiar word can work in a rather different way depending on the kind of sentence.**

These maps begin with an English word, form, or construction whose natural Spanish changes with meaning, function, or context. The folders are intentionally flat: a learner starts with the English form, not with a grammatical category.

Each `translations-*` folder is one mapping family. Its README gives the complete map, and its micro-lessons teach the individual choices.
