# Uses of **All** and **Every**

| Lesson | Spanish | English |
|---|---|---|
| [**All** With a Complete Group](01-all-with-a-complete-group.md) | Todos los estudiantes entregaron sus proyectos. | All the students submitted their projects. |
| [**All** With an Amount or Singular Thing](02-all-with-an-amount.md) | Leí todo el libro y usé toda la información. | I read the whole book and used all the information. |
| [**All Of**](03-all-of.md) | Todos nosotros leímos todos los documentos. | All of us read all of the documents. |
| [**Every + One Thing**](../every/04-every-plus-one.md) | Cada libro de la colección tiene un índice diferente. | Every book in the collection has a different index. |
| [**Each**](../each/05-each.md) | Cada estudiante recibió comentarios diferentes sobre su proyecto. | Each student received different feedback on their project. |
| [**All, Every**, and **Each**](06-all-every-and-each.md) | Todos los libros tienen portada, cada libro tiene un título y cada uno tiene un número distinto. | All the books have covers, every book has a title, and each one has a different number. |
| [**Everyone** and **Everybody**](../every/07-everyone-and-everybody.md) | Todos están listos, pero cada uno tiene que traer su propia identificación. | Everyone's ready, but everybody has to bring their own ID. |
| [**Everything** and **Everywhere**](../every/08-everything-and-everywhere.md) | Buscamos por todas partes y revisamos todo, pero no encontramos la llave. | We looked everywhere and checked everything, but we didn't find the key. |
| [**All Day** Versus **Every Day**](09-all-day-versus-every-day.md) | Trabajé todo el día ayer, pero no trabajo todos los días. | I worked all day yesterday, but I don't work every day. |
| [**All** Versus **Whole**](10-all-versus-whole.md) | Leí todo el informe y todos los anexos. | I read the whole report and all the attachments. |
| [**All at Once**](11-all-at-once.md) | Todos empezaron a hablar al mismo tiempo. | They all started talking all at once. |
| [**All of a Sudden**](12-all-of-a-sudden.md) | De repente, se apagaron todas las luces. | All of a sudden, all the lights went out. |
| [**After All**](13-after-all.md) | Llevemos paraguas; después de todo, estamos en temporada de lluvias. | Let's take umbrellas; after all, it's the rainy season. |
| [**Above All**](14-above-all.md) | Sobre todo, no compartas tu contraseña con nadie. | Above all, don't share your password with anyone. |
| [**Once and for All**](15-once-and-for-all.md) | Resolvamos este problema de una vez por todas. | Let's solve this problem once and for all. |
| [**All Right** and **Alright**](16-all-right-and-alright.md) | —¿Estás bien? —Sí, todo está bien. | “Are you all right?” “Yeah, everything's alright.” |
| [Homophones: **All** and **Awl**](17-homophones-all-and-awl.md) | Todos usaron un punzón para hacer cada agujero. | They all used an awl to make every hole. |

## Mastery Phrases

| Spanish | English |
|---|---|
| Todos nosotros leímos el libro completo, pero cada estudiante marcó una página diferente. | All of us read the whole book, but every student marked a different page. |
| Trabajé todo el día, como todos los días, y de repente todos llamaron al mismo tiempo. | I worked all day, as I do every day, and all of a sudden, everyone called all at once. |
| Todos usaron un punzón para hacer cada agujero y terminar el trabajo de una vez por todas. | They all used an awl to make every hole and finish the job once and for all. |
