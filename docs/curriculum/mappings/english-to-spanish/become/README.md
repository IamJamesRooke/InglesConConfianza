# English **Become**

| English | Spanish |
|---|---|
| She became angry. | Se puso brava. |
| The problem became serious. | El problema se volvió serio. |
| He became a doctor. | Se hizo médico. |
| The caterpillar became a butterfly. | La oruga se convirtió en mariposa. |
| She eventually became president. | Llegó a ser presidenta. |

Spanish chooses the change verb according to the kind of result: **ponerse, volverse, hacerse, convertirse en**, or **llegar a ser**.
