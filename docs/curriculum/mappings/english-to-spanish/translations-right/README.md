# Uses of **Right**

| Lesson | Spanish | English |
|---|---|---|
| [**Right** for Direction](01-right-for-direction.md) | Gira a la derecha y busca la puerta a tu derecha. | Turn right and look for the door on your right. |
| [**Be Right**](02-be-right.md) | La respuesta es correcta y tú tienes razón. | The answer is right, and you're right. |
| [Human **Rights**](03-human-rights.md) | Todos tenemos los mismos derechos humanos. | We all have the same human rights. |
| [**Right Now, Right Here**, and **Right Away**](04-right-now-here-and-away.md) | Hazlo aquí mismo, ahora mismo y de inmediato. | Do it right here, right now, and right away. |
| [Homophones: **Right, Write, Rite**, and **Wright**](05-homophones-right-write-rite-and-wright.md) | El dramaturgo escribirá el rito correcto. | The playwright will write the right rite. |
