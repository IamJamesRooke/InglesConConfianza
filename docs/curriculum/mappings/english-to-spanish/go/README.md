# Spanish Translations of English **Go**

English **go** covers movement, destination, change, operation, suitability, availability, events, future plans, and many particle combinations.

| Lesson | English | Spanish |
|---|---|---|
| [**Go → Ir**](01-movement.md) | Go home now; I'll go to Bogotá tomorrow. | Vete a casa ahora; mañana iré a Bogotá. |
| [**Go → Ponerse / Volverse**](02-become.md) | The milk went bad, and the room went quiet. | La leche se dañó y el salón se quedó en silencio. |
| [**Go → Funcionar / Servir**](03-function.md) | The generator is still going. | El generador todavía funciona. |
| [**Go → Combinar / Ir**](04-match-or-belong.md) | This shirt goes with those pants. | Esta camisa combina con esos pantalones. |
| [**Go → Caber / Estar Disponible**](05-be-available-or-fit.md) | The boxes go here, and the tickets are going fast. | Las cajas van aquí y las entradas se están agotando rápido. |
| [**How Did It Go? → ¿Cómo Te Fue?**](06-happen.md) | How did the meeting go? | ¿Cómo te fue en la reunión? |
| [**Be Going To → Ir A**](07-going-to-future.md) | We're going to leave early. | Vamos a salir temprano. |
| [Particles with **Go**](08-particles.md) | The alarm went off, but the meeting went on. | Sonó la alarma, pero la reunión continuó. |
