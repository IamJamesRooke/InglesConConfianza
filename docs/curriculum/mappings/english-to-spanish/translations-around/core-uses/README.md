# Core Uses of **Around**

| Lesson | Spanish | English |
|---|---|---|
| [Surrounding or on Different Sides](01-surrounding-or-different-sides.md) | Nos sentamos alrededor de la mesa. | We sat around the table. |
| [Nearby or Available](02-nearby-or-available.md) | Estaré por aquí si me necesitas. | I'll be around if you need me. |
| [Approximately](03-approximately.md) | Llegaré alrededor de las diez. | I'll arrive around ten. |
| [**Just Around the Corner**](04-just-around-the-corner.md) | La tienda está a la vuelta de la esquina y el examen se acerca. | The store is just around the corner, and the exam is just around the corner. |
