# English **Receive**

| English | Spanish |
|---|---|
| I received your message. | Recibí tu mensaje. |
| She received a good grade. | Sacó una buena nota. |
| The hotel receives guests all night. | El hotel recibe huéspedes toda la noche. |
| The signal is not being received. | No se capta la señal. |

General reception uses **recibir**, while grades and electronic signals commonly use **sacar** and **captar**.
