# English **Die**

| English | Spanish |
|---|---|
| The plant died. | La planta murió. |
| My phone died. | Mi teléfono se descargó. |
| The engine died. | El motor se apagó. |
| I am dying to know. | Me muero por saber. |

Living things use **morir**. Batteries, machinery, and emphatic desire require **descargarse, apagarse**, or **morirse por**.
