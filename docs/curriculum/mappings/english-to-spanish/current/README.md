# English **Current**

| English | Spanish |
|---|---|
| The current price is ten dollars. | El precio actual es de diez dólares. |
| The river has a strong current. | El río tiene una corriente fuerte. |
| Keep your information current. | Mantén actualizada tu información. |
| Current affairs interest her. | Le interesan los asuntos de actualidad. |

Present-time **current** uses **actual/actualizado**, while moving water or electricity is **corriente** and news is **actualidad**.
