# English **Fine**

| English | Spanish |
|---|---|
| I am fine. | Estoy bien. |
| That is fine with me. | Me parece bien. |
| The company paid a fine. | La empresa pagó una multa. |
| The powder is very fine. | El polvo es muy fino. |

Well-being and acceptance use **bien**, a penalty **multa**, and texture or delicacy **fino**.
