# English **Although**

| English | Spanish |
|---|---|
| Although it was raining, we left. | Aunque llovía, salimos. |
| Although difficult, the exam was fair. | A pesar de ser difícil, el examen fue justo. |
| It is useful, although expensive. | Es útil, pero es costoso. |

A full concessive clause uses **aunque**. Reduced or afterthought contrasts may use **a pesar de** or **pero**.
