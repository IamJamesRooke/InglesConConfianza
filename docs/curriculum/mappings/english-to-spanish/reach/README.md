# English **Reach**

| English | Spanish |
|---|---|
| I can't reach the shelf. | No alcanzo el estante. |
| We reached Bogotá at noon. | Llegamos a Bogotá al mediodía. |
| We reached an agreement. | Llegamos a un acuerdo. |
| You can reach me by phone. | Puedes comunicarte conmigo por teléfono. |

Physical range uses **alcanzar**; destinations and agreements **llegar a**; contacting someone **comunicarse con**.
