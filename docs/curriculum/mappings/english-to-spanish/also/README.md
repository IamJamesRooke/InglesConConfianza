# English **Also**

| English | Spanish |
|---|---|
| Laura also speaks French. | Laura también habla francés. |
| The plan is expensive; it is also risky. | El plan es costoso; además, es arriesgado. |
| I don't want to go either. | Yo tampoco quiero ir. |
| Not only Laura but also Mateo came. | No solo vino Laura, sino también Mateo. |

Positive addition uses **también** or **además**. In a negative sentence English **either** corresponds to **tampoco**, and **but also** uses **sino también**.
