# English **Let**

| English | Spanish |
|---|---|
| Let me explain. | Déjame explicar. |
| They don't let us enter. | No nos permiten entrar. |
| Let's begin. | Empecemos. / Vamos a empezar. |
| Let go of my hand. | Suelta mi mano. |
| The apartment is for rent. | El apartamento se arrienda. |

Permission uses **dejar** or **permitir**. Suggestions with **let's**, releasing something, and rental **let** require separate Spanish structures.
