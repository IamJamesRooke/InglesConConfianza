# English **Thank**

| English | Spanish |
|---|---|
| Thank Laura for her help. | Agradécele a Laura su ayuda. |
| Thank you for coming. | Gracias por venir. |
| I have you to thank for this opportunity. | Te debo esta oportunidad. |

Verb **thank** uses **agradecer**, the routine expression uses **gracias**, and assigning positive credit may use **deber**.
