# English **If**

| English | Spanish |
|---|---|
| If it rains, we will stay home. | Si llueve, nos quedaremos en casa. |
| I don't know if she is coming. | No sé si viene. |
| Even if it rains, we will go. | Aunque llueva, iremos. |
| If only I had more time. | Ojalá tuviera más tiempo. |
| What if we leave now? | ¿Y si salimos ahora? |

Conditional and indirect-question **if** normally become **si**. **Even if**, **if only**, and **what if** require complete Spanish expressions.
