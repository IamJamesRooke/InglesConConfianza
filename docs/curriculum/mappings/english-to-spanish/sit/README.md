# English **Sit**

| English | Spanish |
|---|---|
| Sit here. | Siéntate aquí. |
| The building sits on a hill. | El edificio está en una colina. |
| I sat the exam yesterday. | Presenté el examen ayer. |
| The committee sits tomorrow. | El comité se reúne mañana. |

Body position uses **sentarse**. Location, taking an exam, and a formal body meeting use unrelated Spanish verbs.
