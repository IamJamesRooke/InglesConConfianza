# Uses of **Some** and Related Quantities

| Lesson | Spanish | English |
|---|---|---|
| [**Some** With More Than One Thing](01-some-with-more-than-one-thing.md) | Compré unos libros para la clase. | I bought some books for the class. |
| [**Some** With Part of an Amount](02-some-with-part-of-an-amount.md) | Leí parte del libro y tomé un poco de café. | I read some of the book and had some coffee. |
| [**Some Of**](03-some-of.md) | Algunos de los libros estaban dañados. | Some of the books were damaged. |
| [**Some** in Offers and Requests](04-some-in-offers-and-requests.md) | ¿Quieres un poco de café? ¿Me puedes prestar algo de dinero? | Would you like some coffee? Could you lend me some money? |
| [**Some** Versus **Any**](05-some-versus-any.md) | Tengo algunos libros, pero no tengo ninguno sobre ese tema. | I've got some books, but I don't have any on that topic. |
| [**A Few** Versus **Few**](../few/06-a-few-versus-few.md) | Tengo unos cuantos amigos aquí, pero muy pocos pueden quedarse hasta tarde. | I've got a few friends here, but few of them can stay late. |
| [**A Little** Versus **Little**](../little/07-a-little-versus-little.md) | Tenemos un poco de tiempo, pero queda muy poca comida. | We've got a little time, but there's little food left. |
| [**A Little Bit**](../little/08-a-little-bit.md) | Estoy un poquito cansada, así que voy a descansar. | I'm a little bit tired, so I'm gonna rest. |
| [**Several**](../several/09-several.md) | Varios clientes llamaron por el mismo problema. | Several clients called about the same problem. |
| [**A Lot Of, Lots Of**, and **Plenty Of**](../../../structure/reference-and-noun-phrases/quantity/a-lot-of-lots-of-and-plenty-of.md) | Tenemos muchos libros y más que suficiente tiempo para revisarlos. | We've got lots of books and plenty of time to review them. |
| [**Someone, Something**, and **Somewhere**](11-someone-something-and-somewhere.md) | Alguien dejó algo en algún lugar de la oficina. | Someone left something somewhere in the office. |
| [**Some** Versus **Same**](12-some-versus-same.md) | Algunos estudiantes dieron la misma respuesta de siempre. | Some students gave the same answer as always. |
| [**Sometimes, Sometime**, and **Some Time**](13-sometimes-sometime-and-some-time.md) | A veces practico sola; deberíamos reunirnos algún día y dedicar algo de tiempo a practicar. | Sometimes I practice alone; we should meet sometime and spend some time practicing. |
| [**Somehow**](14-somehow.md) | De alguna manera, logramos terminar a tiempo. | Somehow, we managed to finish on time. |
| [Emphatic **Some**](15-some-meaning-impressive.md) | ¡Esa sí que fue una reunión! Duró cinco horas. | That was some meeting! It lasted five hours. |
| [Homophones: **Some** and **Sum**](16-homophones-some-and-sum.md) | Algunos estudiantes calcularon la misma suma de varias maneras. | Some students calculated the same sum in several ways. |

## Mastery Phrases

| Spanish | English |
|---|---|
| Leí parte del libro, algunos de los capítulos y unas cuantas notas, pero todavía me falta bastante. | I read some of the book, some of the chapters, and a few notes, but I've still got plenty left. |
| A veces necesitamos algo de tiempo, un poco de ayuda y varias ideas para resolver de alguna manera el mismo problema. | Sometimes we need some time, a little help, and several ideas to somehow solve the same problem. |
| Algunos estudiantes calcularon la misma suma; unos cuantos lo hicieron bien, pero pocos pudieron explicarla. | Some students calculated the same sum; a few got it right, but few could explain it. |
