# English **Happen**

| English | Spanish |
|---|---|
| What happened? | ¿Qué pasó? |
| The accident happened at night. | El accidente ocurrió de noche. |
| I happened to see Laura downtown. | Por casualidad vi a Laura en el centro. |
| We happened upon a quiet café. | Nos encontramos con un café tranquilo. |

Events can **pasar, suceder**, or **ocurrir**. **Happen to** and **happen upon** express chance and normally require restructuring.
