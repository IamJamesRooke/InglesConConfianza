# Uses of **Start**

English **start** maps to **empezar/comenzar**, but machines and engines commonly require **encender** or **arrancar**.

| Lesson | Spanish | English |
|---|---|---|
| [Start Something](01-start-something.md) | Empiezo el informe. | I start the report. |
| [Start a Machine or Trip](02-start-a-machine-or-trip.md) | El carro no arranca. | The car won't start. |
