# English **Pay**

| English | Spanish |
|---|---|
| I paid the bill. | Pagué la cuenta. |
| Pay attention. | Presta atención. |
| I paid Laura yesterday. | Le pagué a Laura ayer. |
| We paid off the debt. | Saldamos la deuda. |
| The extra practice paid off. | La práctica adicional dio resultado. |

Money normally uses **pagar**, but **pay attention**, clearing a debt, and producing a benefit use different Spanish expressions.
