# English **For**

| English | Spanish |
|---|---|
| This gift is for Ana. | Este regalo es para Ana. |
| I did it for you. | Lo hice por ti. |
| We waited for three hours. | Esperamos durante tres horas. |
| Thank you for coming. | Gracias por venir. |
| I bought it for ten dollars. | Lo compré por diez dólares. |

**For** does not have one fixed Spanish equivalent. Purpose and destination usually favor **para**; cause, exchange, and the reason for gratitude favor **por**; measured duration can use **durante**.
