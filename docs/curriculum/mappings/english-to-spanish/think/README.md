# Uses of **Think**

English **think** maps to **pensar en** for a topic and to **pensar/creer** for an opinion.

| Lesson | Spanish | English |
|---|---|---|
| [Think About](01-think-about.md) | Pienso en el problema. | I think about the problem. |
| [Think for an Opinion](02-think-for-an-opinion.md) | Creo que funcionará. | I think it will work. |
| [Think vs Believe](confusion-sets/README.md) | Creo que es cierto. | I think / believe it's true. |
