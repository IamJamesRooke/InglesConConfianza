# English **Lie**

| English | Spanish |
|---|---|
| He lied about the money. | Mintió sobre el dinero. |
| Lie down and rest. | Acuéstate y descansa. |
| The town lies north of Bogotá. | El pueblo queda al norte de Bogotá. |
| A difficult decision lies ahead. | Queda una decisión difícil por delante. |

Falsehood uses **mentir**. Reclining, geographical location, and something awaiting in the future use unrelated Spanish verbs.
