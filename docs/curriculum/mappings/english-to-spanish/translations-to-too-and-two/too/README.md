# Uses of **Too**

| Lesson | Spanish | English |
|---|---|---|
| [**Too + Description** Meaning Excess](01-too-plus-description-meaning-excess.md) | Estoy demasiado ocupado para revisar el informe hoy. | I'm too busy to review the report today. |
| [**Too Much** and **Too Many**](02-too-much-and-too-many.md) | Hay demasiado tráfico y demasiados carros como para que lleguemos antes de las ocho. | There's too much traffic and there are too many cars for us to arrive before eight. |
| [**Too...To**](03-too-to.md) | El archivo es demasiado grande para enviarlo por correo. | The file is too large to send by email. |
| [**Too...For Someone To**](04-too-for-someone-to.md) | El informe es demasiado técnico para que el cliente lo entienda sin ayuda. | The report is too technical for the client to understand without help. |
| [**Much Too** Versus **Too Much**](05-much-too-versus-too-much.md) | El apartamento es demasiado caro y cuesta demasiado para nuestro presupuesto. | The apartment is much too expensive, and it costs too much for our budget. |
| [**Far Too** and Informal **Way Too**](06-far-too-and-informal-way-too.md) | Dos horas es demasiado tiempo para una reunión que podría durar veinte minutos. | Two hours is far too long for a meeting that could take twenty minutes. |
| [**Not Too**](07-not-too.md) | El examen no estuvo muy difícil, así que terminé temprano. | The exam wasn't too difficult, so I finished early. |
| [**Too** Meaning Also](08-too-meaning-also.md) | Laura va a asistir y yo también voy. | Laura's going to attend, and I'm going too. |
| [**Me Too**](09-me-too.md) | —Quiero ir a Cartagena. —Yo también. | “I want to go to Cartagena.” “Me too.” |
| [Formal or Emphatic **Too**](10-formal-or-emphatic-too.md) | Laura también vio el error, aunque no dijo nada durante la reunión. | Laura, too, saw the error, although she said nothing during the meeting. |
| [**All Too**](11-all-too.md) | Es demasiado común que una contraseña débil permita el acceso a datos privados. | It's all too common for a weak password to expose private data. |
| [**Only Too**](12-only-too.md) | Con mucho gusto revisaré el contrato antes de que lo firmes. | I'll be only too happy to review the contract before you sign it. |
| [**Cannot Be Too Careful**](13-cannot-be-too-careful.md) | No se puede ser demasiado cuidadoso al verificar un número de cuenta antes de transferir dinero. | You can't be too careful when checking an account number before transferring money. |

## Mastery Phrases

| Spanish | English |
|---|---|
| Los dos sastres están demasiado cansados para confeccionar dos tutús también. | The two tailors are too tired to tailor two tutus too. |
| El material es demasiado caro y cuesta demasiado; además, el diseño es demasiado complejo para que lo terminemos hoy. | The material is much too expensive and costs too much; the design is far too complex for us to finish today too. |
| —Yo también revisaré las cifras. —Yo también; nunca se puede ser demasiado cuidadoso. | “I'll check the figures too.” “Me too; you can't be too careful.” |
