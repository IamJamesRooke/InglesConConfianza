# Uses of **Two** and Related Forms

| Lesson | Spanish | English |
|---|---|---|
| [**Two**](01-two.md) | Compré dos libros porque cada estudiante necesita uno. | I bought two books because each student needs one. |
| [**The Two** Versus **Two**](02-the-two-versus-two.md) | Compré dos libros y le di los dos libros a Laura. | I bought two books and gave the two books to Laura. |
| [**Both**](03-both.md) | Leí ambos libros: el primero explica la teoría y el segundo muestra los ejemplos. | I read both books: the first one explains the theory, and the second one shows the examples. |
| [**A Couple Of**](04-a-couple-of.md) | Dame un par de minutos para terminar este correo. | Give me a couple of minutes to finish this email. |
| [**A Pair Of**](05-a-pair-of.md) | Necesito un par de zapatos negros para la entrevista. | I need a pair of black shoes for the interview. |
| [**Twins**](06-twins.md) | Las gemelas se parecen mucho, pero tienen personalidades diferentes. | The twins look very similar, but they have different personalities. |
| [**Twice**](07-twice.md) | Leí el contrato dos veces porque encontré un número diferente en cada copia. | I read the contract twice because I found a different number in each copy. |
| [**Second, Half**, and **Double**](08-second-half-and-double.md) | Las dos gemelas leyeron ambos libros dos veces. | The two twins read both books twice. |

## Mastery Phrases

| Spanish | English |
|---|---|
| Las dos gemelas leyeron ambos libros dos veces. | The two twins read both books twice. |
| Compré un par de zapatos y un par de medias hace un par de días. | I bought a pair of shoes and a pair of socks a couple of days ago. |
| El segundo par cuesta el doble que el primero, así que comprar dos pares costaría el doble. | The second pair costs twice as much as the first one, so buying two pairs would cost double. |
