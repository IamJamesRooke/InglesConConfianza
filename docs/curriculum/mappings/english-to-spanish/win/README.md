# English **Win**

| English | Spanish |
|---|---|
| We won the game. | Ganamos el partido. |
| Bogotá won against Cali. | Bogotá venció a Cali. |
| She won me over. | Me convenció. |
| The proposal won support. | La propuesta consiguió apoyo. |

Competitions use **ganar** or **vencer**. Persuasion and gaining support use **convencer** or **conseguir**.
