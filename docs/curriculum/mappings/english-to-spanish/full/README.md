# English **Full**

| English | Spanish |
|---|---|
| The glass is full. | El vaso está lleno. |
| I am full. | Estoy lleno. / Ya no tengo hambre. |
| Give me your full name. | Dame tu nombre completo. |
| The bus is full. | El bus está lleno. |

Capacity uses **lleno**, completeness **completo**, and physical satiety may be expressed as **ya no tener hambre**.
