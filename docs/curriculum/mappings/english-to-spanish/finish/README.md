# Uses of **Finish**

English **finish** maps to **terminar/acabar** for completing an action and to **acabarse** when something is used up.

| Lesson | Spanish | English |
|---|---|---|
| [Finish Something](01-finish-something.md) | Termino el informe. | I finish the report. |
| [Finish or Run Out](02-finish-or-run-out.md) | Nos acabamos el café. | We finished the coffee. |
