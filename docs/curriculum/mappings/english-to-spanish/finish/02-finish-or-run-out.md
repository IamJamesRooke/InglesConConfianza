# **Finish** or Run Out

When a person completes something, Spanish commonly uses **terminar** or **acabar**. When a supply finishes, Spanish may use **acabarse**.

| Spanish | English |
|---|---|
| Acabé el informe. | I finished the report. |
| Nos acabamos el café. | We finished the coffee. |
| Se acabó el café. | We ran out of coffee. |
