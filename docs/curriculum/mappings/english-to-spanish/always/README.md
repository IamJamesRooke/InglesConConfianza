# English **Always**

| English | Spanish |
|---|---|
| I always arrive early. | Siempre llego temprano. |
| She is always complaining. | No deja de quejarse. |
| You can always call me. | En todo caso, puedes llamarme. |
| The door is always open. | La puerta está abierta todo el tiempo. |

Habit uses **siempre**. Annoying repetition, a fallback option, and uninterrupted duration may require fuller expressions.
