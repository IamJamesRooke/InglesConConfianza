# English **Wait**

| English | Spanish |
|---|---|
| Wait here. | Espera aquí. |
| I am waiting for Laura. | Estoy esperando a Laura. |
| I can't wait to see you. | Tengo muchas ganas de verte. |
| Wait on this table, please. | Atiende esta mesa, por favor. |
| Hold on a moment. | Espera un momento. |

Ordinary **wait** uses **esperar**. Eager **can't wait**, serving a customer, and telephone **hold on** require complete expressions.
