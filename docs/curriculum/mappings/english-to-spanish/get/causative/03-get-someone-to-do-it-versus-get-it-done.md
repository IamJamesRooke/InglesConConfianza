# **Get Someone To Do It** Versus **Get It Done**

These patterns can describe the same situation from two different angles.

| Spanish | English |
|---|---|
| Conseguiré que alguien arregle el informe; no importa quién lo haga, pero conseguiré que quede listo hoy. | I'll get someone to fix the report; it doesn't matter who does it, but I'll get it done today. |

- **get + person + to + verb** names the person and the action: **get Ana to fix it**
- **get + thing + done** names the thing and emphasizes the completed result: **get it done**

**I'll get it done** doesn't say whether I'll do it myself or arrange for someone else to do it.
