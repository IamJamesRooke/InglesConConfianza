# English **Learn**

| English | Spanish |
|---|---|
| I am learning English. | Estoy aprendiendo inglés. |
| I learned that the office was closed. | Me enteré de que la oficina estaba cerrada. |
| Learn this number by heart. | Memoriza este número. |
| She learned to drive last year. | Aprendió a manejar el año pasado. |

Acquiring knowledge or a skill uses **aprender**. Receiving news uses **enterarse**, and deliberate exact recall uses **memorizar**.
