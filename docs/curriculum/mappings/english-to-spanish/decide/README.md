# English **Decide**

| English | Spanish |
|---|---|
| We decided to leave. | Decidimos salir. |
| The judge decided the case. | El juez resolvió el caso. |
| I can't decide between the two. | No me decido entre los dos. |

Making a choice uses **decidir**; resolving a formal matter **resolver**; difficulty choosing often pronominal **decidirse**.
