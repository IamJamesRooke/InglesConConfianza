# English **High**

| English | Spanish |
|---|---|
| The wall is high. | El muro es alto. |
| Prices are high. | Los precios son elevados. |
| The volume is too high. | El volumen está muy alto. |
| She holds a high position. | Ocupa un cargo importante. |

Height uses **alto**, level **elevado/alto**, and rank or importance may require **importante**.
