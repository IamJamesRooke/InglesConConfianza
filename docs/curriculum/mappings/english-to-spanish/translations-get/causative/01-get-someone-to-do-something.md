# **Get Someone To Do Something**

The familiar pattern **want + person + to + verb** provides a direct bridge to **get + person + to + verb**.

| Spanish | English |
|---|---|
| Quiero que alguien arregle la puerta, así que conseguiré que mi hermano la arregle. | I want someone to fix the door, so I'll get my brother to fix it. |

**Want** expresses the desire; **get** means persuade, arrange, or successfully cause the action. The reusable frame stays almost the same:

- **I want + someone + to fix it.**
- **I'll get + someone + to fix it.**

**Lemme see if I can get them to wait.** Here, **lemme** is an informal spelling of spoken **let me**.
