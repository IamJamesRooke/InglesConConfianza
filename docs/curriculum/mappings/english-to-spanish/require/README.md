# English **Require**

| English | Spanish |
|---|---|
| The job requires experience. | El trabajo requiere experiencia. |
| This plant requires a lot of water. | Esta planta necesita mucha agua. |
| The law requires us to register. | La ley exige que nos registremos. |

Formal requirements use **requerir**, practical needs **necesitar**, and imposed rules **exigir**.
