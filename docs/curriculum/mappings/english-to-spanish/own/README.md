# English **Own**

| English | Spanish |
|---|---|
| I have my own office. | Tengo mi propia oficina. |
| She owns the apartment. | Es dueña del apartamento. |
| He did it on his own. | Lo hizo solo. |
| Own up to the mistake. | Admite el error. |

Adjective **own**, possession as a verb, independence, and **own up** use **propio, ser dueño de, solo**, or **admitir**.
