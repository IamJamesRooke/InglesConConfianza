# Translations of Spanish **Para**

Spanish **para** points toward a recipient, purpose, destination, deadline, standard, or intended result. English chooses among **for, to, by**, and a result clause.

| Lesson | Spanish | English |
|---|---|---|
| [**Para → For** a Recipient](01-recipient.md) | Este café es para Laura. | This coffee is for Laura. |
| [**Para + Infinitive → To + Verb**](02-purpose-with-infinitive.md) | Necesito tiempo para terminar el informe. | I need time to finish the report. |
| [**Para → For** a Destination](03-destination.md) | Salimos para Bogotá mañana. | We leave for Bogotá tomorrow. |
| [**Para → By** a Deadline](04-deadline.md) | Necesito el informe para el viernes. | I need the report by Friday. |
| [**Para → For** a Standard or Perspective](05-standard-and-perspective.md) | Para un principiante, habla muy bien. | For a beginner, she speaks very well. |
| [**Para Que → So That**](06-para-que.md) | Hablo despacio para que puedas entender. | I speak slowly so that you can understand. |
