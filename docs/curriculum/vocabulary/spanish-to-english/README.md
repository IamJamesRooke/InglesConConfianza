# Spanish-to-English Vocabulary Maps

These lessons begin with a Spanish word or structure whose English translation changes with meaning and context.

| Category | Scope |
|---|---|
| [Verbs](verbs/README.md) | High-frequency verbs, pronominal forms, modal meanings, and verb confusion sets. |
| [Function Words](function-words/README.md) | Prepositions, connectors, and other short words whose English equivalent depends on their function. |
| [Pronouns](pronouns/README.md) | Pronouns and pronominal structures that require English to reorganize who does or receives an action. |
| [Constructions](constructions/README.md) | Cross-cutting Spanish patterns that require English subjects, tense, causative, aspect, or abstraction restructuring. |
