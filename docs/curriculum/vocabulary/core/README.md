This area contains the small, reusable lexicon used to make structural contrasts concrete before learners expand their vocabulary independently.

| Area | Focus |
|---|---|

| [Adjectives and States](adjectives-and-states/README.md) | Essential descriptions, evaluations, physical states, and practical qualities. |
| [Everyday](everyday/README.md) | Small contextual sets such as the place vocabulary used in location lessons. |
| [Expressions](expressions/README.md) | High-frequency social and conversational expressions. |
