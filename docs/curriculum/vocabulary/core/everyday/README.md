# Everyday Domains

This area holds deliberately small contextual vocabulary sets used to make structural practice concrete.

| Area | Focus |
|---|---|
| [Places](places/minimal-place-vocabulary.md) | Reusable destinations and locations for movement and position examples. |

Large themed vocabulary lists are outside the purpose of the core curriculum. Learners should acquire most additional vocabulary through cognates, transformations, and later independent exposure.
