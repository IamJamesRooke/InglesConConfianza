# Handle Verbs

In this course, verbs such as **want**, **like**, and **need** are called **handle verbs** because another action can follow them.

Use the handle verb followed by a **full infinitive**: **to** + the base form of the next verb.

**Quiero hacer algo.**<br>
I want to do something.

The core pattern is:

**subject + handle verb + to + base verb**
