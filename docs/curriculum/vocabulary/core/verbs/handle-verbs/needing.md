# Handle Verbs: Needing

## Needing something

| Spanish | English |
|---|---|
| necesitar algo | **to need something** |

**Necesito más tiempo.**<br>
I need more time.

## Needing to do an action

Use **need + full infinitive** when you must perform an action.

| Spanish | English |
|---|---|
| necesitar hacer algo | **to need to do something** |

**Necesito terminar el informe hoy.**<br>
I need to finish the report today.
