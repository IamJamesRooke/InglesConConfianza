# Core Verbs

This directory defines the closed set of English verb meanings and constructions taught explicitly as core material and reused throughout the structural curriculum. Outside this set, learners can acquire many new verbs through the cognate curriculum.

These files are curriculum specifications, not a required teaching sequence. Folders organize related meanings and constructions; individual lessons remain small enough to be selected and sequenced later.

## Organization

| Folder | Focus |
|---|---|
| `communication` | speaking, listening, saying, telling, and asking |
| `doing-and-making` | **do** and **make** |
| `eating-and-drinking` | food, drinks, and meals |
| `handle-verbs` | a course term for verbs followed by a full infinitive |
| `having` | possession, obligation, and **to have done** |
| `living-learning-and-working` | studying, living, working, and functioning |
| `money` | buying, selling, paying, costing, and spending |
| `moving` | direction, arrival, departure, and movement |
| `opening-and-closing` | **open** and **close** |
| `people` | helping, knowing, meeting, and introducing people |
| `seeing` | seeing, looking, finding, and showing |
| `sending-and-receiving` | transfer and the receiving meanings of **get** |
| `taking-and-putting` | moving or leaving objects |
| `thinking-and-feeling` | thought, knowledge, understanding, and memory |
| `time` | starting, finishing, waiting, and spending time |
| `to-be` | foundational uses of **be** |

## Lesson boundaries

- One file should teach one verb, one construction, or one contrast that is best understood as a set.
- Keep contrasts together when comparison carries the teaching value, such as **do/make**, **say/tell**, **come/go**, and **see/look at**.
- Separate identical-looking patterns when their grammar or meaning differs, such as possession with **have**, obligation with **have to**, and the perfect infinitive **to have done**.
- Repeated core verbs are intentional when they teach distinct meanings. Important examples include **get**, **have**, **leave**, **take**, and **work**.
- Some core verbs are also cognates. Their core lessons teach the meaning or construction; their cognate lessons may separately teach how learners can recognize or build the word.
- Examples may combine these core verbs with verbs already available through the cognate curriculum.
