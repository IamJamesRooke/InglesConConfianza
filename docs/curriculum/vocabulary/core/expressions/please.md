# **Please**

Use **please** to make a request more polite.

| Spanish | English |
|---|---|
| por favor | please |

**Please** can go before the request or at the end:

| Spanish | English |
|---|---|
| Por favor, ayúdame. | Please help me. |
| Ayúdame, por favor. | Help me, please. |

The end position normally uses a comma in writing.
