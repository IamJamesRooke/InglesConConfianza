# Size, Length, and Age

| Contrast | Spanish | English |
|---|---|---|
| size | grande / pequeño | big / small |
| length or duration | largo / corto | long / short |
| age | viejo / joven | old / young |

| Spanish | English |
|---|---|
| Vivimos en una casa pequeña, pero el jardín es grande. | We live in a small house, but the yard is big. |
| La reunión fue larga, pero el descanso fue corto. | The meeting was long, but the break was short. |
| El edificio es viejo, pero la empresa es joven. | The building is old, but the company is young. |

**Grande** does not always become **big**. Use **long** for length or duration: **una reunión larga → a long meeting**.
