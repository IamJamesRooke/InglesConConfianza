# **To Be**: **Be Able To** and **Can**

Use **be able to** or **can** to express ability.

## **Be able to**

The form of **be** changes with the subject. Keep **to** before the action.

| Spanish | English |
|---|---|
| poder hacer algo | **to be able to do something** |
| puedo hacer algo | **I am able to do something** |
| puede hacer algo | **he/she is able to do something** |
| puedes, podemos, pueden hacer algo | **you/we/they are able to do something** |

**Puedo explicar la actividad en inglés.**<br>
I am able to explain the activity in English.

## **Can**

**Can** does not change with the subject, and the next verb does not use **to**.

| Spanish | English |
|---|---|
| poder hacer algo | **can do something** |

**Puedo explicar la actividad en inglés.**<br>
I can explain the activity in English.

Compare the patterns:

**I am able to do it.**<br>
**I can do it.**<br>
Not: *I can to do it.*
