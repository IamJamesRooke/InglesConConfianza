# The Verb **To Be**

English **to be** can correspond to Spanish **ser** or **estar**. English also uses forms of **be** to build other essential constructions.

This foundational group covers:

- present forms and contractions of **be**;
- core uses corresponding to **ser** and **estar**;
- **there is** and **there are**;
- **be going to** for future plans and predictions;
- **be able to** and **can** for ability.

The advanced curriculum can extend these foundations with less common uses and finer distinctions.
