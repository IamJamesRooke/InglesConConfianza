# Spanish **Rendir**

| Spanish | English |
|---|---|
| El equipo rinde bien bajo presión. | The team performs well under pressure. |
| Esta inversión rindió buenos resultados. | This investment yielded good results. |
| El esfuerzo rindió frutos. | The effort paid off. |
| Los soldados se rindieron. | The soldiers surrendered. |

**Rendir** can become **perform, yield**, or **pay off**; pronominal **rendirse** means surrender or give up.
