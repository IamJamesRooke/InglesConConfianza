# Spanish **Lleno**

| Spanish | English |
|---|---|
| El vaso está lleno. | The glass is full. |
| El bus está lleno. | The bus is crowded/full. |
| Estoy lleno. | I am full. |
| El informe está lleno de errores. | The report is full of errors. |

**Lleno** can become **full, crowded**, or physically **full after eating**, depending on what has reached capacity.
