# Spanish **Dirigir**

| Spanish | English |
|---|---|
| Laura dirige la empresa. | Laura runs the company. |
| Dirigió la reunión. | She led the meeting. |
| Dirige la carta al gerente. | Address the letter to the manager. |
| Se dirigió a la salida. | He headed toward the exit. |

**Dirigir** can become **run, lead, address**, or **head toward**, according to what is guided.
