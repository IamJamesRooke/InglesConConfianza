# Spanish **Blanco**

| Spanish | English |
|---|---|
| La pared es blanca. | The wall is white. |
| Deja este espacio en blanco. | Leave this space blank. |
| El edificio era el blanco del ataque. | The building was the target of the attack. |
| Se quedó en blanco. | Her mind went blank. |

**Blanco** can become **white, blank**, or **target**, and **quedarse en blanco** means one's mind goes blank.
