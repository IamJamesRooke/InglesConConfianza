# Spanish **Tirar**

| Spanish | English |
|---|---|
| Tira la pelota. | Throw the ball. |
| Tira de la puerta. | Pull the door. |
| Tira eso a la basura. | Throw that away. |
| No tires el dinero. | Don't waste money. |
| El carro tira hacia la izquierda. | The car pulls to the left. |

**Tirar** can become **throw, pull, throw away**, or **waste**, and its preposition helps determine the direction.
