# Spanish **Casar**

| Spanish | English |
|---|---|
| El juez los casó. | The judge married them. |
| Se casaron en junio. | They got married in June. |
| Esa explicación no casa con los hechos. | That explanation doesn't match the facts. |
| Quieren casar las dos ideas. | They want to reconcile the two ideas. |

**Casar** can become **marry, get married, match**, or **reconcile** two things.
