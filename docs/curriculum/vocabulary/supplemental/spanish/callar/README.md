# Spanish **Callar**

| Spanish | English |
|---|---|
| Calló durante la reunión. | She remained silent during the meeting. |
| ¡Cállate! | Be quiet! / Shut up! |
| No puedo callar la verdad. | I can't keep the truth quiet. |
| La noticia hizo callar a todos. | The news silenced everyone. |

**Callar** can become **remain silent, be quiet, shut up, keep quiet**, or **silence** someone.
