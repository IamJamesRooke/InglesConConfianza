# Spanish **Partir**

| Spanish | English |
|---|---|
| El tren parte a las ocho. | The train leaves at eight. |
| Partió el pan en dos. | She split the bread in two. |
| Partimos de una idea sencilla. | We started from a simple idea. |
| La noticia me partió el corazón. | The news broke my heart. |

**Partir** can become **leave, split, start from**, or **break** in fixed emotional expressions.
