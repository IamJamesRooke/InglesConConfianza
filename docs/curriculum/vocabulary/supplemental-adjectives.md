# Supplemental Adjectives

These are useful direct vocabulary items, but they do not currently need a large translation map or a transformation lesson.

| Spanish | English |
|---|---|
| rojo / roja | red |
| azul | blue |
| verde | green |
| amarillo / amarilla | yellow |
| blanco / blanca | white |
| negro / negra | black |

For shades, use the existing mappings for [**claro**](../mappings/spanish-to-english/claro/README.md) and [**oscuro**](../mappings/spanish-to-english/oscuro/README.md): **azul claro** is **light blue**, and **verde oscuro** is **dark green**. The English shade word comes before the color.
