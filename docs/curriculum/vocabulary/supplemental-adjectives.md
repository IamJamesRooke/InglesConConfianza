# Supplemental Adjectives

These are useful direct vocabulary items, but they do not currently need a large translation map or a transformation lesson.

| Spanish | English |
|---|---|
| rojo / roja | red |
| azul | blue |
| verde | green |
| amarillo / amarilla | yellow |
| blanco / blanca | white |
| negro / negra | black |
| barato / barata / económico / económica | cheap / inexpensive |
| caro / cara | expensive / dear |
| corto / corta | short / brief |
| largo / larga | long / lengthy |
| lento / lenta | slow |
| oscuro / oscura | dark |

For shades, use the existing mapping for [**claro**](../mappings/spanish-to-english/claro/README.md): **azul claro** is **light blue**, while **verde oscuro** is **dark green**. The English shade word comes before the color. For example, **Laura lleva una chaqueta verde oscuro. → Laura is wearing a dark green jacket.**

## Register and usage notes

- **Inexpensive** is more neutral than **cheap**; **cheap** can also suggest poor quality. **Ese apartamento es barato. → That apartment is cheap.**
- **Dear** can mean expensive in some contexts, but it also commonly means loved or addressed in a letter. **Este apartamento es caro. → This apartment is expensive.**
- **Brief** is a more formal alternative to **short**. **El descanso fue corto. → The break was short.**
- **Lengthy** emphasizes extended detail or duration. **La reunión fue larga. → The meeting was long.**
- **Slow** describes a person, vehicle, process, or movement with low speed. **El carro es lento. → The car is slow.**

These direct or near-synonymous choices remain supplemental vocabulary rather than separate mapping families.
