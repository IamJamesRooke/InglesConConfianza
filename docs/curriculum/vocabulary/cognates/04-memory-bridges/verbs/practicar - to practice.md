# Verb Cognates: **-ice**

These Spanish and English cognates correspond to English verbs ending in **-ice**.

| Spanish | English | Example |
|---|---|---|
| practicar | **to practice** | **Necesitas practicar inglés todos los días.**<br>You need to practice English every day. |
| notar | **to notice** | **Noté un error en la última página.**<br>I noticed an error on the last page. |
| prometer | **to promise** | **Te prometo que terminaré el trabajo hoy.**<br>I promise you that I will finish the work today. |

## Additional Cognates

| Spanish | English | Example |
|---|---|---|
