# Cognate Verbs

This page identifies the verb lessons within the unified cognate curriculum and connects them to the usable core-verb inventory.

The overlap is intentional:

- In [Cognates](README.md), students encounter these verbs as a way to infer English vocabulary from Spanish.
- In [Core Verbs](../core-verbs/README.md), selected meanings become part of the usable verb inventory and combine with the six English verb forms.

Start with `selected-verbs.md` for the closed, high-frequency foundation inventory. Use the lesson folders when a cognate rule needs more examples, exceptions, or false-cognate contrasts.

The folders progress from the most reliable inference patterns to the least mechanical material:

| Folder | Focus |
|---|---|
| `01-direct/verbs` | forms found by removing the Spanish infinitive ending |
| `02-spelling-patterns/verbs` | visible, reusable spelling changes |
| `02-spelling-patterns/past-and-progressive` | cognate bridges for **-ed** and **-ing** forms |
| `03-word-families/verbs` | shared roots and prefixes |
| `04-memory-bridges/verbs` | useful associations that are not dependable spelling rules |
| `05-confusion-sets` | false cognates and context-dependent translations |

Teach the reliable pattern first, then its exceptions and false cognates.
