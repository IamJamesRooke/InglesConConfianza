# Vocabulary

This pillar contains the deliberately limited core lexicon used to make the course's mappings, transformations, and structures concrete.

| Area | Focus |
|---|---|
| [Core](core/README.md) | High-reuse verbs, nouns, descriptions, domains, and expressions used to build and practice English structure. |
| [Mappings](../mappings/README.md) | Choose a natural form in either direction from meaning, function, and context. |
| [Transformations](../transformations/README.md) | Learn cognates and productive changes from one familiar word or form to another. |

Vocabulary folders do not represent a list to memorize before using the language. Structure lessons should introduce only the words needed to make their contrasts concrete.

Mapping folders identify the learner-facing explanation, not separate courses. Transformations provide the productive vocabulary layer that was formerly divided between cognates, word building, and verb-form inventories.
