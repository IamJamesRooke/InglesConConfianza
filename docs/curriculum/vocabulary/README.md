# Vocabulary

Vocabulary is the compact reference layer for useful words and expressions that do not currently justify independent contextual mapping lessons. It supports lesson building without competing with the canonical [Mappings](../mappings/README.md), [Transformations](../transformations/README.md), or [Structure](../structure/README.md) collections.

All category files are deliberately flat. **Core** and **supplemental** are priorities inside the tables, not separate directory trees: core vocabulary is likely to appear early, while supplemental vocabulary can be introduced whenever a lesson needs it.

## Editing rule

Add a word to the most useful existing category and record its priority in the row or family index. Create a new category only when the material cannot be scanned naturally in an existing file. If one source word has several context-dependent translations that merit explicit teaching, promote it to the appropriate mapping direction instead of expanding this reference layer indefinitely.

Six previously structured mapping records remain nested under `entries` in the relevant category frontmatter. Their IDs and examples are retained for later database migration even though the vocabulary itself is presented as a table-first reference.
