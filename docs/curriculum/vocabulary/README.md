# Vocabulary

This pillar contains the deliberately limited core lexicon and the productive systems that let learners acquire additional words independently.

| Area | Focus |
|---|---|
| [Core Verbs](core-verbs/README.md) | High-reuse verb meanings used to build and practice English structure. |
| [Core Nouns](core-nouns/README.md) | A small noun inventory for concrete, reusable examples. |
| [Core Adjectives and States](core-adjectives-and-states/README.md) | Essential descriptions, evaluations, physical states, and practical qualities. |
| [Everyday Domains](everyday-domains/README.md) | Small contextual sets such as the place vocabulary used in location lessons. |
| [Expressions](expressions/README.md) | High-frequency social and conversational expressions. |
| [Cognates](cognates/README.md) | Reliable inference patterns, spelling changes, memory bridges, and confusion sets. |
| [Transformations](transformations/README.md) | Productive English word families and visible form changes. |

Vocabulary folders do not represent a list to memorize before using the language. Structure lessons should introduce only the words needed to make their contrasts concrete.
