# Expressions

This folder contains a deliberately small set of conversational chunks that should be learned as complete expressions rather than translated word by word.

| Function | Core expressions |
|---|---|
| making a request polite | **please** |
| expressing gratitude | **thank you / thanks** |
| responding to gratitude | **you're welcome / no problem** |
| apologizing or getting attention | **I'm sorry / excuse me** |

The curriculum keeps this category small. Additional idioms and fixed expressions can be evaluated during later curation.
