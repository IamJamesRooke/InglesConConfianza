# Speed, Price, and Sufficiency

| Spanish | English |
|---|---|
| rápido | fast |
| lento | slow |
| despacio | slowly |
| gratuito | free |
| caro | expensive |
| barato / económico | cheap |
| suficiente | enough |

| Spanish | English |
|---|---|
| El carro es rápido. | The car is fast. |
| El carro es lento. | The car is slow. |
| Laura habla despacio. | Laura speaks slowly. |
| El evento es gratuito. | The event is free. |
| Este apartamento es caro. | This apartment is expensive. |
| Ese apartamento es barato. | That apartment is cheap. |
| Tenemos suficiente tiempo. | We have enough time. |

**Fast** can be an adjective or an adverb: **a fast car / the car goes fast**. Use **slow** as an adjective and **slowly** as the default adverb.
