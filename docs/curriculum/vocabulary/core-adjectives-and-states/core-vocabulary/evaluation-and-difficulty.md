# Evaluation and Difficulty

| Spanish | English |
|---|---|
| bueno | good |
| malo | bad |
| práctico | practical |
| lógico | logical |
| difícil | difficult |
| duro / difícil | hard |
| fácil | easy |

| Spanish | English |
|---|---|
| Es una idea buena y práctica. | It is a good, practical idea. |
| Es una mala idea. | It is a bad idea. |
| La decisión es lógica. | The decision is logical. |
| Este trabajo es difícil. | This work is difficult. |
| La primera parte es fácil, pero la segunda es difícil. | The first part is easy, but the second is hard. |

**Hard** can mean **difficult** or physically **duro**. Context identifies the meaning.
