# Connector **That** After a Description

**That** can introduce the idea connected to a reaction, certainty or evaluation.

| Spanish | English |
|---|---|
| Estoy segura de que el archivo está listo y me alegra que Laura lo haya revisado. | I'm sure that the file is ready, and I'm glad that Laura reviewed it. |

Common chunks include **be sure that**, **be aware that**, **be glad that**, **be sorry that**, and **be surprised that**. In conversation, **that** is often omitted: **I'm sure it's ready**.
