# **Such a + Description + Singular Thing**

Use **such a/an + description + singular thing**. **So** goes directly before the description.

| Spanish | English |
|---|---|
| Ella es una mujer tan paciente porque ha tenido una vida muy difícil. | She's such a patient woman because she's had such a difficult life. |

Compare **She's so patient** with **She's such a patient woman**.
