# Uses of **Really**

| Lesson | Spanish | English |
|---|---|---|
| [**Really** Meaning Truly](01-really-meaning-truly.md) | ¿Laura de verdad renunció, o solo está pensando en irse? | Did Laura really quit, or is she only thinking about leaving? |
| [**Really?** as a Reaction](02-really-as-a-reaction.md) | —Conseguí el trabajo en Toronto. —¿En serio? ¡Felicitaciones! | “I got the job in Toronto.” “Really? Congratulations!” |
| [**Really** as an Intensifier](03-really-as-an-intensifier.md) | Es muy importante verificar el número de cuenta porque no podremos cancelar la transferencia. | It's really important to verify the account number because we won't be able to cancel the transfer. |
| [**Really + Verb**](04-really-plus-verb.md) | Me gusta mucho este apartamento, pero no puedo pagar el arriendo. | I really like this apartment, but I can't afford the rent. |
| [**Not Really**](05-not-really.md) | —¿Te gustó la película? —La verdad, no mucho; la historia era demasiado predecible. | “Did you like the movie?” “Not really; the story was too predictable.” |
