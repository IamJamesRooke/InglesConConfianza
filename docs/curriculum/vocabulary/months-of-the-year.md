# Months of the Year

The twelve months as a compact bilingual reference.
## Quick reference

| Spanish | English |
|---|---|
| enero | January |
| febrero | February |
| marzo | March |
| abril | April |
| mayo | May |
| junio | June |
| julio | July |
| agosto | August |
| septiembre | September |
| octubre | October |
| noviembre | November |
| diciembre | December |

English month names begin with a capital letter. Date order and the use of **in** and **on** are collected in [Dates and Calendar Periods](dates-and-calendar-periods.md).
