# Translations of Spanish **Quizá**

Spanish **quizá** and its alias **quizás** introduce uncertainty. English commonly chooses **maybe**, **perhaps**, or **possibly**.

| Source | Target | Atomic mapping |
|---|---|---|

| **quizá** | **perhaps** | [open](<quizá (perhaps).md>) |
| **quizá** | **possibly** | [open](<quizá (possibly).md>) |
