# Spanish **Correr**

| Spanish | English |
|---|---|
| Corro todas las mañanas. | I run every morning. |
| El agua corre por la calle. | Water flows down the street. |
| Corre la silla hacia la ventana. | Move the chair toward the window. |
| El programa corre bien. | The program runs well. |
| No quiero correr ese riesgo. | I don't want to take that risk. |

**Correr** can become **run, flow, move**, or **take**, depending on what moves or what risk is accepted.
