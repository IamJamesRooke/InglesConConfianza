# **Hora** → **Hour** or **Time**

| Spanish | English |
|---|---|
| Esperé una hora. | I waited for an hour. |
| ¿Qué hora es? | What time is it? |

Use **hour** for a sixty-minute unit. Use **time** when **la hora** means the clock time. The broader clock system lives in [structure](../../../../structure/time-and-sequencing/basic-units-and-clock-time.md).
