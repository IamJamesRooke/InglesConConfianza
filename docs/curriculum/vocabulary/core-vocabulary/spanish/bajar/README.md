# Translations of Spanish **Bajar**

Spanish **bajar** can become **go down, come down, lower, get off, download, turn down, fall, take down**, or **lose weight**. Each lesson keeps **subir** visible as the useful inverse contrast; the same contrasts are indexed under [**subir**](../subir/README.md).

| Lesson | Main English mappings |
|---|---|
| [movement](01-go-or-come-up-and-down.md) | go down / come down |
| [moving something](02-raise-or-lower.md) | lower |
| [transport](03-get-on-or-off-transport.md) | get off |
| [files](04-upload-or-download.md) | download |
| [settings](05-volume-and-settings.md) | turn down |
| [prices and levels](06-prices-and-levels.md) | fall |
| [take something down](07-pick-up-or-drop-off.md) | take down |
| [weight](08-weight.md) | lose weight |
