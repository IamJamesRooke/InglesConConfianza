# Spanish **Apagar**

| Spanish | English |
|---|---|
| Apaga la luz. | Turn off the light. |
| Apaga el computador. | Shut down the computer. |
| Los bomberos apagaron el fuego. | The firefighters put out the fire. |
| La música se apagó. | The music faded away. |

**Apagar** can become **turn off, shut down, put out**, or **fade away**, depending on what stops producing energy, fire, or sound.
