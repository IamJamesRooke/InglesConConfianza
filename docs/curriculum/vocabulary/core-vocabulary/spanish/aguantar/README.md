# Spanish **Aguantar**

| Spanish | English |
|---|---|
| No aguanto este calor. | I can't stand this heat. |
| Aguantó el dolor sin quejarse. | She endured the pain without complaining. |
| Aguanta un momento. | Hold on a moment. |
| La silla no aguanta ese peso. | The chair can't support that weight. |

**Aguantar** can become **stand, endure, hold on**, or **support**, depending on what must be tolerated or sustained.
