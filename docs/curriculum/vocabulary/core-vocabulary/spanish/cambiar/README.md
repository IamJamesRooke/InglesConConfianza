# Spanish **Cambiar**

| Spanish | English |
|---|---|
| Cambié el plan. | I changed the plan. |
| Quiero cambiar dólares por pesos. | I want to exchange dollars for pesos. |
| Cambia de canal. | Switch channels. |
| Voy a cambiarme antes de salir. | I am going to get changed before leaving. |

General alteration, currency exchange, switching options, and changing clothes use different English expressions.
