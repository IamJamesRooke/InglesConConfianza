# Spanish **Olvidar**

| Spanish | English |
|---|---|
| Olvidé la reunión. | I forgot the meeting. |
| Olvidé las llaves en casa. | I left my keys at home. |
| Se me olvidaron las llaves. | I forgot my keys. |
| Olvídate de ese problema. | Forget about that problem. |

**Olvidar** may become **forget** or **leave behind**. Accidental **se me olvidó** changes perspective in English rather than translating word for word.
