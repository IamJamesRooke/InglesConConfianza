# Spanish **Jugar**

| Spanish | English |
|---|---|
| Los niños juegan fútbol. | The children play soccer. |
| Jugaron dinero en la carrera. | They gambled money on the race. |
| Laura juega un papel importante. | Laura plays an important role. |
| No juegues con mis sentimientos. | Don't play with my feelings. |

Games use **play**, betting uses **gamble**, and figurative combinations require the corresponding complete English expression.
