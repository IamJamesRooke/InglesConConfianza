# Spanish **Gastar**

| Spanish | English |
|---|---|
| Gasté demasiado dinero. | I spent too much money. |
| No gastes el tiempo discutiendo. | Don't waste time arguing. |
| Gastaron toda el agua. | They used up all the water. |
| Los zapatos se gastaron. | The shoes wore out. |

**Gastar** can become **spend, waste**, or **use up**; pronominal **gastarse** often means **wear out**.
