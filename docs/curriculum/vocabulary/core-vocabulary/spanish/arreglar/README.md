# Spanish **Arreglar**

| Spanish | English |
|---|---|
| Arreglaron el computador. | They fixed the computer. |
| Arreglé una reunión con Laura. | I arranged a meeting with Laura. |
| Arregla tu cuarto. | Tidy your room. |
| Me arreglé antes de salir. | I got ready before leaving. |
| Ya arreglamos el problema. | We sorted out the problem. |

**Arreglar** can become **fix, arrange, tidy, get ready**, or **sort out**.
