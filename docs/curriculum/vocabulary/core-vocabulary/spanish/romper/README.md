# Spanish **Romper**

| Spanish | English |
|---|---|
| Rompí el vaso. | I broke the glass. |
| Rompió la carta. | She tore up the letter. |
| Rompieron el récord. | They broke the record. |
| Laura rompió con Mateo. | Laura broke up with Mateo. |
| El ruido rompió el silencio. | The noise interrupted the silence. |

**Romper** can become **break, tear, break a record, break up**, or **interrupt**.
