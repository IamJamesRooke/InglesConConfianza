# Spanish **Empezar**

| Spanish | English |
|---|---|
| La clase empieza a las ocho. | Class starts at eight. |
| Empecé a trabajar aquí en enero. | I began working here in January. |
| Empieza por leer las instrucciones. | Start by reading the instructions. |
| Para empezar, necesitamos un plan. | To begin with, we need a plan. |

**Empezar** can become **start** or **begin**, while **empezar por** and **para empezar** require complete English patterns.
