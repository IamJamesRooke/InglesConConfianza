# Spanish **Cerrar**

| Spanish | English |
|---|---|
| Cierra la puerta. | Close the door. |
| La tienda cierra a las ocho. | The store closes at eight. |
| Cerraron la calle. | They blocked off the street. |
| Cerramos el trato ayer. | We closed the deal yesterday. |
| Cierra sesión antes de salir. | Log out before leaving. |

**Cerrar** can become **close, shut, block off, close a deal**, or **log out**, depending on what is made inaccessible or complete.
