# Spanish **Avisar**

| Spanish | English |
|---|---|
| Avísame cuando llegues. | Let me know when you arrive. |
| Le avisaron del peligro. | They warned her about the danger. |
| Te aviso que mañana no abren. | I am telling you that they are closed tomorrow. |
| El sistema avisa cuando hay un error. | The system alerts you when there is an error. |

**Avisar** can become **let someone know, warn, tell**, or **alert**.
