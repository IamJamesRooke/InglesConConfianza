# Hard → Harder → the Hardest

Most one-syllable adjectives add **-er** for a comparison and **-est** for the highest degree:

| Base | Comparative | Superlative |
|---|---|---|
| hard | harder | the hardest |

| Spanish | English |
|---|---|
| Esta pregunta es difícil. | This question is hard. |
| Esta pregunta es más difícil que la primera. | This question is harder than the first one. |
| Esta es la pregunta más difícil del examen. | This is the hardest question on the test. |

Use **than** to name the other side of a comparison and normally use **the** before the superlative.
