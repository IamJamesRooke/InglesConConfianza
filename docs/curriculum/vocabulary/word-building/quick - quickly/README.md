# **Quick → Quickly**

Add **-ly** to many adjectives to form an adverb describing how an action happens.

| Adjective | **-ly** adverb | Spanish |
|---|---|---|
| quick | **quickly** | rápidamente |
| normal | **normally** | normalmente |
| careful | **carefully** | cuidadosamente |
| probable | **probably** | probablemente |
| easy | **easily** | fácilmente |

| Spanish | English |
|---|---|
| **El técnico resolvió el problema rápidamente.** | The technician solved the problem **quickly**. |
| **Revisé el contrato cuidadosamente antes de firmarlo.** | I reviewed the contract **carefully** before signing it. |
| **Probablemente llegaremos antes de las ocho.** | We will **probably** arrive before eight. |

## Spelling

Some words change before **-ly**: **probable → probably** and **easy → easily**.

## Meaning Distinction

Not every word ending in **-ly** is an adverb. **Friendly** is an adjective meaning **amable**.

| Spanish | English |
|---|---|
| **La recepcionista fue muy amable.** | The receptionist was very **friendly**. |
