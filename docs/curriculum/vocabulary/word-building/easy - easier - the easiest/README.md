# Easy → Easier → the Easiest

An adjective ending in consonant + **y** changes **y** to **i** before **-er** or **-est**:

| Base | Comparative | Superlative |
|---|---|---|
| easy | easier | the easiest |

| Spanish | English |
|---|---|
| Esta parte es fácil. | This part is easy. |
| Esta parte es más fácil que la primera. | This part is easier than the first one. |
| Esta es la parte más fácil del curso. | This is the easiest part of the course. |

The same spelling change appears in **happy → happier → the happiest**. Do not write *easyer* or *easyest*.
