# Good → Better → the Best

The comparison forms of **good** are irregular:

| Base | Comparative | Superlative |
|---|---|---|
| good | better | the best |

| Spanish | English |
|---|---|
| Esta opción es buena. | This option is good. |
| Esta opción es mejor que la anterior. | This option is better than the previous one. |
| Esta es la mejor opción para Laura. | This is the best option for Laura. |

The forms must be learned as one family. Do not use *gooder* or *the goodest*.

The opposite family is also irregular: **bad → worse → the worst**.
