# **To → Towards** and the **-ward/-wards** Family

**Toward** means **in the direction of**. The ending **-ward** attaches to familiar direction words to create the same “in the direction of” idea.

## Productive Pattern

| Base | Directional form |
|---|---|
| **in** | **inward(s)** |
| **out** | **outward(s)** |
| **up** | **upward(s)** |
| **down** | **downward(s)** |
| **for(e)** | **forward(s)** |
| **back** | **backward(s)** |
| **on** | **onward(s)** |
| **home** | **homeward(s)** |

The form without **-s** is standard in both American and British English. The **-s** form is especially common in British English.

Only the form without **-s** normally goes before a noun: **an upward movement**, **an outward-facing door**. Use either form for direction: **move upward/upwards**.

## Mastery Phrases

| Spanish | English |
|---|---|
| Dé un paso hacia adentro, mire hacia arriba y luego camine hacia adelante. | Step inward, look upward, and then walk forward. |
| La puerta se abre hacia afuera, así que dé un paso hacia atrás. | The door opens outward, so step backward. |
| Prepárese de antemano; después seguiremos adelante hacia el norte. | Prepare beforehand; afterward, we'll continue onward and head northward. |
