# Ordinal Numbers

Position words from first onward, including compounds and spelling changes.
## Compound and Large Ordinals

For a compound number, only the final part becomes ordinal:

| Number | Spanish | English |
|---|---|---|
| 20th | vigésimo | twentieth |
| 21st | vigésimo primero | twenty-first |
| 22nd | vigésimo segundo | twenty-second |
| 23rd | vigésimo tercero | twenty-third |
| 24th | vigésimo cuarto | twenty-fourth |
| 25th | vigésimo quinto | twenty-fifth |
| 28th | vigésimo octavo | twenty-eighth |
| 29th | vigésimo noveno | twenty-ninth |
| 30th | trigésimo | thirtieth |
| 31st | trigésimo primero | thirty-first |

Notice the spelling:

- **twenty-fourth**, not *twenty-forth*
- **twentieth**, not *twentyth*
- **thirtieth**, not *thirtyth*

Large round numbers also take an ordinal ending:

| Number | Spanish | English |
|---|---|---|
| 100th | centésimo | hundredth |
| 1,000th | milésimo | thousandth |
| 1,000,000th | millonésimo | millionth |

The written ending follows the final ordinal word: **21st, 22nd, 23rd**, but **11th, 12th**, and **13th** all use **-th**.

## Ordinal Numbers: First to Nineteenth

Cardinal numbers express quantity; ordinal numbers express position.

| Number | Spanish | English |
|---|---|---|
| 1st | primero | first |
| 2nd | segundo | second |
| 3rd | tercero | third |
| 4th | cuarto | fourth |
| 5th | quinto | fifth |
| 6th | sexto | sixth |
| 7th | séptimo | seventh |
| 8th | octavo | eighth |
| 9th | noveno | ninth |
| 10th | décimo | tenth |
| 11th | undécimo | eleventh |
| 12th | duodécimo | twelfth |
| 13th | decimotercero | thirteenth |
| 14th | decimocuarto | fourteenth |
| 15th | decimoquinto | fifteenth |
| 16th | decimosexto | sixteenth |
| 17th | decimoséptimo | seventeenth |
| 18th | decimoctavo | eighteenth |
| 19th | decimonoveno | nineteenth |

| Spanish | English |
|---|---|
| Laura fue la primera persona en llegar. | Laura was the first person to arrive. |
| La oficina está en el octavo piso. | The office is on the eighth floor. |

Most written ordinals end in **-th**, but **first, second**, and **third** are irregular.
