# Colors and Light

| Spanish | English |
|---|---|
| rojo | red |
| azul | blue |
| verde | green |
| amarillo | yellow |
| blanco | white |
| negro | black |
| claro | light |
| oscuro | dark |

Use **light** and **dark** before a color to describe its shade:

| Spanish | English |
|---|---|
| La pared es azul claro. | The wall is light blue. |
| Laura lleva una chaqueta verde oscuro. | Laura is wearing a dark green jacket. |
| El texto es negro sobre un fondo blanco. | The text is black on a white background. |

English places the shade word before the color: **light blue**, not *blue light*.
