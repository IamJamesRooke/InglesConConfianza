# **Allow**

| Spanish | English |
|---|---|
| No permiten fumar aquí, pero permiten que los clientes esperen afuera. | They don't allow smoking here, but they allow customers to wait outside. |

Use **allow + -ing** for an activity and **allow + person + to + verb** when naming who receives permission.

The spelling **al-** does not transparently contribute the modern meaning “permit.”
