# Prefix Transformations

These maps collect meaning-changing prefixes and high-value beginning patterns. Some groups, especially **al-** and parts of **be-**, are recognition families rather than fully productive grammatical prefixes.

| Beginning | Core idea |
|---|---|
| [**al-**](al-/README.md) | Recognize **also, alone, already, always, although**, and related words. |
| [**be-**](be-/README.md) | Recognize **become, because, before, beneath/below, beside**, and related words. |
| [**fore-**](fore-/README.md) | Front, before, or advance: **forearm, forecast, foresee, forewarn**. |
| [**un-**](un-/README.md) | Not or the opposite: **happy → unhappy**. |
| [**re-**](re-/README.md) | Again: **write → rewrite**. |
| [**dis-**](dis-/README.md) | Not, opposite, or apart: **agree → disagree**. |
| [**mis-**](mis-/README.md) | Wrongly: **understand → misunderstand**. |
| [**over-**](over-/README.md) | Too much or above: **cook → overcook**. |
| [**under-**](under-/README.md) | Too little or below: **estimate → underestimate**. |
