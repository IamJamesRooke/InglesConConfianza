# **Accept → Acceptable**

Add **-able** or **-ible** to many verbs to express that something can be done or has a particular quality. The correct suffix must be learned with the word.

| Verb | Adjective | Spanish |
|---|---|---|
| accept | **acceptable** | aceptable |
| understand | **understandable** | comprensible |
| predict | **predictable** | predecible |
| access | **accessible** | accesible |
| convert | **convertible** | convertible |

| Spanish | English |
|---|---|
| **La calidad del informe es aceptable.** | The quality of the report is **acceptable**. |
| **Su reacción es comprensible dadas las circunstancias.** | Her reaction is **understandable** under the circumstances. |
| **El edificio debe ser accesible para todos los visitantes.** | The building must be **accessible** to every visitor. |
