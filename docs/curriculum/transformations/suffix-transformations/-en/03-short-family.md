# **Short → Shortness / Shorten**

| Form | Spanish | English |
|---|---|---|
| **short** | El informe es corto. | The report is short. |
| **shortness** | Me sorprendió la brevedad del informe. | The shortness of the report surprised me. |
| **shorten** | Tenemos que acortarlo. | We need to shorten it. |
| **shortening** | El acortamiento eliminó dos páginas. | The shortening removed two pages. |
| **shortened** | Leímos la versión abreviada. | We read the shortened version. |

**Shortener** is a real word for a person, tool, or substance that shortens something, but it is uncommon outside specialized contexts.
