# **Long → Length → Lengthen**

| Form | Spanish | English |
|---|---|---|
| **long** | El cable es largo. | The cable is long. |
| **length** | Mida la longitud del cable. | Measure the cable's length. |
| **lengthen** | Tenemos que alargar el cable. | We need to lengthen the cable. |
| **lengthening** | El alargamiento tomó una hora. | The lengthening took an hour. |
| **lengthened** | Probamos el cable alargado. | We tested the lengthened cable. |

The spelling reveals a real stem change: **long → length → lengthen**.

**Lengthener** is possible for a person, tool, or piece that lengthens something, but it is uncommon outside specialized contexts.
