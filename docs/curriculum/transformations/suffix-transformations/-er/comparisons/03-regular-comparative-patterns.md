# Regular Comparative Patterns

Most short adjectives add **-er** to compare two things.

| Base | Comparative | Spanish bridge |
|---|---|---|
| hard | harder | difícil → más difícil |
| fast | faster | rápido → más rápido |
| slow | slower | lento → más lento |
| cheap | cheaper | barato → más barato |
| safe | safer | seguro → más seguro |

Some short adjectives double the final consonant: **big → bigger**.

Adjectives ending in consonant + **y** change **y** to **i**:

| Base | Comparative |
|---|---|
| funny | funnier |
| happy | happier |
| easy | easier |

Longer adjectives usually use **more** instead of **-er**: **more important**, **more difficult**, and **more beautiful**. Do not combine the patterns: **more difficult**, not *more difficulter*.
