# **Follow → Followed → Followed**

The written **-ed** ending is pronounced `/d/`.


When the base ends in a voiced vowel sound, **-ed** is pronounced `/d/`. In **follow**, the written **w** is part of the vowel spelling:

**follow → followed**

| Course source | Base | Past and past participle | Spanish bridge |
|---|---|---|---|
| model vocabulary | follow | followed | siguió / seguido |
| established transformation vocabulary | allow | allowed | permitió / permitido |

- Past: Laura **followed** the instructions because the teacher **allowed** extra time.
- Past participle: Laura has **followed** the instructions because the teacher has **allowed** extra time.

There is no regular core verb in the course for this narrow written **w** family, so this lesson uses the source model **follow** and the established **allow** transformation.
