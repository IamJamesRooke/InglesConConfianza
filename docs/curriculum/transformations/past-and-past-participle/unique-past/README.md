# Unique Past Forms

This branch teaches irregular past forms that need attention separate from their participles.

| Group | Examples |
|---|---|
| [Ending in `/d/`](ending-in-d/README.md) | **do → did** |
| [Ending in `/t/`](ending-in-t/README.md) | **get → got**, **go → went** |
| [Vowel shifts](vowel-shifts/README.md) | **see → saw**, **take → took** |
| [Was and were](was-and-were/README.md) | **be → was/were** |
