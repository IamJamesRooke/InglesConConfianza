# Matching Past and Past Participle

In these irregular verbs, the past and participle match each other. The final sound provides the first teaching split.

| Group | Model |
|---|---|
| [No change](no-change/README.md) | **cut → cut → cut** |
| [Ending in `/d/`](ending-in-d/README.md) | **have → had → had** |
| [Ending in `/t/`](ending-in-t/README.md) | **feel → felt → felt** |
| [Other endings](other-endings/README.md) | **sit → sat → sat** |
