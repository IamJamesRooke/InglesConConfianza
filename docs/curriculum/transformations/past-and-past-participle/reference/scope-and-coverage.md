# What “All Irregular Verbs” Means

English has no single official total. Counts change according to what a list includes:

- head verbs only or every prefixed compound;
- current forms or archaic forms;
- standard alternatives such as **burned/burnt**;
- verbs that are irregular only in one meaning;
- modal verbs such as **can → could**, which have no participle.

This course uses three explicit boundaries:

1. **Core memory system:** all high-frequency irregular head verbs in standard modern English.
2. **Extended standard set:** current lower-frequency forms and accepted regional alternatives.
3. **Inherited compounds:** learn the head verb once, then apply it to transparent compounds such as **take → overtake**, **write → rewrite**, and **do → undo**.

It excludes genuinely archaic forms that a learner may encounter in old literature but should not produce in ordinary modern English. Those are dictionary-reference material, not a speaking target.

## Why the number becomes misleading

If **write → wrote → written** is one family, then **rewrite, overwrite, underwrite**, and other transparent compounds do not require four new memory patterns. The vocabulary expands, but the transformation does not.

The course therefore promises complete coverage of the modern transformation patterns—not a padded count created by listing every possible prefix as an unrelated verb.
