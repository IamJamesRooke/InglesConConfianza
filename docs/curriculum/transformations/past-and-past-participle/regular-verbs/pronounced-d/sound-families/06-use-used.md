# **Use → Used**

Verb **use** ends in the voiced sound `/z/`, so **-ed** is pronounced `/d/`:

**use → used**

| Course source | Base | Past and past participle | Spanish bridge |
|---|---|---|---|
| core verb | use | used | usó / usado |
| core verb | close | closed | cerró / cerrado |
| memory bridge | refuse | refused | rehusó / rechazó |

- Past: Laura **used** the application, but her colleague **refused** to use it.
- Past participle: Laura has **used** the application, but her colleague has **refused** to use it.

Do not confuse the verb with the noun:

- verb **use** `/juːz/` → **used** `/juːzd/`
- noun **use** `/juːs/`
