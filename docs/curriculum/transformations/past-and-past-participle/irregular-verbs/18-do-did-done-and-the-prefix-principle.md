# **Do → Did → Done** and the Prefix Principle

Many compounds inherit the complete irregular chain of the final verb.

| Model | Inherited examples |
|---|---|
| do → did → done | undo → undid → undone; overdo → overdid → overdone |
| take → took → taken | overtake, retake, undertake |
| come → came → come | become, overcome |
| stand → stood → stood | understand, withstand |
| tell → told → told | foretell |
| see → saw → seen | foresee |
| write → wrote → written | rewrite |
| draw → drew → drawn | withdraw |
| give → gave → given | forgive |
| get → got → got/gotten | forget |

This is why counting every compound creates inflated “370+ verb” lists. Learn the head family and attach the prefix.
