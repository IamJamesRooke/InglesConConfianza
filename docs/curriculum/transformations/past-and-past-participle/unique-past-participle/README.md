# Unique Past Participles

This branch teaches irregular participles that need attention separate from their past forms.

| Group | Examples |
|---|---|
| [Ending in `/n/`](ending-in-n/README.md) | **be → been**, **see → seen** |
| [Vowel shifts](vowel-shifts/README.md) | **drink → drunk**, **run → run** |
| [Returns to the base](returns-to-base/README.md) | **come → came → come** |
| [Other `-en` families](other-en-families/README.md) | **speak → spoken**, **write → written** |
