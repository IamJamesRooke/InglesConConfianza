# Transformations

Transformations are the productive vocabulary core of the course: a familiar English word or visible form becomes another useful word or form.

| Area | Purpose |
|---|---|
| [Cognates](cognates/README.md) | Use reliable Spanish-English similarities, spelling patterns, memory bridges, and confusion sets. |
| [Suffix Transformations](suffix-transformations/README.md) | Turn a base into a related form with endings such as **-ness, -ish, -er**, and **-tion**. |
| [Prefix Transformations](prefix-transformations/README.md) | Recognize meaning-changing prefixes and memorable beginning families such as **un-, fore-, be-**, and **al-**. |
| [Past and Past Participle](past-and-past-participle/README.md) | Existing regular and irregular form families; leave intact until the dedicated collation pass. |
| [Past II — Needs Merging](<past-II%20(needs%20merging)/README.md>) | Preserved past-form branch awaiting collation. |
| [Past Participle II — Needs Merging](<past-participle-II%20(needs%20merging)/README.md>) | Preserved participle-form branch awaiting collation. |

Mixed legacy word-building families are preserved under [root curriculum unsorted](../unsorted/transformation-source-families/README.md). Material that does not clearly belong to a canonical transformation remains in that single shared unsorted area.
