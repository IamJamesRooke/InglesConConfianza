# Cognates: **-il → -ile**

In these cognates, Spanish **-il** corresponds to English **-ile**. Some words require an additional spelling change.

| Spanish | English | Example |
|---|---|---|
| móvil | **mobile** | **La clínica ofrece una unidad móvil para las zonas rurales.**<br>The clinic provides a mobile unit for rural areas. |
| automóvil | **automobile** | **El museo exhibe un automóvil de 1920.**<br>The museum displays an automobile from 1920. |
| ágil | **agile** | **La empresa necesita un equipo ágil y flexible.**<br>The company needs an agile and flexible team. |
| frágil | **fragile** | **El paquete contiene un objeto frágil.**<br>The package contains a fragile object. |
| hostil | **hostile** | **La conversación creó un ambiente hostil.**<br>The conversation created a hostile environment. |
