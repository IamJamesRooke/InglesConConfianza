# Noun Cognates: **-ancia → -ance**

In these cognates, Spanish **-ancia** corresponds to English **-ance**.

| Spanish | English | Example |
|---|---|---|
| importancia | **importance** | **La profesora explicó la importancia de practicar cada día.**<br>The teacher explained the importance of practicing every day. |
| distancia | **distance** | **La distancia entre las dos ciudades es de cien kilómetros.**<br>The distance between the two cities is one hundred kilometers. |
| instancia | **instance** | **En este caso, encontramos una instancia del mismo error.**<br>In this case, we found an instance of the same error. |
| abundancia | **abundance** | **La región tiene una abundancia de recursos naturales.**<br>The region has an abundance of natural resources. |
