# Cognate Forms: Spanish **-iendo** and English **-ing**

Spanish **-iendo** forms often correspond to related English forms ending in **-ing**.

| Spanish | English | Example |
|---|---|---|
| recibiendo | **receiving** | **Estamos recibiendo muchas solicitudes esta semana.**<br>We are receiving many applications this week. |
| decidiendo | **deciding** | **El comité está decidiendo cómo usar el presupuesto.**<br>The committee is deciding how to use the budget. |

In English, the **-ing** form stays the same; only the form of **be** changes:

| Spanish | English |
|---|---|
| **Estoy recibiendo las solicitudes.** | I am **receiving** the applications. |
| **Estás recibiendo las solicitudes.** | You are **receiving** the applications. |
| **Estamos recibiendo las solicitudes.** | We are **receiving** the applications. |
| **Están recibiendo las solicitudes.** | They are **receiving** the applications. |
| **Ella está recibiendo las solicitudes.** | She is **receiving** the applications. |

## Spelling

- Usually remove final **-e** before adding **-ing**: **receive → receiving**, **decide → deciding**.
- Some short or final-stressed verbs double their last consonant: **permit → permitting**.

## Additional Cognates

| Spanish | English | Example |
|---|---|---|
| permitiendo | **permitting** | **La empresa está permitiendo horarios más flexibles.**<br>The company is permitting more flexible schedules. |
| produciendo | **producing** | **La fábrica está produciendo más unidades este mes.**<br>The factory is producing more units this month. |
| proponiendo | **proposing** | **Estamos proponiendo una solución más sencilla.**<br>We are proposing a simpler solution. |
| manteniendo | **maintaining** | **El equipo está manteniendo el sistema actualizado.**<br>The team is maintaining the system up to date. |
