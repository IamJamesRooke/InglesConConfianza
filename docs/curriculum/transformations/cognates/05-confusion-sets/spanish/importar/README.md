# Translations of Spanish **Importar**

Spanish **importar** can express importance, personal concern, polite **mind**, or the literal movement of goods.

| Lesson | Spanish | English |
|---|---|---|
| [matter](01-matter.md) | Esto importa mucho. | This matters a lot. |
| [care](02-care.md) | Me importa lo que pase. | I care about what happens. |
| [mind](03-mind.md) | ¿Te importa si abro la ventana? | Do you mind if I open the window? |
| [import goods](04-import-goods.md) | La empresa importa café colombiano. | The company imports Colombian coffee. |
