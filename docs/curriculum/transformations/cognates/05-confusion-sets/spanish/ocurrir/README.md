# Spanish **Ocurrir**

| Spanish | English |
|---|---|
| El accidente ocurrió anoche. | The accident happened last night. |
| Eso ocurre con frecuencia. | That occurs frequently. |
| Se me ocurrió una idea. | An idea occurred to me. / I had an idea. |
| ¿Qué ocurrió? | What happened? |

Events use **happen** or **occur**. Pronominal **ocurrírsele** often becomes **occur to someone** or the more natural **have an idea**.
