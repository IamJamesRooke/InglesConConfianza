# Spanish **Único**

| Spanish | English |
|---|---|
| Es el único camino. | It is the only way. |
| Es una oportunidad única. | It is a unique opportunity. |
| Es hijo único. | He is an only child. |
| Lo único que quiero es dormir. | All I want is to sleep. |

**Único** can become **only, unique**, or part of complete expressions such as **only child** and **all I want**.
