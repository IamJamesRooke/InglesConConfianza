# **Disponibilidad** → **Availability**

| Spanish | English |
|---|---|
| Necesitamos confirmar la disponibilidad del salón. | We need to confirm the room's availability. |
| La disponibilidad de Ana cambia cada semana. | Ana's availability changes every week. |

The noun **disponibilidad** becomes **availability**. The related adjective **disponible** becomes **available** or, for a person's schedule, **free**.
