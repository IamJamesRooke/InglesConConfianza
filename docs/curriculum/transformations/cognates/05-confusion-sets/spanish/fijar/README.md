# Translations of Spanish **Fijar** and **Fijarse**

Spanish **fijar** and **fijarse** map to fixing, setting, establishing, noticing, paying attention, and emphatic discourse.

| Lesson | Spanish | English |
|---|---|---|
| [**Fijar → Fix / Attach**](01-fix-or-attach.md) | Fija el estante a la pared. | Fix the shelf to the wall. |
| [**Fijar → Set**](02-set-a-date-or-price.md) | Fijaron la fecha y el precio. | They set the date and the price. |
| [**Fijar → Establish**](03-establish.md) | La empresa fijó nuevas reglas. | The company established new rules. |
| [**Fijarse En → Notice**](04-notice.md) | ¿Te fijaste en el error? | Did you notice the error? |
| [**Fijarse En → Pay Attention To**](05-pay-attention.md) | Fíjate en la pronunciación. | Pay attention to the pronunciation. |
| [**Fijarse → Look Carefully / Check**](06-look-carefully.md) | Fíjate bien antes de firmar. | Look carefully before signing. |
| [**Fíjate → You Know / Just Imagine**](07-discourse-fijate.md) | Fíjate que Ana ya terminó. | You know, Ana has already finished. |
| [**Fijarse Una Meta / En Alguien**](08-set-ones-sights.md) | Se fijó la meta de terminar en junio. | She set herself the goal of finishing in June. |
