# Spanish **Discutir**

| Spanish | English |
|---|---|
| Discutieron por dinero. | They argued about money. |
| Discutimos el plan en la reunión. | We discussed the plan in the meeting. |
| Los candidatos discutieron el tema. | The candidates debated the issue. |

Spanish **discutir** can mean either **argue** or **discuss**. English **discuss** does not normally take **about** before its object.
