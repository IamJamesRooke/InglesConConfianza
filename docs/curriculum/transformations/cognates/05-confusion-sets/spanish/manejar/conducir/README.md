# Spanish **Conducir**

| Spanish | English |
|---|---|
| Conduzco al trabajo. | I drive to work. |
| Esta carretera conduce al aeropuerto. | This road leads to the airport. |
| Ella conduce el programa. | She hosts the program. |
| El director condujo la reunión. | The director led the meeting. |

**Conducir** can become **drive, lead, host**, or **conduct**, according to what is guided.
