# Spanish **Permitir**

## Atomic mappings

- [**permitirle a alguien hacer algo** → **allow someone to do something**](<permitirle a alguien hacer algo (allow someone to do something).md>)
- [**estar permitido** → **be allowed**](<estar permitido (be allowed).md>)

## Teaching overview

| Spanish | English |
|---|---|
| No permiten entrar después de las ocho. | They don't allow entry after eight. |
| Permíteme explicar. | Let me explain. |
| El permiso permite trabajar legalmente. | The permit enables you to work legally. |
| Está permitido estacionar aquí. | Parking is permitted here. |

**Permitir** can become **allow, let, enable**, or formal **permit**, with different English sentence patterns.
