# Spanish **Propio**

| Spanish | English |
|---|---|
| Tengo mi propia oficina. | I have my own office. |
| Es propio de ella llegar temprano. | It is typical of her to arrive early. |
| Lo hizo el propio director. | The director himself did it. |

**Propio** can become **own, typical of**, or emphatic **himself/herself/itself**.
