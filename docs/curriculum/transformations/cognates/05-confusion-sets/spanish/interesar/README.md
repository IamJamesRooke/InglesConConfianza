# Spanish **Interesar**

| Spanish | English |
|---|---|
| Me interesa la historia. | I am interested in history. |
| No me interesa comprarlo. | I am not interested in buying it. |
| Ese asunto le interesa al gobierno. | That matter concerns the government. |
| Solo le interesa el dinero. | He only cares about money. |

**Interesar** can become **be interested in, concern**, or **care about**, and English normally changes the subject structure.
