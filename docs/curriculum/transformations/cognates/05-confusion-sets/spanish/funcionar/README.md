# Spanish **Funcionar**

| Spanish | English |
|---|---|
| El computador no funciona. | The computer doesn't work. |
| El motor funciona con gasolina. | The engine runs on gasoline. |
| Así funciona el sistema. | This is how the system functions. |
| El plan funcionó. | The plan worked out. |

**Funcionar** can become **work, run, function**, or **work out**, depending on whether it describes machinery, systems, or results.
