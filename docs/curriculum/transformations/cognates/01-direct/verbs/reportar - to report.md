# Verb Cognates: **-rt**

In these cognates, remove the Spanish infinitive ending **-ar** to find the English verb ending in **-rt**.

| Spanish | English | Example |
|---|---|---|
| reportar | **to report** | **Debes reportar cualquier actividad sospechosa.**<br>You must report any suspicious activity. |
| transportar | **to transport** | **La empresa transporta flores colombianas por avión.**<br>The company transports Colombian flowers by air. |
| importar | **to import** | **La tienda va a importar computadores desde Canadá.**<br>The store is going to import computers from Canada. |
| exportar | **to export** | **Colombia exporta café a muchos países.**<br>Colombia exports coffee to many countries. |
| deportar | **to deport** | **Un juez debe revisar el caso antes de deportar al extranjero.**<br>A judge must review the case before deporting the foreign national. |

## False Cognates

**Soportar** normally means **to tolerate**, **to bear**, or **to withstand**, not **to support**. **To support** usually means **apoyar**.

| Spanish | English |
|---|---|
| **Esta mesa puede soportar mucho peso.** | This table can **withstand** a lot of weight. |
| **La comunidad decidió apoyar el proyecto.** | The community decided to **support** the project. |
