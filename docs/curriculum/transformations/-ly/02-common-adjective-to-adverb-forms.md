# Common **-ly** Adjective-to-Adverb Forms

Many adjectives form a manner adverb with **-ly**.

| Adjective | Adverb | Spanish bridge |
|---|---|---|
| slow | slowly | lento / despacio |
| logical | logically | lógico / lógicamente |
| practical | practically | práctico / prácticamente |

| Spanish | English |
|---|---|
| El carro es lento. | The car is slow. |
| El carro va despacio. | The car goes slowly. |
| Es una decisión lógica. | It is a logical decision. |
| El argumento está presentado lógicamente. | The argument is presented logically. |
| Es una solución práctica. | It is a practical solution. |
| En la práctica, la solución funciona prácticamente igual. | In practice, the solution works practically the same way. |

The ending is productive, but the Spanish word may change more than just its ending. Learn the useful pair together rather than applying a mechanical translation rule.
