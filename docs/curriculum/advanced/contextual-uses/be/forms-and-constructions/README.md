# Forms and Constructions with **Be**

| Lesson | Spanish | English |
|---|---|---|
| [Be Going To](01-be-going-to.md) | Voy a salir. | I'm going to leave. |
| [Be Able To](02-be-able-to.md) | Puedo ayudar. | I'm able to help. |
| [Passive Be](03-passive-be.md) | Me golpearon. | I was hit. |
| [Progressive Be](04-progressive-be.md) | Estoy trabajando. | I'm working. |
| [Subjunctive Be](05-subjunctive-be.md) | Es importante que estés aquí. | It's important that you be here. |
| [If I Were](06-if-i-were.md) | Si yo fuera usted... | If I were you... |
| [Perfect and Modal Be](07-perfect-and-modal-be.md) | Ha estado aquí y podría estar cansada. | She has been here and could be tired. |

## Mastery Phrase

| Spanish | English |
|---|---|
| Si yo fuera usted, estaría trabajando ahora para poder terminar antes de que el informe sea revisado. | If I were you, I'd be working now to be able to finish before the report is reviewed. |
