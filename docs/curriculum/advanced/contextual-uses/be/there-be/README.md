# **There Be** for Spanish **Haber**

| Lesson | Spanish | English |
|---|---|---|
| [Present and Past](01-present-and-past.md) | Hay uno; había dos. | There is one; there were two. |
| [Future and Conditional](02-future-and-conditional.md) | Habrá uno; habría dos. | There will be one; there would be two. |
| [Modal Forms](03-modal-forms.md) | Podría haber un error. | There could be an error. |
| [Going To](04-going-to-be.md) | Va a haber cambios. | There are going to be changes. |
| [Perfect Forms](05-perfect-forms.md) | Ha habido cambios. | There have been changes. |

## Mastery Phrase

| Spanish | English |
|---|---|
| Hubo un error, ha habido varias quejas y va a haber una reunión, pero podría haber una solución. | There was an error, there have been several complaints, and there's going to be a meeting, but there could be a solution. |
