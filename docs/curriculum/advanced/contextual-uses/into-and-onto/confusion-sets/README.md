| Lesson | Central Contrast |
|---|---|
| [**In** vs **Into**](01-in-vs-into.md) | Position vs entry |
| [**On** vs **Onto**](02-on-vs-onto.md) | Position vs movement to a surface |
| [**Into** vs **In To**](03-into-vs-in-to.md) | One preposition vs two separate words |
| [**Onto** vs **On To**](04-onto-vs-on-to.md) | Movement to a surface vs continuing to another step |
| [**Into** vs **Against**](05-into-vs-against.md) | Movement/collision vs forceful contact |
