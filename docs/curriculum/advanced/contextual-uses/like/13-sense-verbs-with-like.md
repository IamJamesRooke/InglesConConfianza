# **Sound, Feel, Taste**, and **Smell Like**

Use a sense verb + **like + person or thing** to identify a resemblance.

| Spanish | English |
|---|---|
| Suena como una alarma, se siente como seda, sabe a limón y huele a café. | It sounds like an alarm, feels like silk, tastes like lemon, and smells like coffee. |

Without **like**, a description follows directly:

- **It sounds strange.**
- **It feels soft.**
- **It tastes sour.**
- **It smells wonderful.**
