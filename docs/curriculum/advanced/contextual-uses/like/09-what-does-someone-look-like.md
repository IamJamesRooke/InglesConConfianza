# **What Does Someone Look Like?**

Use **what does someone look like?** to ask for a description of physical appearance.

| Spanish | English |
|---|---|
| —¿Cómo es físicamente el nuevo gerente? —Es alto, tiene el pelo corto y usa gafas. | “What does the new manager look like?” “He's tall, has short hair, and wears glasses.” |

This question does not ask whether you like the manager.
