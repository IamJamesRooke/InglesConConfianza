# **As...As Possible**

Use **as + description + as possible** for the greatest degree circumstances allow.

| Spanish | English |
|---|---|
| Explícamelo de la manera más clara posible porque tengo que presentarlo mañana. | Explain it to me as clearly as possible because I've gotta present it tomorrow. |

**Gotta** represents informal speech for **have got to**; use **have to** or **must** in formal writing.
