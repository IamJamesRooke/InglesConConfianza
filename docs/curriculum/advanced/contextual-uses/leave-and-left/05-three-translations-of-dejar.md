# Three Translations of **Dejar**

| Pattern | Spanish | English |
|---|---|---|
| **dejar + thing + place** | Déjalo aquí. | Leave it here. |
| **dejar de + action** | Deja de hacer eso. | Stop doing that. |
| **dejar + person + action** | Déjame hacerlo. | Let me do it. |

English does not use **leave** for every meaning of **dejar**. Use **leave** for keeping something in a place, **stop** for ending an action, and **let** for allowing someone to act.
