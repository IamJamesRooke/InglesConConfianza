# Core Uses of **By**

| Lesson | Spanish | English |
|---|---|---|
| [Beside](01-beside.md) | Siéntese junto a la ventana. | Sit by the window. |
| [Passing](02-passing-by.md) | Pasé por su oficina. | I went by your office. |
| [Deadline](03-deadline.md) | Envíelo antes de las doce. | Send it by twelve. |
| [Creator or Agent](04-agent.md) | Fue escrito por Ana. | It was written by Ana. |
| [Transport](05-transport.md) | Llegamos en bus. | We got there by bus. |
| [Method](06-method-by-ing.md) | Aprendió practicando. | She learned by practicing. |
| [Communication](07-communication.md) | Envíelo por correo. | Send it by email. |
| [Measurement](08-rate-and-unit.md) | Se paga por hora. | It's paid by the hour. |
| [Nearby](09-nearby.md) | Hay una farmacia cerca. | There's a pharmacy nearby. |
| [Expressions](10-fixed-expressions.md) | Por cierto, ¿tienes alguna pregunta? | By the way, do you have any questions? |
