# Core Uses of **Through**

| Lesson | Spanish | English |
|---|---|---|
| [Physical Path](01-physical-path.md) | Caminamos por el túnel. | We walked through the tunnel. |
| [Opening or Medium](02-opening-and-medium.md) | Miró por la ventana. | She looked through the window. |
| [Time](03-time-period.md) | Trabajamos toda la noche. | We worked through the night. |
| [Process or Means](04-process-and-means.md) | Lo resolvimos mediante la negociación. | We solved it through negotiation. |
| [Throughout](05-throughout.md) | Llovió durante todo el día. | It rained throughout the day. |
| [Completion](06-through-to-the-end.md) | Lea el informe completo. | Read the report through. |

## Mastery Phrase

| Spanish | English |
|---|---|
| Miramos por la ventana mientras el bus atravesaba el túnel, y hablamos durante todo el viaje. | We looked through the window while the bus drove through the tunnel, and we talked throughout the trip. |
