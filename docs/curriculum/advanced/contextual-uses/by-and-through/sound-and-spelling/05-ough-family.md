# The **-ough** Spelling Family

| Word | Teaching sound | Example |
|---|---|---|
| **though** | rhymes with **go** | Though it was late, we continued. |
| **thought** | vowel like **caught** in many accents | I thought about it. |
| **through** | rhymes with **too** | We went through it. |
| **tough** | rhymes with **stuff** | It was tough. |
| **thorough** | ends like unstressed **oh/uh** depending on accent | We did a thorough check. |

The spelling **ough** does not identify one sound. Learn each whole word with a contrastive sentence.
