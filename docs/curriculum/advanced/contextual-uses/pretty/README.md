# Uses of **Pretty**

| Lesson | Spanish | English |
|---|---|---|
| [**Pretty** Meaning Attractive](01-pretty-meaning-attractive.md) | El jardín se ve muy bonito ahora que las flores rosadas están abiertas. | The garden looks very pretty now that the pink flowers are open. |
| [**Pretty** Meaning Fairly or Quite](02-pretty-meaning-fairly-or-quite.md) | Es bastante importante guardar una copia del contrato porque el original podría perderse. | It's pretty important to keep a copy of the contract because the original could get lost. |
| [Position Changes the Meaning](03-position-changes-the-meaning.md) | Laura es bonita. | Laura is pretty. |
