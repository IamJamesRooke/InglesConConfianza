# **A While** Versus **Awhile**

**A while** is a noun phrase; **awhile** is an adverb meaning for a while.

| Spanish | English |
|---|---|
| Quédate un rato; hace tiempo que no hablamos. | Stay awhile; it's been a while since we talked. |

After **for**, use **a while**: **Stay for a while**, not *stay for awhile*.
