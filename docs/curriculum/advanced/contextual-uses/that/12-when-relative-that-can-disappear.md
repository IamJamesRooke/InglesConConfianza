# When Relative **That** Can Disappear

Omit relative **that** when another person or thing performs the following action.

| With **that** | Without **that** |
|---|---|
| **The book that I need** | **The book I need** |
| **The change that Laura requested** | **The change Laura requested** |

Do not omit **that** when **that** itself performs the action:

- **The book that is on the table**
- not *The book is on the table* when it must remain part of a larger phrase.

Compare:

- **the file (that) Laura sent**: Laura sent the file, so **that** can disappear;
- **the file that contains the figures**: the file contains the figures, so **that** stays.
