# **Like That** and **That Way**

**Like that** and **that way** can mean **así**, **de esa manera** or **de ese modo**.

| Spanish | English |
|---|---|
| No organices los archivos así; si lo haces de esa manera, nadie podrá encontrarlos. | Don't organize the files like that; if you do it that way, nobody will be able to find them. |

Use **it is like that** to describe what something is like. Use **it works that way** to describe how it operates.
