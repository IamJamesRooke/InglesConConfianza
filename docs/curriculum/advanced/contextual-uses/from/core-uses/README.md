# Core Uses of **From**

| Lesson | Spanish | English |
|---|---|---|
| [Origin](01-origin.md) | Soy de Colombia. | I'm from Colombia. |
| [Material and Source](02-material-and-source.md) | El queso se hace con leche. | Cheese is made from milk. |
| [Time](03-time.md) | Trabajo de ocho a cinco. | I work from eight to five. |
| [Distance](04-distance.md) | Vivo a cinco minutos de aquí. | I live five minutes from here. |
| [Change](05-change.md) | La temperatura subió de diez a veinte grados. | The temperature rose from ten to twenty degrees. |
| [Information and Sender](06-information-and-sender.md) | Recibí un mensaje de Ana. | I received a message from Ana. |

## Mastery Phrase

| Spanish | English |
|---|---|
| Soy de Colombia, trabajo de ocho a cinco y vivo a cinco minutos de una oficina construida con materiales reciclados. | I'm from Colombia, work from eight to five, and live five minutes from an office built from recycled materials. |
