# **And So On**

**And so on** continues an obvious list and means **etcétera**, **y así sucesivamente** or **y demás**.

| Spanish | English |
|---|---|
| El formulario pide el nombre, la dirección, el teléfono y demás. | The form asks for your name, address, phone number, and so on. |

Use it only when the listener can reasonably infer the omitted items.
