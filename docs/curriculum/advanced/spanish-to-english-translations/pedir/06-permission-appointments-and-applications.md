# Permission, Appointments, and Applications

| Spanish | English |
|---|---|
| Pedí permiso para salir, pedí una cita con la médica y solicité una visa. | I asked for permission to leave, made an appointment with the doctor, and applied for a visa. |

English uses a conventional verb for each purpose: **ask for permission**, **make/book an appointment**, and **apply for a job, visa**, or program.
