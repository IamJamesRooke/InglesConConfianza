# Translations of Spanish **Llevar** and **Llevarse**

Spanish **llevar** and **llevarse** cover movement away from the speaker, carrying, clothing, elapsed time, duration, relationships, and removal.

| Lesson | Spanish | English |
|---|---|---|
| [**Llevar → Take / Carry**](01-take-or-carry.md) | Llevo el café a Ana. | I'm taking the coffee to Ana. |
| [**Llevar → Wear**](02-wear.md) | Ana lleva una camisa azul. | Ana is wearing a blue shirt. |
| [**Llevar + Time + Doing**](03-have-been-doing.md) | Llevo dos años viviendo aquí. | I've been living here for two years. |
| [**Llevar → Take** Time](04-take-time.md) | El viaje lleva tres horas. | The trip takes three hours. |
| [**Llevarse Bien o Mal → Get Along**](05-get-along.md) | Me llevo bien con mis vecinos. | I get along well with my neighbors. |
| [**Llevarse → Take Away**](06-take-away.md) | Se llevó las llaves por error. | She took the keys away by mistake. |
