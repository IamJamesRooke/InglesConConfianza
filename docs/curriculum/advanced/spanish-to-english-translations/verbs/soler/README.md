# Translations of Spanish **Soler**

Spanish **soler + infinitive** has no direct English verb equivalent. English restructures it through frequency, tendency, or past habit.

| Lesson | Spanish | English |
|---|---|---|
| [Present **Soler → Usually**](01-usually.md) | Suelo caminar al trabajo. | I usually walk to work. |
| [**Soler → Tend To**](02-tend-to.md) | Este problema suele ocurrir en invierno. | This problem tends to occur in winter. |
| [Imperfect **Soler → Used To**](03-used-to.md) | Solíamos vivir cerca del parque. | We used to live near the park. |
| [Past **Soler → Would**](04-would-for-past-habit.md) | De niños, solíamos jugar afuera hasta tarde. | As children, we would play outside until late. |
| [**Soler → Often**](05-often.md) | Suele llegar temprano. | She often arrives early. |
| [**No Soler → Don't Usually**](06-negative-habit.md) | No suelo tomar café por la noche. | I don't usually drink coffee at night. |
| [**¿Sueles...? → Do You Usually...?**](07-questions.md) | ¿Sueles trabajar los sábados? | Do you usually work on Saturdays? |
| [Form and Register of **Soler**](08-form-limits.md) | No es una forma que se suela usar aquí. | It isn't a form that is usually used here. |
