# Translations of Spanish **Faltar**

Spanish **faltar** presents an absent or needed thing as the subject. English often reorganizes the sentence around the person, place, amount, or time affected.

| Lesson | Spanish | English |
|---|---|---|
| [**Faltar → Be Missing**](01-be-missing.md) | Falta una página del informe. | One page is missing from the report. |
| [**Faltar → Lack**](02-lack.md) | Al proyecto le falta claridad. | The project lacks clarity. |
| [**Me Falta → I Need**](03-need.md) | Me falta dinero para el pasaje. | I need more money for the fare. |
| [**Faltar → Be Left / To Go**](04-remain-until.md) | Faltan cinco minutos para las ocho. | There are five minutes left until eight. |
| [**Faltar → Be Absent / Miss**](05-be-absent.md) | Ana faltó a clase ayer. | Ana was absent from class yesterday. / Ana missed class yesterday. |
| [**Faltar A → Fail To / Break**](06-fail-to-do.md) | Faltó a su promesa. | He broke his promise. / He failed to keep his promise. |
