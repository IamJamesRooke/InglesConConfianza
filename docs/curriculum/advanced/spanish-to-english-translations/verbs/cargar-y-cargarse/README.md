# Translations of Spanish **Cargar** and **Cargarse**

Spanish **cargar** and **cargarse** cover carrying, loading, charging, burdening, blaming, taking responsibility, and informal destruction.

| Lesson | Spanish | English |
|---|---|---|
| [**Cargar → Carry**](01-carry.md) | Carga la caja con las dos manos. | Carry the box with both hands. |
| [**Cargar → Load**](02-load.md) | Cargaron el camión antes del amanecer. | They loaded the truck before dawn. |
| [**Cargar → Charge**](03-charge-a-device.md) | Tengo que cargar el teléfono. | I have to charge my phone. |
| [**Cargar / Cobrar → Charge**](04-charge-a-price.md) | Cargaron veinte dólares a mi tarjeta por el envío. | They charged twenty dollars to my card for shipping. |
| [**Cargar Con → Carry / Bear** a Burden](05-burden.md) | Carga con demasiada responsabilidad. | She carries too much responsibility. |
| [**Cargarle Algo A Alguien → Blame / Pin On**](06-blame.md) | Le cargaron toda la culpa a Ana. | They put all the blame on Ana. |
| [**Cargarse Algo Al Hombro → Take On**](07-take-care-of.md) | Se cargó el proyecto al hombro. | He took the project on his shoulders. |
| [Informal **Cargarse → Wreck / Kill**](08-damage-or-kill-informal.md) | Se cargó el computador al instalar el programa. | He wrecked the computer by installing the program. |
