# Translations of Spanish **Resultar**

Spanish **resultar** maps to resulting, turning out, proving to be, being convenient or strange, working for someone, and producing totals.

| Lesson | Spanish | English |
|---|---|---|
| [**Resultar En → Result In**](01-result-in.md) | El error resultó en una demora. | The error resulted in a delay. |
| [**Resultar → Turn Out**](02-turn-out.md) | La reunión resultó mejor de lo esperado. | The meeting turned out better than expected. |
| [**Resultar Ser → Prove To Be**](03-prove-to-be.md) | La solución resultó ser muy costosa. | The solution proved to be very expensive. |
| [**Resultar Conveniente → Be Convenient / Work**](04-be-convenient.md) | Ese horario me resulta conveniente. | That schedule works for me. |
| [**Resultar Extraño → Seem / Strike As Strange**](05-seem-strange.md) | Me resulta extraño que no responda. | It seems strange to me that she isn't answering. |
| [**Resultar → Work / Be Effective**](06-work-for-someone.md) | Este método me resulta útil. | This method works well for me. |
| [**Resultar → Turn Out To Be**](07-turn-out-to-be-someone.md) | El dueño resultó ser un viejo amigo. | The owner turned out to be an old friend. |
| [**Resultar → Come To / Amount To**](08-total-or-come-to.md) | El total resultó ser de cien dólares. | The total came to one hundred dollars. |
