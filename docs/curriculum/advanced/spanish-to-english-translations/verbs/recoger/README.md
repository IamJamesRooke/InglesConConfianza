# Translations of Spanish **Recoger**

Spanish **recoger** maps to picking up, collecting, gathering, tidying, retrieving, harvesting, and taking in.

| Lesson | Spanish | English |
|---|---|---|
| [**Recoger → Pick Up** a Person](01-pick-up-a-person.md) | Recojo a Ana en el aeropuerto. | I'll pick Ana up at the airport. |
| [**Recoger → Pick Up** an Object](02-pick-up-an-object.md) | Recogí el paquete en recepción. | I picked up the package at reception. |
| [**Recoger → Collect**](03-collect.md) | La organización recoge donaciones. | The organization collects donations. |
| [**Recoger → Gather**](04-gather.md) | Recogimos las hojas del jardín. | We gathered the leaves from the garden. |
| [**Recoger → Tidy Up**](05-tidy-up.md) | Recoge tu cuarto antes de salir. | Tidy up your room before leaving. |
| [**Recoger → Retrieve**](06-retrieve.md) | El sistema recoge los datos guardados. | The system retrieves the stored data. |
| [**Recoger → Harvest / Pick**](07-harvest.md) | Recogen café entre octubre y enero. | They harvest coffee between October and January. |
| [**Recoger → Take In / Tie Back**](08-take-in-or-fold.md) | Recogió la ropa y se recogió el cabello. | She took in the laundry and tied back her hair. |
