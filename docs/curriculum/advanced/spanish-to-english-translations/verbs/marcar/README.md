# Translations of Spanish **Marcar**

Spanish **marcar** maps to marking, dialing, scoring, indicating, setting, defining, and making a difference.

| Lesson | Spanish | English |
|---|---|---|
| [**Marcar → Mark**](01-mark.md) | Marca la respuesta correcta. | Mark the correct answer. |
| [**Marcar → Dial**](02-dial.md) | Marca este número y espera. | Dial this number and wait. |
| [**Marcar → Score**](03-score.md) | Marcó dos goles en el partido. | She scored two goals in the match. |
| [**Marcar → Indicate / Show**](04-indicate.md) | El termómetro marca treinta grados. | The thermometer reads thirty degrees. |
| [**Marcar → Set / Schedule**](05-set-a-time-or-date.md) | Marcaron la reunión para el martes. | They scheduled the meeting for Tuesday. |
| [**Marcar → Mark / Shape**](06-define-or-shape.md) | Ese momento marcó su carrera. | That moment shaped her career. |
| [**Marcar La Diferencia → Make a Difference**](07-make-a-difference.md) | Un buen profesor marca la diferencia. | A good teacher makes a difference. |
| [**Marcado → Marked / Pronounced**](08-marked-or-noticeable.md) | Tiene un acento muy marcado. | She has a very pronounced accent. |
