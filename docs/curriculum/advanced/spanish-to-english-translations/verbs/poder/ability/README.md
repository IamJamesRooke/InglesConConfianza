# **Poder** for Ability

| Lesson | Spanish | English |
|---|---|---|
| [Present Ability: **Can**](01-present-can.md) | Puedo conducir. | I can drive. |
| [Infinitive: **Be Able To**](02-infinitive-be-able-to.md) | Quiero poder conducir. | I want to be able to drive. |
| [General Past Ability: **Could**](03-general-past-could.md) | De niña, podía nadar muy bien. | As a child, I could swim very well. |
| [Specific Past Success](04-specific-past-success.md) | Ayer pude abrir la puerta. | I was able to open the door yesterday. |
| [**Manage To**](05-manage-to.md) | Logré terminar a tiempo. | I managed to finish on time. |

## Mastery Phrase

| Spanish | English |
|---|---|
| De niña podía nadar, y ayer logré cruzar el río aunque la corriente estaba fuerte. | As a child, I could swim, and yesterday I managed to cross the river although the current was strong. |
