# Translations of Spanish **Contar** and **Contar Con**

Spanish **contar** can mean enumerate, narrate, include, matter, or rely on someone. The preposition **con** changes the map decisively.

| Lesson | Spanish | English |
|---|---|---|
| [**Contar → Count**](01-count.md) | Cuenta el dinero antes de salir. | Count the money before leaving. |
| [**Contar → Tell**](02-tell.md) | Cuéntame qué pasó. | Tell me what happened. |
| [**Contar → Include / Count**](03-include-or-count.md) | Cuenta el envío dentro del total. | Include shipping in the total. |
| [**Contar Con → Count On / Rely On**](04-count-on-or-rely-on.md) | Puedes contar conmigo. | You can count on me. |
| [**Contar Con → Have / Have Available**](05-have-available.md) | El equipo cuenta con tres diseñadores. | The team has three designers. |
