# Translations of Spanish **Montar**

Spanish **montar** maps to riding, mounting, assembling, setting up, staging, boarding, and establishing activities or businesses.

| Lesson | Spanish | English |
|---|---|---|
| [**Montar → Ride**](01-ride.md) | Monta bicicleta todos los domingos. | She rides a bicycle every Sunday. |
| [**Montar → Mount**](02-mount.md) | Montó el caballo sin ayuda. | He mounted the horse without help. |
| [**Montar → Assemble / Put Together**](03-assemble.md) | Montamos la mesa en una hora. | We assembled the table in an hour. |
| [**Montar → Set Up**](04-set-up.md) | Montaron una oficina temporal. | They set up a temporary office. |
| [**Montar → Stage / Put On**](05-stage-or-put-on.md) | El colegio montó una obra de teatro. | The school put on a play. |
| [**Montarse → Get On / Into**](06-get-on-transport.md) | Nos montamos en el bus a las seis. | We got on the bus at six. |
| [**Montar → Start / Set Up** a Business](07-start-a-business.md) | Montó una empresa de diseño. | She started a design company. |
| [**Montar → Put Together / Fabricate**](08-make-a-scene-or-story.md) | Montó un escándalo por un error pequeño. | He made a scene over a small mistake. |
