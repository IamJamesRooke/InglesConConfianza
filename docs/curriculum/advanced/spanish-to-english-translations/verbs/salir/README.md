# Translations of Spanish **Salir**

Spanish **salir** can describe leaving, social activity, emergence, results, cost, publication, dating, and successful completion.

| Lesson | Spanish | English |
|---|---|---|
| [**Salir → Leave / Go Out**](01-leave-or-go-out.md) | Salí de la oficina y luego salí con amigos. | I left the office and then went out with friends. |
| [**Salir → Come Out**](02-come-out.md) | La mancha no salió, pero el sol sí salió. | The stain didn't come out, but the sun did come out. |
| [**Salir → Turn Out**](03-turn-out.md) | La presentación salió bien. | The presentation turned out well. |
| [**Salir → Cost / Come To**](04-cost.md) | La reparación salió cara. | The repair was expensive. / The repair cost a lot. |
| [**Salir → Appear / Be Released**](05-appear-or-be-published.md) | La noticia salió hoy y el libro sale mañana. | The news appeared today, and the book comes out tomorrow. |
| [**Salir Con → Date / Go Out With**](06-date-someone.md) | Ana sale con Luis desde enero. | Ana has been dating Luis since January. |
| [**Salir → Come Off / Succeed**](07-come-off-or-succeed.md) | El plan salió como esperábamos. | The plan came off as we expected. |
