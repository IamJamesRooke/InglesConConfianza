# Core Translations of **De**

| Lesson | Spanish | English |
|---|---|---|
| [**De → Of**](01-de-to-of.md) | El nombre de la tienda está al final de la calle. | The name of the store is at the end of the street. |
| [**De → From**](02-de-to-from.md) | Vengo de Bogotá y acabo de salir de la oficina. | I come from Bogotá, and I've just left the office. |
| [**De → About**](03-de-to-about.md) | Hablamos del problema y me enteré del cambio. | We talked about the problem, and I heard about the change. |
| [**De → By**](04-de-to-by.md) | Es una novela de Gabriel García Márquez. | It's a novel by Gabriel García Márquez. |
