# Core Translations of **Deber**

| Lesson | Spanish | English |
|---|---|---|
| [**Deber Algo → Owe**](01-deber-algo-meaning-owe.md) | Le debo dinero a Ana. | I owe Ana money. |
| [**Deber Hacer → Must / Have To**](02-must-and-have-to.md) | Debo terminar el informe hoy. | I must finish the report today. |
| [**Debería → Should**](03-should.md) | Deberías descansar. | You should rest. |
| [**Debería → Ought To**](04-ought-to.md) | Deberíamos cumplir nuestra promesa. | We ought to keep our promise. |
| [**Deber → Be Supposed To**](05-be-supposed-to.md) | Ana debe llegar a las diez. | Ana is supposed to arrive at ten. |
| [**Deber → Must** for Probability](06-must-for-probability.md) | Ana debe estar cansada. | Ana must be tired. |
| [**Deberá → Will Have To**](07-will-have-to.md) | Tendrá que presentar el informe mañana. | She'll have to submit the report tomorrow. |

## Mastery Phrase

| Spanish | English |
|---|---|
| Le debo dinero a Ana, tengo que pagarle hoy y debería llamarla porque debe estar preocupada. | I owe Ana money, have to pay her today, and should call her because she must be worried. |
