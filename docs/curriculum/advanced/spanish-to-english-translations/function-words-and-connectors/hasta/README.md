# Translations of Spanish **Hasta**

|---|---|---|

| [as-far-as](03-as-far-as.md) | Caminamos hasta el parque. | We walked as far as the park. |
| [even](04-even.md) | Hasta Ana lo sabía. | Even Ana knew it. |
| [hasta-que](05-hasta-que.md) | Espera hasta que llegue. | Wait until she arrives. |
| [not-until](06-not-until.md) | No salí hasta las ocho. | I didn't leave until eight. |
