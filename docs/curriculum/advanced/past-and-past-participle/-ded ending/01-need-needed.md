# **Need → Needed**

When a regular base ends in written **d** and the sound `/d/`, add **-ed** and pronounce an extra `/ɪd/` syllable:

**need → needed**

| Course source | Base | Past and past participle | Spanish bridge |
|---|---|---|---|
| core verb | need | needed | necesitó / necesitado |
| supporting vocabulary | add | added | añadió / añadido |
| supporting vocabulary | end | ended | terminó / terminado |
| established cognate | recommend | recommended | recomendó / recomendado |
| established Foundations verb | avoid | avoided | evitó / evitado |

- Past: Laura **needed** another example, so the teacher **added** one.
- Past participle: Laura has **needed** another example, so the teacher has **added** one.

The vowel is audible: **nee-ded, ad-ded, en-ded, recommen-ded**.
