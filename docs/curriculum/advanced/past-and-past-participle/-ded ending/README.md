# The **-ded** Ending

When a regular base verb ends in `/d/`, **-ed** adds a new syllable pronounced `/ɪd/`:

**need `/niːd/` → needed `/ˈniː.dɪd/`**

| Spelling family | Model transformation |
|---|---|
| [base ending in written **d**](01-need-needed.md) | **need → needed** |
| [base ending in written **de**](02-decide-decided.md) | **decide → decided** |

## One ending, two grammatical jobs

| Job | Example |
|---|---|
| past | Laura **needed** help yesterday. |
| past participle | Laura has **needed** help before. |

The simple course bridge is:

> If the result ends in written **-ded**, pronounce the **e**.

The ending is `/ɪd/`, not a bare `/d/`, because English needs a vowel between the two `/d/` sounds.
