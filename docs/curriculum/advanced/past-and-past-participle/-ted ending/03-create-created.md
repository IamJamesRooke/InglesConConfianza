# **Create → Created**

When a regular base ends in silent **e** after `/t/`, add only written **-d**. The result still ends in **-ted** and gains the `/ɪd/` syllable:

**create → created**

| Base | Past and past participle | Spanish bridge |
|---|---|---|
| create | created | creó / creado |
| communicate | communicated | comunicó / comunicado |
| invite | invited | invitó / invitado |
| indicate | indicated | indicó / indicado |
| educate | educated | educó / educado |

- Past: Laura **created** the invitation and **communicated** the date.
- Past participle: Laura has **created** the invitation and has **communicated** the date.

Do not add another written **e**: **create + d = created**, not *createed*. Pronounce the result as **crea-ted**.
