# The `/d/` Ending

After a voiced sound other than `/d/`, regular **-ed** is pronounced `/d/`. The written **e** does not create another syllable.

| Final sound family | Model transformation |
|---|---|
| [`/l/`](01-call-called.md) | **call → called** |
| [`/n/` and related nasal sounds](02-clean-cleaned.md) | **clean → cleaned** |
| [`/r/` or a final vowel in non-rhotic accents](03-offer-offered.md) | **offer → offered** |
| [`/dʒ/`](04-damage-damaged.md) | **damage → damaged** |
| [`/v/`](05-love-loved.md) | **love → loved** |
| [`/z/` written **s/se**](06-use-used.md) | **use → used** |
| [vowel sound, often written **w**](07-follow-followed.md) | **follow → followed** |
| [vowel sound, often written **y**](08-enjoy-enjoyed.md) | **enjoy → enjoyed** |
| [`/z/` written **z/ze**](09-amaze-amazed.md) | **amaze → amazed** |
| [`/ð/` written **th**](10-breathe-breathed.md) | **breathe → breathed** |

## One ending, two grammatical jobs

| Job | Example |
|---|---|
| past | Laura **called** yesterday. |
| past participle | Laura has **called** twice. |

Both forms are **called**, pronounced as one syllable: call + `/d/`.

The chart groups useful spelling and sound families for memory. The actual rule listens to the final sound: voiced final sounds keep the voice on for `/d/`.
