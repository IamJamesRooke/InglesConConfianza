# Irregular Verbs by Memory Family

Do not memorize a long alphabetical table as unrelated facts. Learn one model, then attach its rhyming relatives.

Every lesson keeps the three forms together:

| Base | Past | Past participle |
|---|---|---|
| sing | sang | sung |

- **Yesterday, Laura sang.** — past
- **Laura has sung here before.** — participle after **has**
