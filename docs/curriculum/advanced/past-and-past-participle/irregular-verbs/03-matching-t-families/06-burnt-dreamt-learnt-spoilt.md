# **Burnt, Dreamt, Learnt, Spoilt**: Smaller Alternatives

These forms do not rhyme with one another. Each competes with a regular form:

| Base | Standard forms |
|---|---|
| burn | burned / burnt |
| dream | dreamed / dreamt |
| learn | learned / learnt |
| spoil | spoiled / spoilt |

They are collected only as a review doorway to the alternatives lesson, not as a chant.
