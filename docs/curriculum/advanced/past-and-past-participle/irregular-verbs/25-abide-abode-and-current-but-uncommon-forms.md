# **Abide → Abode/Abided** and Current but Uncommon Forms

| Base | Past | Participle | Note |
|---|---|---|---|
| abide | abode / abided | abode / abided | **abide by** normally uses **abided** |
| alight | alit / alighted | alit / alighted | bajar / posarse |
| bereave | bereaved / bereft | bereaved / bereft | **bereft** is frequent as an adjective |
| beseech | besought / beseeched | besought / beseeched | suplicar |
| gild | gilded / gilt | gilded / gilt | **gilt** is frequent as an adjective |
| hew | hewed | hewn / hewed | tallar |
| knit | knit / knitted | knit / knitted | tejer |
| plead | pleaded / pled | pleaded / pled | **pled** is especially American |
| rend | rent | rent | desgarrar; literary |
| thrive | thrived / throve | thrived / thriven | prosperar |
| wed | wed / wedded | wed / wedded | casarse |
| wet | wet / wetted | wet / wetted | mojar |

These belong in the coverage record, but they should not compete with **went, had, made**, or **took** during initial memorization.
