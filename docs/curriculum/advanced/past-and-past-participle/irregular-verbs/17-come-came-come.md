# **Come → Came → Come**: Return to the Base

| Base | Past | Participle | Spanish |
|---|---|---|---|
| become | became | become | convertirse / llegar a ser |
| come | came | come | venir |
| overcome | overcame | overcome | superar |
| run | ran | run | correr |

The participle returns to the base form.

**She came home after she had overcome the problem and had run ten kilometers.**
