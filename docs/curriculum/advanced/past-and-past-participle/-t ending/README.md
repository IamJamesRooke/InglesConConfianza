# The `/t/` Ending

After a voiceless sound other than `/t/`, regular **-ed** is pronounced `/t/`. The written **e** does not create another syllable.

| Final sound or spelling family | Model transformation |
|---|---|
| [`/p/`](01-help-helped.md) | **help → helped** |
| [`/k/`](02-look-looked.md) | **look → looked** |
| [`/ʃ/` written **sh**](03-wash-washed.md) | **wash → washed** |
| [`/tʃ/` written **ch**](04-watch-watched.md) | **watch → watched** |
| [`/f/` written **gh**](05-laugh-laughed.md) | **laugh → laughed** |
| [`/θ/` written **th**](06-unearth-unearthed.md) | **unearth → unearthed** |
| [`/s/` written **s/ss/se**](07-kiss-kissed.md) | **kiss → kissed** |
| [`/s/` written **c/ce**](08-dance-danced.md) | **dance → danced** |
| [`/ks/` written **x**](09-fix-fixed.md) | **fix → fixed** |

## One ending, two grammatical jobs

| Job | Example |
|---|---|
| past | Laura **helped** yesterday. |
| past participle | Laura has **helped** twice. |

Both forms are **helped**, pronounced as one syllable: help + `/t/`.

The chart makes spelling families visible, but the rule listens to the final sound. Voiceless final sounds remain voiceless when `/t/` attaches.
