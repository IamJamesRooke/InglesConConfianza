# **Free → Freedom**

English **-dom** forms nouns describing a state, condition, or domain. The resulting Spanish noun usually has a different ending.

| Base word | **-dom** noun | Spanish |
|---|---|---|
| free | **freedom** | libertad |
| bored | **boredom** | aburrimiento |
| wise | **wisdom** | sabiduría |
| king | **kingdom** | reino |

| Spanish | English |
|---|---|
| **La constitución protege la libertad de expresión.** | The constitution protects **freedom** of expression. |
| **Los niños inventaron un juego para combatir el aburrimiento.** | The children invented a game to combat **boredom**. |
| **El rey gobernó el reino durante treinta años.** | The king ruled the **kingdom** for thirty years. |

## Additional Examples

| Base word | **-dom** noun | Example |
|---|---|---|
