# Transformations

These maps show how a familiar base word can generate a related form with a predictable new function.

| Transformation | Core idea |
|---|---|
| [**In → Inner**](in - inner/README.md) | A position or direction becomes a relative part: **in → inner**, **out → outer**, **up → upper**, **down → lower**. |
| [**To → Towards**](to - towards/README.md) | A base direction becomes movement in that direction: **in → inward**, **up → upward**, **back → backward**. |
| [**North → Northern**](north - northern/README.md) | A cardinal direction becomes a description or movement form: **north → northern → northward**. |
| [**Power → Powerful/Powerless → Powerlessness**](power - powerful - powerless - powerlessness/README.md) | A base thing branches into having/lacking descriptions and quality nouns. |
| [**Weak → Weakness/Weaken → Weakening**](weak - weakness - weaken - weakening/README.md) | A description branches into a quality noun and a change verb. |
| [**Long → Length → Lengthen → Lengthening**](long - length - lengthen - lengthening/README.md) | A changed noun stem supports a change verb. |
| [**White → Whitish**](white - whitish/README.md) | Five uses of **-ish** across colors, approximation, degree, resemblance, and established identity words. |
| [**Also, Alone, Already**, and **Always**](also - alone - already - always/README.md) | Common **al-** spelling family whose whole meanings must be learned. |
| [**Become, Because, Before**, and **Beside**](become - because - before - beside/README.md) | Common **be-** words and their distinct sentence patterns. |
| [**Forearm, Foresee, Forward**, and **Foreword**](forearm - foresee - forward - foreword/README.md) | The reusable front/before picture of **fore-** and related spelling traps. |
| [**Accept → Acceptable**](accept - acceptable/README.md) | **-able/-ible** descriptions of possibility or quality. |
| [**Arrive → Arrival**](arrive - arrival/README.md) | action or result nouns with **-al**. |
| [**Care → Careful/Careless**](care - careful - careless/README.md) | contrasting **-ful/-less** descriptions. |
| [**Cloud → Cloudy**](cloud - cloudy/README.md) | descriptions with **-y**. |
| [**Develop → Development**](develop - development/README.md) | action, process, state, or result nouns with **-ment**. |
| [**Educate → Education**](educate - education/README.md) | related nouns with **-tion/-sion**. |
| [**Free → Freedom**](free - freedom/README.md) | states and domains with **-dom**. |
| [**Friend → Friendship**](friend - friendship/README.md) | relationships, roles, and states with **-ship**. |
| [**Happy → Happiness**](happy - happiness/README.md) | quality or state nouns with **-ness**. |
| [**Happy → Unhappy**](happy - unhappy/README.md) | meaning-changing prefixes such as **un-, re-, dis-**, and **mis-**. |
| [**Meet → Meeting**](meet - meeting/README.md) | activities, processes, and events named with **-ing**. |
| [**Neighbor → Neighborhood**](neighbor - neighborhood/README.md) | stages, relationships, and communities with **-hood**. |
| [**Possible → Possibility**](possible - possibility/README.md) | quality or state nouns with **-ity**. |
| [**Quick → Quickly**](quick - quickly/README.md) | manner forms with **-ly**. |
| [**Organize → Organizer**](organize - organizer/README.md) | people and things named with **-er/-or**. |

The visible transformation is a learning bridge, not a rule that can be applied to every English word.
