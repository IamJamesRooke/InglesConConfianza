# Noun + **-less**

Add **-less** to certain nouns to build a description meaning “without or lacking the base thing or quality.”

| Base | Description | Spanish |
|---|---|---|
| **power** | **powerless** | impotente / sin poder |
| **color** | **colorless** | incoloro / sin color |
| **use** | **useless** | inútil |
| **pain** | **painless** | indoloro / sin dolor |
| **meaning** | **meaningless** | sin sentido |
| **care** | **careless** | descuidado |
| **hope** | **hopeless** | sin esperanza |

| Spanish | English |
|---|---|
| El líquido incoloro es inofensivo y la prueba es indolora. | The colorless liquid is harmless, and the test is painless. |

The base meaning is a strong clue, but not every noun accepts **-less**.
