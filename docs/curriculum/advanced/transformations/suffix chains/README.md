# Suffix Chains

A suffix can transform a familiar word into a new kind of word. The new form can sometimes accept another suffix, creating a visible family such as **power → powerless → powerlessness**.

## Core Transformations

| Transformation | Main idea | Example |
|---|---|---|
| [noun + **-ful**](01-noun-plus-ful.md) | having or producing the base quality | **power → powerful** |
| [noun + **-less**](02-noun-plus-less.md) | lacking the base thing or quality | **power → powerless** |
| [**-ful** vs **-less**](03-ful-vs-less.md) | contrasting branches from one base | **hopeful / hopeless** |
| [description + **-ness**](04-adjective-plus-ness.md) | the quality or state | **weak → weakness** |
| [Spelling Changes](05-spelling-changes.md) | adjust the base before the suffix | **happy → happiness** |
| [noun → adjective → noun](06-noun-adjective-noun-chains.md) | chain transformations across forms | **use → useful → usefulness** |
| [description + **-en**](10-adjective-plus-en.md) | become or make more like the description | **weak → weaken** |

## Meaning Limits

Suffixes give a strong clue, but the result must be a real English word and its meaning may become specialized. See [When the Pattern Is Not Mechanical](13-pattern-limits.md).

| Focused contrast | Core distinction |
|---|---|
| [**Meaningless** vs **Insignificant**](confusion-sets/01-meaningless-vs-insignificant.md) | without meaning/purpose vs not important or too small to matter |
| [**Careless** vs **Reckless**](confusion-sets/02-careless-vs-reckless.md) | insufficient care vs conscious disregard of serious danger |

## Family Picture

```text
                 powerful
                /
power ─────────
                \
                 powerless ── powerlessness
```

The diagram is a family tree, not one uninterrupted spelling operation: **powerful** and **powerless** both come from **power**.

| Spanish | English |
|---|---|
