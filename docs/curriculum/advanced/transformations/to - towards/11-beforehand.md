# **Beforehand**

| Spanish | English |
|---|---|
| Prepárese de antemano para que podamos comenzar a tiempo. | Prepare beforehand so we can start on time. |

**Beforehand** means **de antemano** or **con anticipación**.

English uses the fixed form **beforehand**, not *beforeward* or *beforewards*. It belongs in this source family as a useful contrast with **afterward**, not as an example of the productive **-ward** pattern.
