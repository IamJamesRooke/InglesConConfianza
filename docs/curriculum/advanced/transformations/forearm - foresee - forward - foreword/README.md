# **Forearm, Foresee, Forward**, and **Foreword**

The reusable picture of **fore-** is before, earlier, or at the front. It remains visible in many established words, but related-looking words still require care.

| Lesson | Core idea | Example |
|---|---|---|
| [The **Fore-** Picture](01-the-fore-picture.md) | before or at the front | **forearm, foresee** |
| [**Forearm** and **Forehead**](02-forearm-and-forehead.md) | front body parts | **forearm, forehead** |
| [**Forecast** and **Foresee**](03-forecast-and-foresee.md) | know or estimate beforehand | **forecast rain; foresee trouble** |
| [**Foretell** and **Forewarn**](04-foretell-and-forewarn.md) | tell or warn beforehand | **forewarn the team** |
| [**Forward** vs **Foreword**](05-forward-vs-foreword.md) | direction vs introductory text | **move forward; read the foreword** |
| [**Before** and **Beforehand**](06-before-and-beforehand.md) | earlier time vs in advance | **before the meeting; prepare beforehand** |
| [**Foremost, Foreground**, and **Forefather**](07-other-fore-words.md) | front, most important, earlier ancestor | established words |
| [**Therefore**](08-therefore.md) | result connector, not a reusable **fore-** transformation | **It rained; therefore, we stayed.** |
