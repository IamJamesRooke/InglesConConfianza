# **Weak → Weakness / Weaken**

| Form | Spanish | English |
|---|---|---|
| **weak** | El soporte está débil. | The support is weak. |
| **weakness** | Encontramos una debilidad. | We found a weakness. |
| **weaken** | La humedad puede debilitarlo. | Moisture can weaken it. |
| **weakening** | El debilitamiento es gradual. | The weakening is gradual. |
| **weakened** | Reemplazamos el soporte debilitado. | We replaced the weakened support. |

**Weakener** is grammatically possible for something that weakens, but it is uncommon outside specialized contexts. Ordinary English usually names the specific cause: **Moisture weakened the support**.
