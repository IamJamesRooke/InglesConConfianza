# **Weak → Weakness/Weaken → Weakening**

A description can branch into a noun naming the quality with **-ness** and a verb naming a change with **-en**.

The **weak** family is the concrete model for this transformation pattern.

```text
          weakness
         /
weak ───
         \
          weaken ── weakening / weakened
```

## Mastery Phrase

| Spanish | English |
|---|---|
| La debilidad puede debilitar la tela blanca, así que el blanqueamiento debe ser suave. | Weakness can weaken the white fabric, so the whitening must be gentle. |

## Pattern Limit

Not every adjective accepts **-ness** or **-en**, and understandable forms may still be uncommon. Learn established families such as **weak/weakness/weaken** rather than generating forms mechanically.
