# **Born → Birth** and **Dead → Death**

These families connect states with the beginning and end of life:

| Related forms | Spanish | English |
|---|---|---|
| be born / birth | Laura nació en Bogotá. | Laura was born in Bogotá. |
| birth | Celebramos el nacimiento del bebé. | We celebrated the baby's birth. |
| dead / death | El árbol está muerto. | The tree is dead. |
| death | La muerte del árbol fue causada por una enfermedad. | The tree's death was caused by disease. |

English uses **be born**, not *born* as an ordinary active verb:

- **Laura was born in Bogotá.**
- Not: *Laura born in Bogotá.*

Learn **born/birth** and **dead/death** as related families; neither transformation follows a reusable spelling rule.
