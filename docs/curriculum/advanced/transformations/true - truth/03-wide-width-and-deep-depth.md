# **Wide → Width** and **Deep → Depth**

Use these related nouns to name measurements:

| Base description | Measurement noun | Spanish | English |
|---|---|---|---|
| wide | width | Medimos la anchura de la puerta. | We measured the door's width. |
| deep | depth | Nadie conocía la profundidad del lago. | Nobody knew the lake's depth. |

The spelling changes:

- **wide → width**
- **deep → depth**

Compare the sentence jobs:

- **How wide is the door?**
- **What is the door's width?**
