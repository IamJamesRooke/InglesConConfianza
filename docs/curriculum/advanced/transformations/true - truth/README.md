# **True → Truth**

Several common English nouns end in **-th** or a related **t/th** sound. The base word often changes its vowel or spelling, so these are families to learn—not a suffix that can be added freely.

| Family | Transformation |
|---|---|
| [**True → Truth**](01-true-truth.md) | a description becomes the noun for what is true |
| [**Long/Strong → Length/Strength**](02-long-length-and-strong-strength.md) | the vowel and final consonants change |
| [**Wide/Deep → Width/Depth**](03-wide-width-and-deep-depth.md) | a dimension becomes its measurement noun |
| [**Warm → Warmth**](04-warm-warmth.md) | a temperature or emotional quality becomes a noun |
| [**Grow → Growth**](05-grow-growth.md) | an action becomes its process or result |
| [**Young → Youth**](06-young-youth.md) | a description becomes a stage of life |
| [**Born/Dead → Birth/Death**](07-born-birth-and-dead-death.md) | states connect to the beginning and end of life |

## Master contrast

| Spanish | English |
|---|---|
| La verdad es que el crecimiento depende de la fortaleza, no solamente de la juventud. | The truth is that growth depends on strength, not only on youth. |

The visible **-th** connection is a memory bridge. Do not invent forms such as *trueth*, *strongth*, or *youngth*.

This word-family pattern is separate from the ordinal ending in **fourth, tenth**, and **hundredth**.
