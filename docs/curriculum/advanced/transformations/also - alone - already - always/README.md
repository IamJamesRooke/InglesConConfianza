# **Also, Alone, Already**, and **Always**

These common words begin with **al-**, but modern learners should not treat **al-** as one productive prefix with one meaning. Learn the words through their complete meanings.

| Lesson | Spanish | English |
|---|---|---|
| [**Also**](01-also.md) | Ana también viene. | Ana is also coming. |
| [**Alone**](02-alone.md) | Vive solo, pero no se siente solo. | He lives alone, but he doesn't feel lonely. |
| [**Already**](03-already.md) | Ya terminé. | I've already finished. |
| [**Always**](04-always.md) | Siempre llega temprano. | She always arrives early. |
| [**Allow**](05-allow.md) | No permiten fumar aquí. | They don't allow smoking here. |
| [**Although**](06-although.md) | Aunque estaba cansada, terminó. | Although she was tired, she finished. |
| [**All Right** and **Alright**](07-all-right-and-alright.md) | Todo está bien. | Everything's all right. |
| [**Along**](08-along.md) | Caminamos a lo largo del río. | We walked along the river. |
| [**Almost**](09-almost.md) | Casi terminé. | I've almost finished. |

## Mastery Phrase

| Spanish | English |
|---|---|
| Aunque casi siempre trabaja solo, Ana también ya le permitió acompañarla. | Although he almost always works alone, Ana has also already allowed him to join her. |
