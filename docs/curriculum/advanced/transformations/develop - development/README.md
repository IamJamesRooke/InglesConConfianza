# **Develop → Development**

Add **-ment** to many verbs to form a noun describing an action, process, state, or result.

| Verb | **-ment** noun | Spanish |
|---|---|---|
| develop | **development** | desarrollo |
| improve | **improvement** | mejora |
| achieve | **achievement** | logro |
| agree | **agreement** | acuerdo |
| govern | **government** | gobierno |

| Spanish | English |
|---|---|
| **El desarrollo del proyecto tomó seis meses.** | The **development** of the project took six months. |
| **Notamos una mejora considerable en su pronunciación.** | We noticed a considerable **improvement** in her pronunciation. |
| **Las dos empresas firmaron un acuerdo.** | The two companies signed an **agreement**. |
