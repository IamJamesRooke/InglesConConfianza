# **Power → Powerful/Powerless → Powerlessness**

A base noun can branch into contrasting descriptions with **-ful** and **-less**. A resulting description can then take **-ness** to name its quality or state.

The **power** family is the concrete model for this transformation pattern.

```text
                 powerful
                /
power ─────────
                \
                 powerless ── powerlessness
```

## Mastery Phrase

| Spanish | English |
|---|---|
| La herramienta poderosa nos dejó impotentes cuando su inutilidad se hizo evidente. | The powerful tool left us powerless when its uselessness became clear. |

## Pattern Limit

The resulting form must be an established word, and its meaning may become specialized. For example, **priceless** usually means extremely valuable, not merely “without a price.”
