# **-ful** vs **-less**

**-ful** and **-less** often create contrasting descriptions from the same base.

| Spanish | English |
|---|---|
| Teníamos esperanza al principio, pero después de la noticia la situación parecía desesperanzadora. | We were hopeful at first, but after the news the situation seemed hopeless. |
| Esta guía es útil, pero el mapa viejo es inútil. | This guide is useful, but the old map is useless. |
| Tenga cuidado: un error por descuido podría borrar el archivo. | Be careful: one careless mistake could delete the file. |

Think of the family as two branches:

```text
       useful
      /
use
      \
       useless
```

For the introductory pattern, see the Foundations lesson [English **-ful** and **-less**](../../../foundations/word-building/care - careful - careless (-ful and -less).md).
