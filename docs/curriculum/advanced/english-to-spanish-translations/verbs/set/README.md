# Spanish Translations of English **Set**

English **set** has many established combinations involving placement, arrangement, rules, schedules, stories, firmness, and devices.

| Lesson | English | Spanish |
|---|---|---|
| [**Set → Poner / Colocar**](01-put-or-place.md) | Set the box on the floor. | Pon la caja en el piso. |
| [**Set the Table → Poner La Mesa**](02-set-the-table.md) | Please set the table for four. | Por favor, pon la mesa para cuatro personas. |
| [**Set → Fijar / Establecer**](03-fix-or-establish.md) | Let's set a date and set clear rules. | Fijemos una fecha y establezcamos reglas claras. |
| [**Set → Programar / Poner**](04-program-a-device.md) | Set the alarm for six. | Programa la alarma para las seis. |
| [**Be Set In → Estar Ambientado En**](05-story-setting.md) | The story is set in Bogotá. | La historia está ambientada en Bogotá. |
| [**Set → Cuajar / Fijarse**](06-become-firm.md) | Let the gelatin set before serving it. | Deja que la gelatina cuaje antes de servirla. |
| [**Set Up → Instalar / Organizar**](07-set-up.md) | They set up the equipment and set up a meeting. | Instalaron el equipo y organizaron una reunión. |
| [Other Connections with **Set**](08-other-fixed-connections.md) | She set a goal and set the plan in motion. | Se fijó una meta y puso el plan en marcha. |
