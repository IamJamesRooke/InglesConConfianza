# Spanish Translations of English **Point**

English **point** functions as a verb and noun for direction, purpose, argument, score, stage, detail, and explicit indication.

| Lesson | English | Spanish |
|---|---|---|
| [**Point → Señalar / Apuntar**](01-point-at.md) | Point at the correct picture. | Señala la imagen correcta. |
| [**The Point → El Objetivo / Sentido**](02-purpose.md) | What's the point of waiting? | ¿Qué sentido tiene esperar? |
| [**Point → Punto / Argumento**](03-argument.md) | She made a good point. | Ella planteó un buen argumento. |
| [**Point → Punto** in a Score](04-score.md) | Our team won by two points. | Nuestro equipo ganó por dos puntos. |
| [**At This Point → A Estas Alturas / En Este Momento**](05-moment-or-stage.md) | At this point, we should stop. | A estas alturas, deberíamos parar. |
| [**Point Out → Señalar / Destacar**](06-point-out.md) | She pointed out the error. | Ella señaló el error. |
| [**Point To → Indicar / Apuntar A**](07-point-to.md) | The evidence points to a different cause. | La evidencia apunta a una causa diferente. |
| [**Point of View → Punto de Vista**](08-point-of-view.md) | I understand your point of view. | Entiendo tu punto de vista. |
