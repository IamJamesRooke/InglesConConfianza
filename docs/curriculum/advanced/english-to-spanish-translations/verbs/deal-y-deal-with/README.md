# Spanish Translations of English **Deal** and **Deal With**

English **deal** covers distributing cards, agreements, prices, quantities, business, and handling people or situations.

| Lesson | English | Spanish |
|---|---|---|
| [**Deal → Repartir** Cards](01-deal-cards.md) | Deal five cards to each player. | Reparte cinco cartas a cada jugador. |
| [**Deal → Acuerdo / Trato**](02-agreement.md) | We made a deal yesterday. | Hicimos un acuerdo ayer. |
| [**A Good Deal → Una Buena Oferta / Un Buen Negocio**](03-good-deal.md) | That laptop was a good deal. | Ese portátil estaba a muy buen precio. |
| [**A Great Deal → Mucho / Gran Cantidad**](04-quantity.md) | The repair requires a great deal of time. | La reparación requiere mucho tiempo. |
| [**Deal With → Manejar / Resolver**](05-deal-with-a-problem.md) | We need to deal with this problem today. | Tenemos que resolver este problema hoy. |
| [**Deal With → Tratar Con**](06-deal-with-a-person.md) | I deal with customers every day. | Trato con clientes todos los días. |
| [**Deal In → Comerciar Con / Dedicarse A**](07-business-dealings.md) | The company deals in medical equipment. | La empresa comercializa equipos médicos. |
| [**No Big Deal → No Es Gran Cosa**](08-no-big-deal.md) | It's no big deal; we can fix it. | No es gran cosa; podemos arreglarlo. |
