# Spanish Translations of English **Miss**

English **miss** maps to affection, failed transport or opportunities, failed aim, absence, omission, and failure to understand.

| Lesson | English | Spanish |
|---|---|---|
| [**Miss → Extrañar**](01-miss-someone.md) | I miss my family. | Extraño a mi familia. |
| [**Miss → Perder** Transport](02-miss-transport.md) | We missed the last bus. | Perdimos el último bus. |
| [**Miss → Perder / Dejar Pasar**](03-miss-an-opportunity.md) | Don't miss this opportunity. | No pierdas esta oportunidad. |
| [**Miss → Fallar / No Acertar**](04-miss-a-target.md) | He shot but missed the target. | Disparó, pero no acertó en el blanco. |
| [**Miss → Faltar A / Perderse**](05-miss-an-event.md) | She missed class yesterday. | Faltó a clase ayer. |
| [**Miss → No Notar / Pasar Por Alto**](06-fail-to-notice.md) | I missed the error in the report. | No noté el error en el informe. |
| [**Miss the Point → No Entender**](07-miss-the-point.md) | You missed the point of my question. | No entendiste el punto de mi pregunta. |
| [**Miss → Evitar Por Poco**](08-narrowly-avoid.md) | The branch missed the car by inches. | La rama no golpeó el carro por muy poco. |
