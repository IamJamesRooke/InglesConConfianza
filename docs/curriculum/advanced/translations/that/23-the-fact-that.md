# **The Fact That**

Use **the fact that** when the reality of an idea is itself important.

| Spanish | English |
|---|---|
| El hecho de que Laura hablara con el cliente evitó otro retraso. | The fact that Laura spoke to the client prevented another delay. |

Do not add **the fact that** mechanically to every Spanish **el hecho de que** if a shorter sentence communicates the same idea clearly.
