# Relative **That** Versus **Which**

Use **that** or **which** for information that identifies which thing you mean.

| Spanish | English |
|---|---|
| El archivo que contiene las cifras definitivas está en esta carpeta. | The file that contains the final figures is in this folder. |

For extra, non-identifying information after a comma, use **which**, not **that**.

| Spanish | English |
|---|---|
| El archivo final, que enviamos ayer, contiene las cifras corregidas. | The final file, which we sent yesterday, contains the corrected figures. |

The comma signals that **we sent yesterday** adds extra information; it does not identify the already specific final file.
