# **That** Versus **It**

Use **that** to point, identify, contrast, or react to a newly mentioned idea. Use **it** to continue referring neutrally to something already established.

| Spanish | English |
|---|---|
| —Compré una bicicleta nueva. —¡Eso es genial! ¿Cuándo la vas a usar? | “I bought a new bicycle.” “That's great! When are you going to use it?” |

**That** reacts to the news; **it** then refers to the bicycle.
