# **Would Rather + Different Subject + Negative**

For a negative preference about another person's action, put the negative inside the following clause.

| Spanish | English |
|---|---|
| Preferiría que ustedes no enviaran el documento todavía porque contiene cifras sin verificar. | I would rather you did not send the document yet because it contains unverified figures. |

Use **I would rather you did not send**, not *I would not rather you sent*.
