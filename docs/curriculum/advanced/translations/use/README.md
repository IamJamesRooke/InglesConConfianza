# Uses of **Use**

| Lesson | Spanish | English |
|---|---|---|
| [**Use** a Thing](01-use-a-thing.md) | Uso esta aplicación para organizar mis tareas. | I use this app to organize my tasks. |
| [**Use Something to Do Something**](02-use-something-to-do.md) | Uso el teléfono para escanear los recibos. | I use my phone to scan receipts. |
| [**Use Something for Doing Something**](03-use-something-for-doing.md) | Uso esta carpeta para guardar los contratos. | I use this folder for storing contracts. |
| [**Used to Do**](04-used-to-do.md) | Antes trabajaba de noche, pero ya no. | I used to work nights, but I don't anymore. |
| [**Usually Do**](05-usually-do.md) | Suelo trabajar desde casa los viernes. | I usually work from home on Fridays. |
| [**Be Used to Doing**](06-be-used-to.md) | Estoy acostumbrada a trabajar con plazos cortos. | I'm used to working with short deadlines. |
| [**Get Used to Doing**](07-get-used-to.md) | Me estoy acostumbrando a levantarme temprano. | I'm getting used to getting up early. |
| [**Used To, Be Used To**, and **Get Used To**](08-used-to-be-used-to-and-get-used-to.md) | Antes conducía, estoy acostumbrada al tráfico y me estoy acostumbrando a ir en bus. | I used to drive, I'm used to traffic, and I'm getting used to taking the bus. |
| [**Be Used For**](09-be-used-for.md) | Esta sala se usa para realizar entrevistas. | This room is used for conducting interviews. |
| [The Noun **Use**](10-the-use-of.md) | El uso de teléfonos está prohibido durante el examen. | The use of phones is prohibited during the exam. |
| [**Make Use Of**](11-make-use-of.md) | Aprovechemos el tiempo que nos queda. | Let's make use of the time we've got left. |
| [**It's No Use** and **What's the Use?**](12-no-use-and-whats-the-use.md) | No sirve de nada discutir; ¿para qué seguir? | It's no use arguing; what's the use of continuing? |
| [**Useful** and **Useless**](13-useful-and-useless.md) | Esta herramienta es útil, pero sin batería es inútil. | This tool's useful, but it's useless without a battery. |
| [**Usefulness** and **Uselessness**](14-usefulness-and-uselessness.md) | Evaluamos la utilidad del sistema y la inutilidad de la función antigua. | We evaluated the system's usefulness and the old feature's uselessness. |
| [Pronunciation: **Use, Used**, and **Used To**](15-pronunciation-use-and-used.md) | Antes usaba una herramienta útil, pero ya no la uso. | I used to use a useful tool, but I don't use it anymore. |

## Mastery Phrases

| Spanish | English |
|---|---|
| Antes usaba esta aplicación para trabajar, ahora estoy acostumbrada a usarla y me acostumbré a trabajar más rápido. | I used to use this app for work, now I'm used to using it, and I got used to working faster. |
| Uso esta herramienta para escanear documentos, se usa para guardar copias y aprovecho todas sus funciones útiles. | I use this tool to scan documents, it's used for storing copies, and I make use of all its useful features. |
| Antes usaba una herramienta útil, pero no sirve de nada usarla ahora porque sin batería es inútil. | I used to use a useful tool, but it's no use using it now because it's useless without a battery. |
