# **All, Every**, and **Each**

These three forms can cover the same group from different viewpoints.

| Spanish | English |
|---|---|
| Todos los libros tienen portada, cada libro tiene un título y cada uno tiene un número distinto. | All the books have covers, every book has a title, and each one has a different number. |

Keep the visible bridge: **all the books / every book / each one**.
