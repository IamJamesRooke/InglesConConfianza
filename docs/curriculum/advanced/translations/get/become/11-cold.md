# **Be Cold** and **Get Cold**

For a person's sensation, **be cold** means tener frío and **get cold** means empezar a tener frío.

| Spanish | English |
|---|---|
| No tenía frío, pero me dio frío y ahora tengo mucho frío. | I wasn't cold, but I got cold, and now I'm really cold. |

For an object, the same English forms describe temperature: **The coffee got cold, so now it's cold.**
