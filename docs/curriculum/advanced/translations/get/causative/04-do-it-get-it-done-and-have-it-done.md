# **Do It, Get It Done**, and **Have It Done**

Spanish may use **hazlo** for all three ideas, but English changes the focus.

| Spanish | English |
|---|---|
| ¡Hazlo tú, asegúrate de que quede listo o encárgale el trabajo a alguien, pero tiene que estar listo hoy! | Do it, get it done, or have it done, but it's gotta be ready today! |

- **Do it!** — perform the action yourself.
- **Get it done!** — make sure it gets completed; you may do it or involve someone else.
- **Have it done!** — arrange or instruct someone else to do it.

The difference isn't always visible in **hazlo**, so the situation determines which English form fits.
