# **Make Sure I Do It** Versus **Make Sure It Gets Done**

Both promises guarantee completion, but only one identifies the person who will perform the action.

| Spanish | English |
|---|---|
| Me aseguraré de hacerlo yo; si no puedo, me aseguraré de que quede listo de todos modos. | I'll make sure I do it; if I can't, I'll make sure it gets done anyway. |

- **I'll make sure I do it.** — I personally commit to doing it.
- **I'll make sure it gets done.** — I commit to the result; I or someone else may do it.

The **get** passive hides the actor and creates a useful ladder:

- **Somebody will do it.** — the actor is somebody.
- **It will get done.** — the task becomes the focus; the actor disappears.
- **I'll make sure it gets done.** — I take responsibility for ensuring that somebody, possibly me, does it.
- **I'll get it done.** — I cause or ensure the same completed result.

So **It will get done** can be taught as **Somebody will do it** with the person removed. It doesn't, by itself, say who will make sure.
