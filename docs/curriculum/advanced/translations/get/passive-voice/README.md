# Passive Voice with **Get**

Use the **get** passive to focus conversationally on an event or change affecting the subject. Use **be** for a more neutral passive statement.

| Lesson | Spanish | English |
|---|---|---|
| [**Was Sold** Versus **Got Sold**](01-was-sold-versus-got-sold.md) | La casa estuvo en venta durante meses; finalmente se vendió ayer. | The house was for sale for months; it finally got sold yesterday. |
| [Common **Get** Passives](02-common-get-passives-and-their-limit.md) | Lo contrataron, lo ascendieron y luego lo despidieron porque lo descubrieron mintiendo. | He got hired, got promoted, and then got fired because he got caught lying. |

## Mastery Phrases

| Spanish | English |
|---|---|
| Ellos lo vendieron, consiguieron que lo vendieran, fue vendido y finalmente se vendió. | They sold it, they got it sold, it was sold, and it finally got sold. |
| Yo lo arreglé, conseguí que lo arreglaran y finalmente se arregló. | I fixed it, I got it fixed, and it finally got fixed. |

The word order controls the meaning: **I got it fixed** is causative; **it got fixed** is passive.

The actor can disappear completely: **Somebody will do it → It will get done**. Add responsibility separately: **I'll make sure it gets done**.
