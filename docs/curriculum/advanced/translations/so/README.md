# Uses of **So**

| Lesson | Spanish | English |
|---|---|---|
| [**So** Meaning **Tan**](01-so-meaning-tan.md) | La película fue tan divertida que la vimos dos veces. | The movie was so funny that we watched it twice. |
| [**So Much** and **So Many**](02-so-much-and-so-many.md) | Tengo tanto trabajo y tantos correos pendientes que no podré salir temprano. | I've got so much work and so many unanswered emails that I won't be able to leave early. |
| [**So** Meaning **Así Que**](03-so-meaning-as-que.md) | Había demasiado tráfico, así que llegamos veinte minutos tarde. | There was too much traffic, so we arrived twenty minutes late. |
| [Sentence-Opening **So**](04-sentence-opening-so.md) | Entonces, ya revisamos los costos. ¿Qué vamos a hacer ahora? | So, we've reviewed the costs. What are we going to do now? |
| [Purpose: **So That**](05-purpose-so-that.md) | Hablo despacio para que todos puedan entenderme. | I speak slowly so that everyone can understand me. |
| [Agreement: **So Am I, So Do I, So Can I**](06-agreement-so-am-i-so-do-i-so-can-i.md) | Entonces, coser es tan fácil que tantas personas cosen tanto, y yo también lo creo. | So, sewing is so easy that so many people sew so much, and I think so too. |
| [**I Think So**](07-i-think-so.md) | —¿Va a aprobar Laura el examen? —Creo que sí; estudió toda la semana. | “Will Laura pass the exam?” “I think so; she studied all week.” |
| [**I Don't Think So**](08-i-don-t-think-so.md) | —¿Está abierto el banco hoy? —No lo creo; hoy es festivo. | “Is the bank open today?” “I don't think so; today's a holiday.” |
| [**If So**](09-if-so.md) | ¿El cliente ya aprobó el diseño? Si es así, podemos publicarlo hoy. | Has the client approved the design? If so, we can publish it today. |
| [**So?** and **So What?**](10-so-and-so-what.md) | —El competidor tiene una oficina más grande. —¿Y qué? La nuestra atiende a más clientes. | “The competitor has a larger office.” “So what? Ours serves more clients.” |
| [**So Far**](11-so-far.md) | Hasta ahora hemos migrado todas las lecciones previstas para esta semana. | So far, we've migrated every lesson planned for this week. |
| [**Or So** Meaning Approximately](12-or-so-meaning-approximately.md) | La reparación tardará unas dos semanas. | The repair will take two weeks or so. |
| [**And So On**](13-and-so-on.md) | El formulario pide el nombre, la dirección, el teléfono y demás. | The form asks for your name, address, phone number, and so on. |
| [**So-Called**](14-so-called.md) | El supuesto experto no pudo responder ninguna pregunta básica. | The so-called expert couldn't answer a single basic question. |
| [**So-So**](15-so-so.md) | —¿Cómo estuvo la comida? —Regular; el plato principal estaba frío. | “How was the food?” “So-so; the main course was cold.” |
| [Homophones: **So, Sew** and **Sow**](16-homophones-so-sew-and-sow.md) | Coso tantas bolsas y siembro tantas semillas que termino muy cansada. | I sew so many bags and sow so many seeds that I end up so tired. |

## Mastery Phrases

| Spanish | English |
|---|---|
| Entonces, coser es tan fácil que tantas personas cosen tanto, y yo también lo creo. | So, sewing is so easy that so many people sew so much, and I think so too. |
| Laura tiene tanto trabajo, así que se quedará unas dos horas más; si es así, yo también me quedaré para que no trabaje sola. | Laura's got so much work, so she'll stay for two hours or so; if so, I'll stay too so that she won't work alone. |
| —El supuesto experto dice que el plan está regular. —Yo también lo creo. —Yo también, pero ¿y qué? Hasta ahora hemos arreglado el presupuesto, el cronograma y demás. | “The so-called expert says the plan is so-so.” “I think so too.” “So do I, but so what? So far, we've fixed the budget, the schedule, and so on.” |
