# Uses of **Like**

| Lesson | Spanish | English |
|---|---|---|
| [**Like** Meaning **Gustar**](01-like-meaning-gustar.md) | Me gusta este café porque tiene un sabor suave. | I like this coffee because it has a mild flavor. |
| [**Like Doing** and **Like To Do**](02-like-doing-and-like-to-do.md) | Me gusta caminar porque disfruto estar al aire libre. | I like walking because I enjoy being outdoors. |
| [**Would Like**](03-would-like.md) | Quisiera reservar una mesa para dos esta noche. | I'd like to reserve a table for two tonight. |
| [**Would Like Someone To**](04-would-like-someone-to.md) | Me gustaría que Laura revisara el contrato antes de que lo firmemos. | I'd like Laura to review the contract before we sign it. |
| [**Like** Meaning Similar To](05-like-meaning-similar-to.md) | Este barrio es como un pueblo pequeño porque todos se conocen. | This neighborhood is like a small town because everyone knows each other. |
| [**This Is Like That**](06-this-is-like-that.md) | Esta situación es como la del año pasado, pero esta vez tenemos más tiempo. | This situation is like the one from last year, but this time we have more time. |
| [**Like That** Versus **That Way**](07-like-that-versus-that-way.md) | No organices los archivos así; si trabajas de esa manera, perderás tiempo. | Don't organize the files like that; if you work that way, you'll waste time. |
| [**What Is It Like?** Versus **How Is It?**](08-what-is-it-like-versus-how-is-it.md) | ¿Cómo es Bogotá y cómo está hoy? | What's Bogotá like, and how is it today? |
| [**What Does Someone Look Like?**](09-what-does-someone-look-like.md) | ¿Cómo es físicamente el nuevo gerente? Es alto, tiene el pelo corto y usa gafas. | “What does the new manager look like?” “He's tall, has short hair, and wears glasses.” |
| [**What Is Someone Like?**](10-what-is-someone-like.md) | ¿Cómo es la nueva gerente? Es paciente, directa y muy organizada. | “What's the new manager like?” “She's patient, direct, and very organized.” |
| [**How Do You Like...?**](11-how-do-you-like.md) | ¿Qué te parece tu nuevo trabajo? Me gusta mucho, aunque el trayecto es largo. | “How do you like your new job?” “I like it a lot, although the commute is long.” |
| [**Look Like**](12-look-like.md) | Esa nube parece un barco desde este ángulo. | That cloud looks like a ship from this angle. |
| [Sense Verbs With **Like**](13-sense-verbs-with-like.md) | Suena como una alarma, se siente como seda, sabe a limón y huele a café. | It sounds like an alarm, feels like silk, tastes like lemon, and smells like coffee. |
| [**It Looks Like** a Complete Idea](14-it-looks-like-a-complete-idea.md) | Parece que va a llover porque el cielo está completamente oscuro. | It looks like it's going to rain because the sky is completely dark. |
| [**Feel Like + Noun or -ing**](15-feel-like-a-noun-or-ing.md) | Tengo ganas de tomar café, pero no tengo ganas de salir bajo la lluvia. | I feel like having coffee, but I don't feel like going out in the rain. |
| [**Feel Like** Meaning Seem](16-feel-like-seeming.md) | Siento como si hubiera olvidado algo importante. | I feel like I've forgotten something important. |
| [**Feel Like Myself**](17-feel-like-myself.md) | Todavía no me siento como siempre después de la gripe. | I still don't feel like myself after the flu. |
| [**Like** Versus **As**](18-like-versus-as.md) | Carlos trabaja como gerente y habla como su antiguo jefe. | Carlos works as a manager and speaks like his former boss. |
| [**Unlike**](19-unlike.md) | A diferencia de su hermano, Natalia disfruta hablar en público. | Unlike her brother, Natalia enjoys speaking in public. |
| [**Alike**](20-alike.md) | Las gemelas se parecen, pero no tienen gustos iguales. | The twins look alike, but they don't have the same tastes. |
| [**Nothing, Anything**, and **Something Like**](21-nothing-anything-and-something-like.md) | El resultado no se parece en nada al diseño original. | The result is nothing like the original design. |
| [**More Like**](22-more-like.md) | No fue una reunión; fue más bien una discusión de dos horas. | It wasn't a meeting; it was more like a two-hour argument. |
| [Examples With **Like**](23-examples-with-like.md) | Ciudades como Bogotá y Ciudad de México necesitan mejores sistemas de transporte público. | Cities like Bogotá and Mexico City need better public transportation systems. |
| [Informal Quotation **Be Like**](24-informal-quotation-be-like.md) | Le mostré el precio y ella reaccionó: “¡De ninguna manera voy a pagar eso!” | I showed her the price, and she was like, “There's no way I'm paying that!” |
| [Filler **Like**](25-filler-like.md) | Esperamos como veinte minutos. | We waited for, like, twenty minutes. |
| [**Likely**](26-likely.md) | Es probable que el vuelo se retrase por la tormenta. | The flight is likely to be delayed because of the storm. |
| [**Unlikely**](27-unlikely.md) | Es improbable que el banco abra hoy porque es festivo. | The bank is unlikely to open today because it's a holiday. |
| [**Likelihood, Probability**, and **Probably**](28-likelihood-probability-and-probably.md) | La probabilidad de lluvia es alta, así que probablemente lloverá esta tarde. | The likelihood of rain is high, so it'll probably rain this afternoon. |
| [The **-like** Suffix](29-like-suffix.md) | Su curiosidad infantil hace que las clases sean interesantes. | Her childlike curiosity makes the classes interesting. |
| [Likes and Dislikes](30-likes-and-dislikes.md) | La encuesta pregunta por tus gustos y preferencias de viaje. | The survey asks about your travel likes and dislikes. |
| [Pronunciation and Sound Contrast](31-pronunciation-and-sound-contrast.md) | A Mike le gusta caminar junto al lago, pero no le gusta lamer hielo de lima. | Mike likes hiking by the lake but dislikes licking lime ice. |

## Mastery Phrases

| Spanish | English |
|---|---|
| Me gustaría saber cómo es querer a alguien que se parece a ti, pero que no es como tú. | I'd like to know what it's like to like someone who looks like you but isn't like you. |
| Parece café, huele a café y sabe a café, pero no tengo ganas de tomarlo porque siento como si algo no estuviera bien. | It looks like coffee, smells like coffee, and tastes like coffee, but I don't feel like drinking it because I feel like something isn't right. |
| A diferencia de su hermana, a la probable ganadora le gusta trabajar como gerente y suele decir: “¡Esto es exactamente lo que me gusta!” | Unlike her sister, the likely winner likes working as a manager and is often like, “This is exactly what I like!” |
