# **This Is Like That**

Use **A is like B** to compare two people, things or situations.

| Spanish | English |
|---|---|
| Esta situación es como la del año pasado, pero esta vez tenemos más tiempo. | This situation is like the one from last year, but this time we have more time. |

**Like this** and **like that** can also mean **así**:

- **Do it like this → Hazlo así.**
- **Don't speak to her like that → No le hables así.**
