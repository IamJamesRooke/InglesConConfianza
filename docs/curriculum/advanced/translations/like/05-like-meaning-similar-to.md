# **Like** Meaning Similar To

Use **like + person or thing** to express similarity.

| Spanish | English |
|---|---|
| Este barrio es como un pueblo pequeño porque todos se conocen. | This neighborhood is like a small town because everyone knows each other. |

Compare liking with similarity:

- **I like Laura**: Laura me cae bien / me gusta Laura.
- **I'm like Laura**: soy como Laura / me parezco a Laura.
