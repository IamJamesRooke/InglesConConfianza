# Uses of **No, None**, and **Any**

| Lesson | Spanish | English |
|---|---|---|
| [**No** Before a Thing](01-no-before-a-thing.md) | No queda café, así que tendremos que comprar más. | There's no coffee left, so we'll have to buy more. |
| [**Not...Any**](02-not-any.md) | No queda café y no tenemos tazas limpias. | There isn't any coffee left, and we don't have any clean cups. |
| [**None** Standing Alone](03-none-standing-alone.md) | —¿Cuánto café queda? —Nada. | “How much coffee is left?” “None.” |
| [**None Of**](04-none-of.md) | Ninguno de los libros explica el problema con claridad. | None of the books explains the problem clearly. |
| [**No** Versus **None**](05-no-versus-none.md) | No había entradas y ninguno de nosotros pudo entrar. | There were no tickets, and none of us could get in. |
| [**Any** in Questions](06-any-in-questions.md) | ¿Tienes alguna pregunta sobre el contrato? | Do you have any questions about the contract? |
| [Affirmative **Any** Meaning Whichever](07-any-meaning-whichever.md) | Puedes escoger cualquier asiento; todos tienen buena vista. | You can choose any seat; they've all got a good view. |
| [**Any Of**](08-any-of.md) | ¿Alguno de estos horarios te sirve? | Do any of these times work for you? |
| [**Not...Anymore**](09-not-anymore.md) | Ya no trabajo los sábados porque cambié de horario. | I don't work Saturdays anymore because I changed my schedule. |
| [**At All**](10-at-all.md) | No entendí la explicación para nada. | I didn't understand the explanation at all. |
| [**Anyway** and Informal **Anyways**](11-anyway-and-anyways.md) | De todas maneras, ya es tarde, así que mejor vámonos. | Anyway, it's already late, so we'd better get going. |
| [**Anyone, Anything**, and **Anywhere**](12-anyone-anything-and-anywhere.md) | No vi a nadie ni encontré nada en ninguna parte. | I didn't see anyone or find anything anywhere. |
| [**No One, Nothing**, and **Nowhere**](13-no-one-nothing-and-nowhere.md) | Nadie dijo nada y no había ningún lugar donde sentarse. | No one said anything, and there was nowhere to sit. |
| [Homophones: **No / Know** and **None / Nun**](14-homophones-no-know-and-none-nun.md) | Sé que ninguna monja dijo que no. | I know that no nun said no, and none of them knew why. |

## Mastery Phrases

| Spanish | English |
|---|---|
| No queda café y ninguno de nosotros tiene dinero, así que no podemos comprar nada. | There's no coffee left, and none of us has any money, so we can't buy anything. |
| ¿Alguno de estos horarios te sirve? Cualquiera está bien; ya no trabajo de noche. | Do any of these times work for you? Any of them is fine; I don't work nights anymore. |
| Sé que ninguna monja dijo que no, pero de todas maneras nadie entendió nada. | I know that no nun said no, but anyway, no one understood anything. |
