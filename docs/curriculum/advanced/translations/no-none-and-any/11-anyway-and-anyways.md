# **Anyway** and Informal **Anyways**

**Anyway** returns to a topic or means despite that. **Anyways** is a very informal variant.

| Spanish | English |
|---|---|
| De todas maneras, ya es tarde, así que mejor vámonos. | Anyway, it's already late, so we'd better get going. |

Use **anyway** in standard writing; **anyways** represents relaxed regional speech.
