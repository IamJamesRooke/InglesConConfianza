# **Might As Well**

Use **might as well + base verb** when an action seems sensible because there isn't a better reason to avoid it or a better alternative.

| Spanish | English |
|---|---|
| Ya que estamos aquí y la fila es corta, mejor entremos de una vez. | Since we're already here and the line's short, we might as well go in. |

It doesn't express simple possibility. **We might go in** means perhaps we will; **we might as well go in** means doing so is the reasonable choice.
