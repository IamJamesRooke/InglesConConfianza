# Translations of Spanish **Tomar**

Spanish **tomar** maps to taking, drinking, transport, decisions, measurements, time, routes, and occupying space.

| Lesson | Spanish | English |
|---|---|---|
| [**Tomar → Take**](01-take.md) | Toma este documento y léelo. | Take this document and read it. |
| [**Tomar → Drink / Have**](02-drink.md) | Tomamos café después del almuerzo. | We drink coffee after lunch. |
| [**Tomar → Take** Transport](03-transport.md) | Tomé el bus hasta el centro. | I took the bus downtown. |
| [**Tomar → Make** a Decision](04-make-a-decision.md) | Tomamos una decisión difícil. | We made a difficult decision. |
| [**Tomar → Take** Time](05-take-time.md) | El trámite tomó dos horas. | The process took two hours. |
| [**Tomar → Take** Measurements](06-take-measurements.md) | La enfermera me tomó la temperatura. | The nurse took my temperature. |
| [**Tomar → Take** a Route](07-take-a-route-or-direction.md) | Toma la segunda calle a la derecha. | Take the second street on the right. |
| [**Tomar → Occupy / Seize / Take Over**](08-occupy-or-seize.md) | Los manifestantes tomaron el edificio. | The protesters occupied the building. |
