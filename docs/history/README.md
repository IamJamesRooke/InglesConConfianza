# Project History

This directory preserves the story of how Ingles Con Confianza was built without mixing completed work into the active backlog.

- [Project Timeline](project-timeline.md) explains the major product, curriculum, architecture, and engineering decisions in chronological order.
- Git remains the detailed source of truth for individual changes, experiments, reversals, and exact implementation evidence.

Current work belongs in [`docs/backlog.md`](../backlog.md). Durable curriculum rules belong in [`docs/curriculum-database.md`](../curriculum-database.md), and lesson-design principles belong in [`docs/teaching-methodology.md`](../teaching-methodology.md).
