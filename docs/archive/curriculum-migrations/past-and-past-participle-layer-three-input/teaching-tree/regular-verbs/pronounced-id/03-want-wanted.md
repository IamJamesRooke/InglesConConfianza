# **Want → Wanted**

The **-ed** ending adds the syllable `/ɪd/`.

## **Want → Wanted**

When a regular base ends in written **t** and the sound `/t/`, add **-ed** and pronounce an extra `/ɪd/` syllable:

**want → wanted**

| Course source | Base | Past and past participle | Spanish bridge |
|---|---|---|---|
| core verb | want | wanted | quiso / querido |
| core verb | start | started | empezó / empezado |
| core verb | wait | waited | esperó / esperado |
| established cognate | visit | visited | visitó / visitado |
| established cognate | present | presented | presentó / presentado |

- Past: Laura **wanted** to begin, but she **waited** until the teacher **started**.
- Past participle: Laura has **wanted** to begin, but she has **waited** until the teacher has **started**.

The vowel is audible: **wan-ted, star-ted, wai-ted, visi-ted, presen-ted**.
