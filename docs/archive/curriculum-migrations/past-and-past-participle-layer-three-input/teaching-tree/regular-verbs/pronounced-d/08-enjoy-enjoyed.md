# **Enjoy → Enjoyed**

The written **-ed** ending is pronounced `/d/`.

## **Enjoy → Enjoyed**

After the voiced vowel sound in **enjoy**, **-ed** is pronounced `/d/`:

**enjoy → enjoyed**

| Course source | Base | Past and past participle | Spanish bridge |
|---|---|---|---|
| core verb | stay | stayed | se quedó / se ha quedado |
| core verb | try | tried | intentó / intentado |
| core verb | study | studied | estudió / estudiado |
| model vocabulary | enjoy | enjoyed | disfrutó / disfrutado |

The spelling pattern depends on the letter before **y**:

- vowel + **y**: **enjoy → enjoyed**, **stay → stayed**
- consonant + **y**: **study → studied**, **try → tried**

All still finish with the sound `/d/`.

- Past: Laura **studied** at home and **enjoyed** the lesson.
- Past participle: Laura has **studied** at home and has **enjoyed** the lesson.
