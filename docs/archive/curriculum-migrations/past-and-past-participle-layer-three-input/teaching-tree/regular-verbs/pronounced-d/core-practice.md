# Core Practice: **-ed** Pronounced `/d/`

Use the same sound in past statements and in constructions that require the past participle.

## Regular Past Pronounced `/d/`

When a regular past form does not end in **-ted** or **-ded**, the written **e** is silent. The verbs in this lesson end with the sound `/d/`.

The `/d/` attaches directly to the base verb:

| Spanish | English | Pronunciation bridge |
|---|---|---|
| estudió | **studied** | study + `/d/` |
| intentó, trató, probó | **tried** | try + `/d/` |
| llamó | **called** | call + `/d/` |
| escuchó | **listened to** | listen + `/d/` |
| explicó | **explained** | explain + `/d/` |
| recordó | **remembered** | remember + `/d/` |
| llegó | **arrived** | arrive + `/d/` |
| vivió | **lived** | live + `/d/` |
| se quedó | **stayed** | stay + `/d/` |
| mostró | **showed** | show + `/d/` |

**El sistema funcionó; pedí el libro, lo obtuve y cerré la aplicación.**<br>

## Similar sound families

- **studied, tried** end in the spelling **-ied**, but the ending is still pronounced `/d/`.
- **listened, explained** finish with `/nd/`.
- **arrived, lived** finish with `/vd/`.
- **stayed** and **showed** attach `/d/` directly to their final vowel sounds.

**Estudié la explicación y traté de recordarla.**<br>
I studied the explanation and tried to remember it.

There is no extra syllable in these endings.

The same rule applies to cognates such as **prepared**:

**prepared** → “prepar + `/d/`” as a course pronunciation bridge, not *pre-par-ed*

## Regular Past Participle Pronounced `/d/`

When the form does not end in **-ted** or **-ded**, the written **e** is silent. The participles in this lesson finish with the sound `/d/`.
