# **Laugh → Laughed**

The written **-ed** ending is pronounced `/t/`.

## **Laugh → Laughed**

In **laugh**, written **gh** represents final `/f/`. After that voiceless sound, **-ed** is pronounced `/t/`:

**laugh → laughed**

| Course source | Base | Past and past participle | Spanish bridge |
|---|---|---|---|
| model vocabulary | laugh | laughed | se rió / se ha reído |
| cognate reinforcement | photograph | photographed | fotografió / fotografiado |

- Past: Laura **laughed** while Diana **photographed** the group.
- Past participle: Laura has **laughed**, and Diana has **photographed** the group.

The spelling differs, but both bases end in `/f/`: laugh + `/t/`, photograph + `/t/`.
