# Past and Past Participle Transformations

This is the single source of truth for English past and past-participle forms. It organizes forms as compact phonetic teaching sets, not as separate “past” and “participle” courses.

| Teaching branch | Rule | Model |
|---|---|---|
| [Regular verbs](regular-verbs/README.md) | Both forms use regular **-ed** | **wait → waited → waited** |
| [Matching past and participle](matching-past-and-participle/README.md) | The two irregular forms match | **feel → felt → felt** |
| [Different past and participle](different-past-and-participle/README.md) | The past and participle follow different transformations | **steal → stole → stolen** |

Use the [complete verb-form index](all-verbs-index.md) to audit coverage. Teaching order comes from the sound families, not alphabetical order or an artificial course-level split.
