# Current but Uncommon Matching Forms

These verbs have current matching past and participle forms. Regular alternatives are often the safest production choice.

| Base | Past = participle | Note |
|---|---|---|
| abide | abode / abided | **abide by** normally uses **abided** |
| alight | alit / alighted | bajar / posarse |
| bereave | bereaved / bereft | **bereft** is frequent as an adjective |
| beseech | besought / beseeched | suplicar |
| gild | gilded / gilt | **gilt** is frequent as an adjective |
| knit | knit / knitted | tejer |
| plead | pleaded / pled | **pled** is especially American |
| rend | rent | desgarrar; literary |
| wed | wed / wedded | casarse |
| wet | wet / wetted | mojar |

These belong in the coverage record, but they should not compete with **went, had, made**, or **took** during initial memorization.
