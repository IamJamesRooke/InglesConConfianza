# **Bent, Lent, Sent, Spent**

The matching irregular forms end in a shared consonant pattern.

## **Bent, Lent, Sent, Spent, Leant, Meant**

| Base | Past | Participle | Spanish |
|---|---|---|---|
| bend | bent | bent | doblar |
| lend | lent | lent | prestar |
| send | sent | sent | enviar |
| spend | spent | spent | gastar / pasar tiempo |
| lean | leant / leaned | leant / leaned | inclinarse |
| mean | meant | meant | significar |

The irregular targets rhyme: **bent–lent–sent–spent–leant–meant**.

**I meant to return what she lent me, so I sent it yesterday.**

## Irregular Past: **Send → Sent** and **Spend → Spent**

Learn these similar changes together:

- **send → sent**
- **spend → spent**

Both past forms end in the sound `/ɛnt/`.

| Spanish | Base form | Past |
|---|---|---|
| enviar, envió | **send** | **sent** |
| gastar dinero, gastó dinero | **spend money** | **spent money** |
| pasar tiempo, pasó tiempo | **spend time** | **spent time** |

**Envié el documento y pasé tiempo con el equipo.**<br>
I sent the document and spent time with the team.

## Irregular Past Participles: **Sent** and **Spent**

Learn these similar changes together:

- **send → sent**
- **spend → spent**

Both participles end in the sound `/ɛnt/`.

| Spanish | Base form | Past participle |
|---|---|---|
| enviar, enviado | **send** | **sent** |
| gastar dinero, gastado dinero | **spend money** | **spent money** |
| pasar tiempo, pasado tiempo | **spend time** | **spent time** |

**He enviado el documento y he pasado tiempo con el equipo.**<br>
I have sent the document and spent time with the team.
