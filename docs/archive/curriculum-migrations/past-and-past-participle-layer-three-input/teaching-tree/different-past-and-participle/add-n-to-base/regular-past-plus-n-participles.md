# Regular Past with an **-n** Participle Alternative

These verbs usually have a regular past while an **-n/-en** participle remains standard.

| Base | Past | Participle | Spanish |
|---|---|---|---|
| mow | mowed | mown / mowed | cortar el césped |
| saw | sawed | sawn / sawed | serruchar |
| sew | sewed | sewn / sewed | coser |
| shave | shaved | shaven / shaved | afeitar |
| shear | sheared | shorn / sheared | esquilar |
| show | showed | shown / showed | mostrar |
| sow | sowed | sown / sowed | sembrar |
| swell | swelled | swollen / swelled | hincharse |

Many **-n** forms are especially common as adjectives: **a shaven face, a mown lawn, a swollen ankle**.

**The grass has been mown, and the seeds have been sown.**
