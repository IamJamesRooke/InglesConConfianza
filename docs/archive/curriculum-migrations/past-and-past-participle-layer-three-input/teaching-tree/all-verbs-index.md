# Complete Modern Verb-Form Index

This is the completeness ledger for the transformation collection. Every included head verb has one canonical family. Frequency and course level do not create duplicate homes.

The index covers current standard forms and accepted regional or meaning-dependent alternatives. Transparent compounds inherit the head transformation: **write → wrote → written** also supports **rewrite**, **overwrite**, and **underwrite**. Genuinely archaic production forms are excluded. Defective modals such as **can → could** link to the modal curriculum because they have no ordinary participle.

## Coverage boundary

The collection prioritizes all high-frequency irregular head verbs in standard modern English, then current lower-frequency forms and accepted variants. It teaches compounds through their reusable head pattern instead of padding the index with every possible prefix.
