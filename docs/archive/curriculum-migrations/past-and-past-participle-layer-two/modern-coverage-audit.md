# Layer-One Modern Coverage Audit

This audit exists to prevent curriculum collation from being mistaken for curriculum completeness.

## Checks performed

1. The high-frequency head-verb inventory was compared with the [Cambridge Grammar table of irregular verbs](https://dictionary.cambridge.org/grammar/british-grammar/table-of-irregular-verbs) and the [British Council learner inventory](https://learnenglish.britishcouncil.org/grammar/english-grammar-reference/irregular-verbs).
2. Lower-frequency current forms, regional alternatives, and meaning-dependent variants were cross-checked against [Cambridge's revised extended irregular-verb reference](https://www.cambridge.org/core/services/aop-file-manager/file/5bd88a176431f1de07115e71/216-Irregular-verbs.pdf) and a [standard-modern inventory](https://en.wikipedia.org/wiki/English_irregular_verbs) that explicitly separates common modern forms from rare, dialectal, and archaic forms.
3. Transparent prefixed verbs were checked through their head transformation, then named explicitly in the inherited-compound section below.
4. Defective modals were checked separately because forms such as **could, might, should**, and **would** do not provide ordinary past-and-participle paradigms.

## Findings and corrections

The source inventory omitted the high-frequency transformation **begin → began → begun**. It now has a teaching home in the [**i–a–u** families](../unique-past-participle/vowel-shifts/complete-families/i-a-u-families/04-begin-began-begun.md).

The source inventory also lacked several current but lower-frequency or region-sensitive forms. They are preserved in [modern coverage additions and regional variants](../special-cases-and-variants/26-modern-coverage-additions.md), including **forsake → forsook → forsaken**, **dive → dove/dived → dived**, **sneak → snuck/sneaked**, and **strew → strewed → strewn/strewed**.

## Inherited compounds checked

These do not require unrelated memory rules, but their forms must remain visible:

| Head transformation | Current compound examples |
|---|---|
| **bear → bore → borne** | forbear, overbear |
| **beat → beat → beaten** | browbeat |
| **come → came → come** | become, overcome |
| **do → did → done** | outdo, overdo, redo, undo |
| **draw → drew → drawn** | withdraw |
| **fall → fell → fallen** | befall |
| **get → got → got/gotten** | beget, forget |
| **hold → held → held** | behold, uphold, withhold |
| **lay → laid → laid** | inlay, overlay |
| **put → put → put** | input, output |
| **set → set → set** | beset, offset, preset, reset, upset |
| **speak → spoke → spoken** | misspeak |
| **stand → stood → stood** | understand, withstand |
| **take → took → taken** | mistake, overtake, retake, undertake |
| **throw → threw → thrown** | overthrow |
| **write → wrote → written** | overwrite, rewrite, underwrite |

## Boundary retained

Genuinely archaic forms are not production targets. For example, **shrive → shrove → shriven** is marked as old use in current dictionaries and is therefore outside the speaking inventory. Purely dialectal or nonstandard alternatives may be mentioned for recognition, but they are not presented as the safest course form.

Ordinary regular forms are covered by the regular transformation system rather than padded into the irregular index. Current dictionary forms include **bide → bided**, **hoist → hoisted**, and **text → texted**.

Defective modals belong in the modal curriculum because they do not have normal three-form paradigms.
