# Regular Pasts with **-n** Participles

Use the base verb as the immediate bridge to the past participle.

## Transformation

| Base | Past participle | Spanish |
|---|---|---|
| mow | **mown/mowed** | cortar el césped |
| saw | **sawn/sawed** | serruchar |
| sew | **sewn/sewed** | coser |

## Examples

**The grass has been mown, and the seeds have been sown.**
