# **Write → Written**

Use the base verb as the immediate bridge to the past participle.

## Transformation

| Base | Past participle | Spanish |
|---|---|---|
| write | **written** | escribir |

## Examples

**I wrote yesterday, and I have written again today.**

**He escrito el mensaje y he manejado hasta la oficina.**<br>
I have written the message and driven to the office.
