# **Forsake → Forsook**

Build the irregular past from the base. The visible or spoken change is the memory bridge.

## Transformation

| Base | Past | Spanish |
|---|---|---|
| forsake | **forsook** | abandonar |

## Examples

**They forsook the old plan, and the building has been forsaken for years.**<br>
Abandonaron el plan anterior y el edificio lleva años abandonado.
