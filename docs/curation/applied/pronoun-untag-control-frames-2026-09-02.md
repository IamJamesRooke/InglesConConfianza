# Removed topic:pronoun from object-control verb frames, 2026-09-02

Phase D cross-tagged 11 verb constructions (querer que [alguien] [haga algo],
necesitar que…, decirle a [alguien] que…, pedirle a…, esperar que…, hacer que…,
conseguir que…, dejar que…, permitir que…, ayudarle a…, quisiera que…) with
topic:pronoun and grammar:subordinate-subject-pronoun. Those are verb
constructions, not pronouns — removed both tags via direct DELETE. They keep
grammar:object-control for a future "verbs + object + infinitive" topic.

The generic prepositional-pronoun rows (con/para/sin/a/de [alguien]) and the
subordinate-subject paradigm (que yo/tú/él/ella/nosotros/ellos [haga algo]) keep
topic:pronoun — those are pronoun content.
