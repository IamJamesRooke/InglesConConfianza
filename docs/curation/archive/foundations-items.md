# Foundations — the mandatory items (DRAFT, 2026-09-15)

**Unit:** one *item* = one thing the student must learn: a word, a rule, or a pattern
with its exemplars. Database rows are *evidence* for items, not items (a row like
`querer [hacer algo] → want to do` is a combination of items; `para él → for him` is two
items counted elsewhere). Row ids for every item are in `foundations-draft.md`.

**Test for mandatory:** can the word be swapped for a more specific one without changing
the grammar? If yes → vocabulary, incidental, never a target (*eat, help, buy, drink*).
If it *is* the slot — *do, something, somebody, thing, it* — it's spine.

**Counting (owner's unit):** irregular verb past + participle = 1 · cognate group = 1 ·
numbers 1–12 = 1 · a verb with two English faces = 2 (*be able* / *can*).

Target: under 300. This draft: **≈ 220** (+ 10 cognate groups pulled in on demand, + up to
~25 irregular pasts *only if* those vocabulary verbs get used).

## E. The rules — 26

86. after *want / need / have / going / would like* → **to** + verb
87. after *can / will / would / should / don't* → bare verb
88. he / she / it adds **-s** (does, has, goes, is)
89. **-ing** (-ando / -iendo)
90. **-ed** — past and participle are the same word (regular verbs)
91. *no* + verb → **don't / doesn't / didn't** + verb
92. questions with **do / does / did**
93. questions with **be / can** — swap the order (*Is she…? Can you…?*)
94. statement order inside *if / what / where* (*I want to know if you can…*)
95. object pronoun goes **after** the verb (*lo quiero → I want it*)
96. *que yo haga* → **me to do** (*want me to, need you to*)
97. **se** disappears (*me llamo → my name is, levantarse → get up*)
98. **tener → be** (*tengo 20 años, tengo hambre*)
99. **ser and estar → one *be***
100. **tú / usted / ustedes → one *you***
101. **su → his / her / its / their / your** — pick by owner
102. four *the*s (el la los las) → one **the**; *un / una* → one **a**
103. frequency word goes **before** the verb (*I always arrive*)
104. double negative: *no … nada → not … anything* (or *nothing*)
105. **more / the most** + *than* (más importante que → more important than)
106. **as … as** (tan … como)
107. after *for / with / to* the pronoun is the object form (*for me, with him, to them*)
108. **it is [adjective] to** (es importante hacerlo)
109. official **contractions**: I'm, you're, it's, don't, doesn't, didn't, can't, isn't, aren't, won't, wouldn't, there's
110. *para* + verb → **to** (purpose: *I'm calling to confirm*)
111. commands: bare verb / **don't** + verb / **let's** + verb
